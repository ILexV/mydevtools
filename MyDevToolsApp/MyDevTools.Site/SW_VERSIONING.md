# Автоматическое управление версией Service Worker

## Как это работает

Версия кэша в `sw.js` автоматически синхронизируется с версией в `package.json`.

### При каждой сборке:

1. **npm run build** запускает `prebuild` скрипт
2. Скрипт `update-sw-version.js` читает версию из `package.json`
3. Автоматически обновляет `CACHE_VERSION` в `sw.js`
4. Vite собирает проект с обновленной версией

### Как обновить версию:

```bash
# Обновите версию в package.json
npm version patch  # 1.0.0 → 1.0.1
npm version minor  # 1.0.1 → 1.1.0
npm version major  # 1.1.0 → 2.0.0

# Или вручную отредактируйте package.json:
{
  "version": "1.2.3"
}

# Затем просто соберите проект:
npm run build
# или
dotnet build
```

### Преимущества:

✅ **Автоматизация**: Не нужно вручную менять версию в sw.js
✅ **Единый источник истины**: Версия хранится только в package.json
✅ **Семантическое версионирование**: Используйте npm version для автоматического обновления
✅ **Нет ошибок**: Невозможно забыть обновить версию

### Пример workflow:

```bash
# 1. Внесли изменения в код
# 2. Обновили версию
npm version patch

# 3. Собрали проект (версия обновится автоматически)
dotnet build

# 4. Service worker автоматически получит новую версию v1.0.1
```

## Файлы

- **package.json**: Хранит версию приложения
- **update-sw-version.js**: Скрипт автоматического обновления
- **sw.js**: Service worker с автоматически обновляемой версией
