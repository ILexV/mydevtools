Agent einrichten

Laden Sie den lokalen Agenten herunter, starten Sie ihn und kehren Sie zu dieser Seite zurück.

Über den Agenten und Download
  1. Starten Sie MyDevTools Agent. Er fragt den DNS-Resolver, der auf diesem Computer bereits eingestellt ist.
  2. Kopieren Sie den Kopplungscode aus dem Agentenfenster.
  3. Fügen Sie den Code unten ein. Wenn der Browser nach lokalem Netzwerkzugriff fragt, erlauben Sie ihn für diese Verbindung.

Der Browser sendet Name und Eintragstyp nur an den Agenten auf 127.0.0.1. Der Agent fragt den DNS-Resolver dieses Computers. Die Abfrage geht nicht an einen MyDevTools-Server und nicht über einen fremden DNS-over-HTTPS-Dienst. Dieser Browser merkt sich den gewählten Eintragstyp. Name, Antwort und Kopplungscode speichert er nicht.

DNS-Name
Ein Hostname oder bei PTR eine IP-Adresse. Internationale Namen brauchen Punycode (xn--). Der Agent fragt den Resolver dieses Computers, nicht einen öffentlichen DoH-Dienst.
Typ
Ein Eintragstyp. PTR kehrt eine IP-Adresse um. Die Suchliste dieses Computers gilt weiter.

Die DNS-Abfrage fragt den auf Ihrem Computer eingestellten Resolver nach einem Namen und einem Eintragstyp. Der Browser sendet die Abfrage nicht selbst. Der lokale Agent vergibt dns.lookup getrennt von http.request und icmp.trace.

Detaillierte Funktionalität

Unterstützt werden A, AAAA, CNAME, MX, NS, TXT, SOA und PTR. Eine IP-Adresse gilt nur für PTR und wird auf dem Agenten nach in-addr.arpa oder ip6.arpa umgekehrt. Die Antwortsektion erscheint so, wie der Resolver sie lieferte, einschließlich eines CNAME neben Adressen. Leeres NOERROR heißt «keine Einträge», NXDOMAIN heißt, der Name steht nicht im DNS. Die Abfrage nutzt den Resolver des Betriebssystems, daher bleiben Split-DNS und die Suchliste des Computers erhalten. Sie geht nicht an einen MyDevTools-Server und nicht über öffentliches DNS-over-HTTPS. Der gewählte Eintragstyp bleibt in diesem Browser. Name und Einträge nicht.

Praktische Beispiele

  • example.com vom Typ A zeigt die IPv4-Adressen des Resolvers dieses Computers.
  • example.com vom Typ MX zeigt Mail-Server und ihre Präferenz.
  • 1.1.1.1 vom Typ PTR fragt den Rückwärtsnamen ab.

So verwenden Sie dieses Tool

  1. 1

    Lokalen Agenten starten

    Laden Sie den Agenten herunter, starten Sie ihn und kopieren Sie den Kopplungscode.

  2. 2

    DNS-Abfrage koppeln

    Fügen Sie den Code ein und verbinden Sie. Die Seite verlangt dns.lookup und behält Rechte, die dieser Browser schon hat.

  3. 3

    Einen Namen abfragen

    Geben Sie einen Hostnamen ein, wählen Sie A, AAAA, CNAME, MX, NS, TXT, SOA oder PTR und drücken Sie Abfragen. Für PTR geben Sie eine IP-Adresse ein.

  4. 4

    Antwort lesen

    Die Tabelle zeigt Name, Typ, TTL, MX-Präferenz und Daten. Kopieren Sie die Antwort als Text. Ein Neuladen löscht sie.

Tipps und Best Practices

  • Eine verlorene oder abgewiesene Abfrage ist ein Fehler. Eine leere NOERROR-Antwort ist keiner.
  • Die hosts-Datei wird nicht gefragt. Nur der DNS-Resolver antwortet.
  • Höchstens vier Abfragen laufen zugleich. Das ist kein Netz-Scan und kein Typ-Durchlauf.
  • Der veröffentlichte Windows-Download kann älter sein als diese Seite. Die DNS-Abfrage braucht einen Agenten, der dns.lookup meldet.
