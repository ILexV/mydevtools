Der Hex-Betrachter öffnet jede lokale Datei als virtuellen Hex-Dump. Jede Zeile zeigt 16 Bytes als Hex, ASCII und UTF-8. Gelesen werden nur die Zeilen auf dem Bildschirm, damit eine große Binärdatei nicht zu einer einzigen langen Seite wird.

Detaillierte Funktionalität

Die Datei bleibt auf diesem Gerät. Die ersten 512 Bytes werden auf eine bekannte Signatur geprüft (PNG, JPEG, GIF, WebP, PDF, ZIP, gzip, ELF, PE, MP3, MP4 und die weiteren Typen, die die Site schon erkennt). Ohne Signatur markiert eine UTF-8-Probe die Datei als Text oder lässt sie als unbekanntes Binärformat.

Die Suche nimmt Text oder Hex (89 50 4e 47 oder 0x89504e47). Sie liest 1 MiB auf einmal, überlappt das Muster, damit ein Treffer eine Blockgrenze kreuzen kann, und stoppt nach 200 Treffern. Der Scan lässt sich abbrechen. Die Entropie nutzt 4-KiB-Blöcke. Bis 1 MiB wird alles gemessen; darüber gibt es 256 gleichmäßige Proben. Das Diagramm schätzt Zufälligkeit, es speichert kein Histogramm jedes Bytes einer mehrgigabytegroßen Datei.

Der Export lädt einen inklusiven Bytebereich als Ausschnitt der Originaldatei herunter, bis 256 MiB, ohne eine zweite Kopie der ganzen Datei in der Seite. Bytes werden nicht geändert, und es gibt keinen Disassembler.

Praktische Beispiele

PNG-Signatur: Eine Datei, die mit 89 50 4E 47 beginnt, wird als PNG beschriftet. Die ersten Bytes stehen über der Tabelle, die Offset-Spalte beginnt bei 00000000.

Sprung: Geben Sie 0x20 oder 32 ein und wählen Sie Gehe. Die virtuelle Tabelle scrollt zu der Zeile, die dieses Byte enthält.

Text- oder Hex-Suche: Suchen Sie Hello als Text oder 48 65 6c 6c 6f als Hex. Jeder Treffer ist ein Offset, den Sie anklicken können. Bei sich wiederholenden Daten stoppt die Suche bei 200 Treffern.

Bereich exportieren: Erstes Byte 0 und letztes Byte 15 laden diese 16 Bytes herunter. Der Dateiname enthält den Hex-Bereich.

So verwenden Sie dieses Tool

  1. 1

    Lokale Datei öffnen

    Legen Sie eine beliebige Datei ab oder wählen Sie sie. Eine leere Datei wird abgelehnt. Das Lesen des Kopfs prüft die ersten Bytes und zeigt Größe, erkannten Typ und Zeilenzahl.

  2. 2

    Durch den Dump gehen

    Scrollen Sie die virtuelle Tabelle oder geben Sie einen dezimalen oder 0x-Offset ein. Jede Zeile hat 16 Bytes: Hex, ASCII (Punkt für nicht druckbare Bytes) und UTF-8 (ein getrenntes Zeichen ist ein Punkt).

  3. 3

    Suchen oder Entropie messen

    Suchen Sie Text oder Hex. Abbrechen lässt die Datei offen. Messen Sie die Entropie für einen Balken je 4-KiB-Block, oder 256 Proben, wenn die Datei größer als 1 MiB ist. Klicken Sie einen Balken an, um dorthin zu springen.

  4. 4

    Einen Bereich exportieren

    Geben Sie das erste und das letzte Byte ein, beide inklusive. Der Download ist ein Ausschnitt von höchstens 256 MiB. Der Rest der Datei wird nicht in den Download kopiert.

Tipps und Best Practices

  • Die Tabelle liest nur das sichtbare Fenster über Dateiausschnitte. Ein Sprung ans Ende einer großen Datei lädt die Mitte nicht.
  • Ein Hex-Muster braucht eine gerade Anzahl Ziffern. Leerzeichen, Doppelpunkte und Bindestriche werden ignoriert, ein führendes 0x ist erlaubt.
  • Die Überlappung behält einen Treffer, der in einem 1-MiB-Block beginnt und im nächsten endet. Derselbe Treffer steht nicht zweimal in der Liste.
  • Die Entropie eines Blocks aus gleichen Bytes ist 0. Eine gleichmäßige Mischung aller 256 Werte ist 8 Bit/Byte.
  • Mehr als 200 Treffer beenden den Scan früh. Grenzen Sie das Muster ein, wenn Sie einen späteren Treffer brauchen.
  • Diese Seite ändert keine Bytes, speichert kein Projekt und lädt die Datei nicht hoch.

Kodierung

  • B64Base64 Kodierer / DekodiererText oder Dateien in Base64 kodieren und zurück dekodieren: Standard- oder URL-sicheres Alphabet, Padding, 76-Zeichen-Umbruch, Bildvorschau. Im Browser.
  • B32Base32 Kodierer / DekodiererBase32 kodieren und dekodieren mit RFC-4648-, Crockford- oder z-base-32-Alphabet, Padding und Groß-/Kleinschreibung – für Text und Dateien im Browser.
  • B58Base58 Kodierer / DekodiererBase58 kodieren und dekodieren mit Bitcoin-, Flickr- oder Ripple-Alphabet, für Text und Dateien bis 1 MiB. Lokal im Browser, ohne Upload.
  • 0xHex Kodierer / DekodiererText oder Dateien in Hexadezimal umwandeln und zurück. Zeichensatz und Schreibweise wählbar; dekodiert Hex mit Leerzeichen, Doppelpunkten, Bindestrichen oder 0x.
