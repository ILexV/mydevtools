HTTP-Client

Sende HTTP-Anfragen vom Windows-PC über einen lokalen Begleiter – ohne Konto oder MyDevTools-Proxy.

Anfragen gehen direkt von deinem Windows-PC zum Ziel

Gespeicherte Anfragen

Speichert die letzten 100 gesendeten Anfragen so, wie sie geschrieben wurden – Variablen und Geheimnisse bleiben unaufgelöst, Antworten werden nicht gespeichert. Liegt dort, wo der Arbeitsbereich liegt.

    i Ziehe Elemente in Ordner oder auf eine freie Fläche, um sie in die oberste Ebene zu verschieben. Klicke mit der rechten Maustaste oder drücke Umschalt+F10, um Aktionen zu öffnen.

    Anfrage-URLs, Header (einschließlich Geheimnissen) und Inhalte werden automatisch nur in diesem Browser gespeichert. Antworten werden nicht gespeichert.

      Umgebungen

      Nutze {{name}} in URL, Parametern, Headern, Body und Autorisierung. Die aktive Umgebung hat Vorrang vor Ordnervariablen, diese vor globalen. Für einen schreibgeschützten Wert setze die Variable auf {{secret:name}}.

      Client-Einstellungen

      Proxy

      Der Agent verbindet sich über einen HTTP-Proxy: CONNECT für https, absolute URLs für http. Das Proxy-Passwort wird mit dem Arbeitsbereich gespeichert.

      Client-Zertifikate (mTLS)

      Der Agent legt https-Hosts aus seiner Liste ein Zertifikat vor, wenn der Server danach fragt. Der private Schlüssel liegt verschlüsselt im Agenten und kommt nie zurück auf die Seite. Verwenden Sie PEM-Dateien mit unverschlüsseltem Schlüssel; wandeln Sie eine .pfx zuerst um: openssl pkcs12 -in cert.pfx -out cert.pem -nodes

      Verbinden Sie einen Agenten mit Geheimnisspeicher, um Client-Zertifikate hinzuzufügen.

        Noch keine Client-Zertifikate.

        Zertifikat hinzufügen

        Lassen Sie beide Dateien leer, um das gespeicherte Zertifikat samt Schlüssel zu behalten.

        Cookies

        Cookies aus Antworten landen hier und gehen mit passenden Anfragen mit: Der Agent wählt sie bei jedem Schritt nach Domain, Pfad und Secure aus, Weiterleitungen eingeschlossen. Ohne „Cookies behalten“ gelten sie, bis die Seite geschlossen wird.

          Daten

          Anfragen laufen nacheinander in Baumreihenfolge mit ihren Skripten; von Skripten geänderte Variablen werden gespeichert. Mit einer Datendatei gibt es eine Iteration pro Zeile, verfügbar als pm.iterationData und {{Spalte}}. Schließen des Fensters stoppt den Lauf.

                        Sende HTTP- und HTTPS-Anfragen ohne Konto und ohne API-Zugangsdaten über einen MyDevTools-Server zu leiten. Ein kleiner Windows-Begleiter führt die Netzwerkanfrage aus und liefert Status, Zeit, Header und Körper zurück.
                        Detaillierte Funktionalität
                        Der Browser koppelt sich ausdrücklich über einen Einmalcode mit dem Begleiter auf 127.0.0.1. Das Verbindungstoken wird in diesem Browser bis zu 8 Stunden oder bis zum Neustart des Agenten gespeichert; der Code wird nicht gespeichert. Das Token gewährt nur http.request. Anfragen gehen direkt zum Ziel. Private und LAN-Ziele erfordern „Allow local network and this PC as targets“ im Agentenfenster (oder --allow-private); Weiterleitungen sind standardmäßig aus und sensible Header werden beim Origin-Wechsel entfernt. Anfrageentwürfe einschließlich URLs, Headern und Geheimnissen sowie Inhalte werden automatisch in diesem Browser gespeichert und später wieder geöffnet; Antworten werden nicht gespeichert. Das Verbindungstoken wird separat bis zu 8 Stunden oder bis zum Neustart des Agenten gespeichert. Mit einem aktuellen Agenten speichert der Agent Entwürfe verschlüsselt auf dem Computer statt im Browser.
                        Praktische Beispiele
                        Nutze GET für JSON, POST mit Content-Type: application/json für APIs oder HEAD für Metadaten. Füge Authorization: Bearer … nur bei Bedarf hinzu; es geht an das Ziel, nicht an MyDevTools.
                        So verwenden Sie dieses Tool
                        1. 1
                          Begleiter installieren und starten
                          Lade den Windows-x64-Begleiter herunter und starte ihn.
                        2. 2
                          Koppeln
                          Fordere im Agent-Fenster einen Code an, gib ihn ein und klicke Verbinden.
                        3. 3
                          Anfrage erstellen
                          Wähle Methode, HTTP- oder HTTPS-URL, Header und UTF-8-Körper.
                        4. 4
                          Senden und prüfen
                          Prüfe Status, Zeit, endgültige URL, Header und sichere Textvorschau. Binärdaten lassen sich bytegenau laden.
