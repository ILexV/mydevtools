Windows-Begleiter

Browser-Werkzeuge mit Ihrem Windows-PC verbinden

Der lokale Agent erteilt ausgewählten MyDevTools-Werkzeugen eine ausdrücklich autorisierte Fähigkeit auf Ihrem Computer. Der Installer legt ihn im Benutzerprofil ab, ein Konto ist nicht nötig, die Steuerung läuft über den Windows-Tray.

Herunterladen, starten und koppeln

Der Download ist ein Installer für den aktuellen Benutzer. Er legt den Agenten im Benutzerprofil ab. Ein neuerer Installer ersetzt diese Kopie.

  1. 1

    Herunterladen

    Laden Sie den Installer herunter. Ein erneuter Start einer neueren Fassung ersetzt den installierten Agenten.

  2. 2

    Starten

    Öffnen Sie den Installer. Er beendet einen bereits laufenden Agenten und schreibt die neue Kopie. Windows kann um Bestätigung für eine heruntergeladene App bitten. Administratorrechte sind nicht erforderlich.

  3. 3

    Koppeln

    Geben Sie den aktuellen Code des Agenten im MyDevTools-Werkzeug ein. Die Kopplung gewährt nur die von diesem Werkzeug angeforderte Fähigkeit.

Ein enges Berechtigungsmodell

Der Agent ist weder Konto noch Remotedienst oder allgemeiner Befehlsausführer.

  • Keine Registrierung, Anmeldung oder MyDevTools-Cloud-Weiterleitung.
  • Keine Administratorrechte und kein Windows-Dienst. Der Installer gilt nur für den aktuellen Benutzer.
  • Ein wechselnder Einmalcode startet eine zeitlich begrenzte Browsersitzung. Der Browser speichert das Verbindungstoken bis zu 8 Stunden oder bis zum Neustart des Agenten, aber niemals den Kopplungscode.
  • Er lauscht nur auf diesem PC. Anfragen und Proben gehen direkt vom Agenten zum Ziel, über einen Proxy nur, wenn Sie einen festlegen. Ziele im privaten Netz sind gesperrt, bis Sie sie im Agentenfenster erlauben. Router auf dem Pfad werden auch mit privater Adresse angezeigt.

Sie behalten die Kontrolle

Das Schließen blendet das kleine Fenster aus; das Tray-Symbol öffnet es wieder.

  • Version und aktuellen Kopplungscode anzeigen.
  • Autostart ist optional und standardmäßig aus. Er nutzt Ihre Windows-Benutzereinstellungen und bleibt erhalten, wenn ein neuerer Installer den Agenten ersetzt.
  • „Allow local network and this PC as targets“ ist standardmäßig aus. Eingeschaltet erreichen Werkzeuge private und Loopback-Adressen und können Ihr eigenes Netzwerk scannen; die Wahl wird gespeichert, und Ausschalten stoppt einen laufenden Scan eines privaten Ziels.
  • Beenden stoppt den lokalen Server und widerruft aktive Sitzungen vollständig.

Ein verschlüsselter Tresor auf diesem PC

Werkzeuge, die den Tresor anfordern, speichern ihre Daten im Agenten statt im Browser.

  • Jede Datei ist mit AES-256-GCM verschlüsselt; Windows schützt den Schlüssel für Ihr Benutzerkonto.
  • Geheimnisse und Schlüssel von Client-Zertifikaten sind nur schreibbar: Eine Seite kann sie in Anfragen verwenden, aber nie zurücklesen.
  • Jede Website hat ihren eigenen Tresor, sodass eine Website die Daten einer anderen nicht lesen kann.
  • Um ihn auf einen anderen Computer zu übertragen, verwenden Sie „Export vault…“ und „Import vault…“ im Agentenfenster: eine Datei für alle Websites, verschlüsselt mit Ihrem Passwort (Argon2id und AES-256-GCM). Eine Seite kann keinen Export starten.

Verfügbare Fähigkeit

Diese Version kann HTTP-Anfragen, WebSocket-Verbindungen, Server-Sent Events, den Tresor für Arbeitsbereiche und Geheimnisse, ICMP-Pfadverfolgung, DNS-Abfrage, TCP-Prüfung, TLS-Prüfung, WHOIS, ASN-Suche, den Portscanner und den Netzwerkscanner koppeln. Jedes Werkzeug fordert eine eigene benannte Fähigkeit an; die Kopplung gewährt zukünftige Fähigkeiten nicht automatisch, daher kann ein Werkzeug nach einem Update eine erneute Kopplung verlangen.

Download prüfen

Der Installer ist nicht digital signiert; Windows SmartScreen kann warnen oder ihn blockieren. Deaktivieren Sie den Windows-Schutz nicht. Vergleichen Sie den SHA-256-Wert der Datei mit dem obigen Wert, um die Integrität zu prüfen; ein passender Hash ersetzt keine Herausgebersignatur.
