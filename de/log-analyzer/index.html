LOG

Analysator für große Logs

Sehr große Serilog-, .NET-, Nginx-, JSON-Lines- und Text-Logs lokal streamen, filtern, visualisieren und exportieren.

Eingaben und Dateien bleiben im Browser

Logdatei hier ablegen

Logdatei hier ablegen

.log, .txt, .jsonl oder .ndjson. Die Datei verbleibt auf diesem Gerät.

Ein lokaler Web Worker durchsucht die Datei in begrenzten Blöcken. Eingabeinhalte und Filter werden weder hochgeladen noch gespeichert.

Importeinstellungen

Sicherheitslimits: 2 MiB pro Zeile, 100 Millionen Datensätze, 512 Zeichen pro Filter und Aggregatbezeichnung, 2,000 unterschiedliche Aggregatwerte und 4,096 unterschiedliche Zeitstempelminuten.

      Der Analysator für große Logs untersucht Produktions-Logs vollständig in Ihrem Browser. Er unterstützt Serilog JSON und Compact Log Event Format, gewöhnlichen .NET-Text, Nginx-Zugriffs- und Fehlerlogs, allgemeines NDJSON sowie Klartext, ohne Betriebsdaten hochzuladen.
      Detaillierte Funktionalität
      Der Analysator liest in einem Web Worker jeweils einen begrenzten Block und behält nur Sparse-Dateioffsets sowie begrenzte Aggregatzähler bei. Er extrahiert Zeitstempel, Schweregrad, Quelle, Anfrage- oder Korrelations-IDs, gerenderte Nachrichten, Nachrichtenvorlagen und Ausnahmetypen. Filter durchsuchen die vollständige Quelle erneut, während die virtuelle Tabelle nur eine kleine sichtbare Seite anfordert. Fehlerhafte strukturierte Zeilen bleiben sichtbar und werden gezählt, statt stillschweigend zu verschwinden.
      


      Beim Export wird das vollständige gefilterte Ergebnis erneut durchsucht. Die ursprünglichen UTF-8-Zeilenbytes werden mit ihren LF-, CRLF- oder CR-Endzeichen gestreamt. Der gerenderte Serilog-Text @m wird angezeigt, während @mt der Gruppierungsschlüssel für die Anzahl der häufigsten Nachrichten bleibt. Weder Eingaben noch Ergebnisse werden in localStorage gespeichert.
      Praktische Beispiele
      Serilog CLEF: {"@t":"2026-10-17T10:01:00Z","@l":"Error","@mt":"Payment failed for {OrderId}","@m":"Payment failed for 17"} gruppiert wechselnde Bestell-IDs unter einer Vorlage.
      


      Nginx-Zugriff: Anfragen im Combined-Log-Format erhalten ihren Schweregrad anhand der HTTP-Statusklasse.
      


      Korrelationssuche: Geben Sie eine Anfrage-ID ein, um Ereignisse quellenübergreifend einzugrenzen, und exportieren Sie anschließend jede passende Originalzeile.
      So verwenden Sie dieses Tool
      1. 1
        Format auswählen
        Verwenden Sie für gewöhnliche Dateien die automatische Erkennung oder wählen Sie ausdrücklich Serilog/.NET, Nginx, JSON Lines oder Text aus.
      2. 2
        Log öffnen
        Legen Sie eine lokale Datei ab und verfolgen Sie exakte Bytes, verstrichene Zeit und Durchsatz. Beim Abbrechen wird die unvollständige Worker-Sitzung gelöscht.
      3. 3
        Filtern und prüfen
        Kombinieren Sie inklusive Zeitgrenzen, Schweregrad, Quelle, Anfrage-/Korrelations-ID und Freitextsuche. Durchsuchen Sie die virtuelle Ergebnistabelle und wählen Sie eine Zeile aus, um den Rohtext anzuzeigen.
      4. 4
        Exportieren
        Laden Sie das vollständige gefilterte Ergebnis herunter. Der Worker durchsucht die Originaldatei erneut und streamt alle Treffer mit Backpressure.
      Tipps und Best Practices
        

      • Wählen Sie ausdrücklich die Voreinstellung JSON Lines, wenn beliebige JSON-Objekte nicht als Serilog interpretiert werden sollen.
        • 

      • Die Anzahl fehlerhafter Zeilen bezieht sich auf Zeilen, die nicht der ausgewählten strukturierten Voreinstellung entsprechen; allgemeiner Text akzeptiert jede gültige UTF-8-Zeile.
        • 

      • Wenn kein Schweregrad ausgewählt ist, werden keine Treffer angezeigt. Zeitgrenzen schließen Datensätze ohne erfolgreich gelesenen Zeitstempel aus.
        • 

      • Aggregatbezeichnungen und Zeitstempelminuten sind zur Speichersicherheit in ihrer Kardinalität begrenzt; Gesamtzahlen, Filterung, Seitennavigation und Export bleiben jedoch exakt.
        • 

      • Die Freitextsuche durchsucht die exakte dekodierte Rohzeile ohne Berücksichtigung der Groß-/Kleinschreibung.
        •

      Strukturierte Daten
      • {}JSON FormatterJSON im Browser formatieren, minifizieren und validieren: 2/4 Leerzeichen oder Tab, rekursive Schlüsselsortierung, exakte große Zahlen, .json-Dateien.
