Agent einrichten

Laden Sie den lokalen Agenten herunter, starten Sie ihn und kehren Sie zu dieser Seite zurück.

Über den Agenten und Download
  1. Starten Sie MyDevTools Agent. Um eine private oder Loopback-Adresse zu scannen, aktivieren Sie „Allow local network and this PC as targets“ im Agentenfenster.
  2. Kopieren Sie den Kopplungscode aus dem Agentenfenster.
  3. Fügen Sie den Code unten ein. Wenn der Browser nach lokalem Netzwerkzugriff fragt, erlauben Sie ihn für diese Verbindung.

Der Browser sendet Host, Portliste und Zeitlimit nur an den Agenten auf 127.0.0.1. Der Agent öffnet TCP-Verbindungen zu diesem einen Host und schließt jede sofort wieder. Er sendet keine Daten und liest keine Banner. Der Scan geht nicht an einen MyDevTools-Server. Dieser Browser merkt sich die Vorauswahl, Ihre Portliste, das Zeitlimit und die Anzahl paralleler Verbindungen. Host und Ergebnisse speichert er nicht.

Hostrechner
Ein Hostname oder eine IP-Adresse. Private und Loopback-Adressen brauchen „Allow local network and this PC as targets“ im Agentenfenster.
Zeitlimit pro Port
Wie lange auf jede Verbindung gewartet wird, von 200 bis 5000 Millisekunden. Ein Port, der nicht rechtzeitig antwortet, gilt als gefiltert.
Parallel
Wie viele Verbindungen gleichzeitig offen sind, von 1 bis 64. Verringern Sie den Wert bei einer langsamen Leitung oder einem Host, der Verbindungen begrenzt.
Portliste
Ports und Bereiche, durch Kommas oder Leerzeichen getrennt, zum Beispiel 22, 80, 8000-8100. Höchstens 1024 einzelne Bereiche.

Der Portscanner bittet den lokalen Agenten auf Ihrem Windows-Computer, TCP-Verbindungen zu einem Host zu versuchen, und meldet jeden Port als offen, geschlossen oder gefiltert. Wählen Sie 70 gängige Dienstports, den bekannten Bereich 1–1024, alle 65535 Ports oder Ihre eigene Liste aus Ports und Bereichen. Die Ergebnisse erscheinen laufend während des Scans, und Anhalten beendet ihn im Agenten. Das Recht ist port.scan, getrennt von tcp.connect und den anderen Netzwerkwerkzeugen.

Detaillierte Funktionalität

Das ist ein Connect-Scan: Der Agent schließt den TCP-Handshake ab und schließt den Socket sofort, ohne Daten zu senden oder ein Banner zu lesen. Eine abgewiesene Verbindung ist geschlossen, keine Antwort innerhalb des Zeitlimits ist gefiltert, und ohne Route ist nicht erreichbar. Bis zu 64 Verbindungen laufen gleichzeitig, und jeder Port wartet 200 bis 5000 Millisekunden. Bei bis zu 1024 Ports wird jeder Port aufgeführt; bei einem größeren Scan nur die offenen, mit Zählern für den Rest. Der Agent wendet dieselben Zielregeln an wie seine anderen Werkzeuge: private und Loopback-Adressen nur, wenn „Allow local network and this PC as targets“ im Agentenfenster aktiviert ist, Metadata-, Link-local- und Multicast-Adressen nie, und sein eigener Lauschport wird als gesperrt angezeigt. Höchstens zwei Scans laufen zugleich. Scannen Sie nur Hosts, die Ihnen gehören oder die Sie testen dürfen.

Praktische Beispiele

  • 127.0.0.1 mit der gängigen Liste zeigt, was auf Ihrem eigenen PC lauscht (aktivieren Sie zuerst den lokalen Netzwerkzugriff im Agentenfenster).
  • 192.168.1.1 mit 1–1024 listet die Dienste auf, die Ihr Router anbietet.
  • example.com mit 80, 443, 8080-8090 prüft einen Webserver und seine Alternativports.

So verwenden Sie dieses Tool

  1. 1

    Lokalen Agenten starten

    Laden Sie den Agenten herunter, starten Sie ihn und kopieren Sie den Kopplungscode.

  2. 2

    Portscanner koppeln

    Fügen Sie den Code ein und verbinden Sie. Die Seite verlangt port.scan und behält Rechte, die dieser Browser schon hat.

  3. 3

    Host und Ports wählen

    Geben Sie einen Host ein, wählen Sie eine Port-Vorauswahl oder tippen Sie Ihre eigene Liste, und legen Sie Zeitlimit und Parallelität fest.

  4. 4

    Scannen und Ergebnisse lesen

    Drücken Sie Scannen. Offene Ports erscheinen, sobald sie gefunden werden, mit ihrem üblichen Dienst. Drücken Sie Anhalten, um früher aufzuhören, und kopieren Sie die Ergebnisse als Text.

Tipps und Best Practices

  • Gefiltert bedeutet meist, dass eine Firewall die Pakete verwirft. Ein längeres Zeitlimit unterscheidet einen langsamen Host von einem gefilterten Port.
  • Ein vollständiger Scan 1–65535 mit 1000 ms Zeitlimit kann bei einem filternden Host mehrere Minuten dauern; senken Sie das Zeitlimit für einen Host im eigenen Netzwerk.
  • Der übliche Dienst ist die gängige Zuordnung des Ports, nicht das, was auf dem Host tatsächlich läuft.
  • Der veröffentlichte Windows-Download kann älter sein als diese Seite. Der Scanner braucht einen Agenten, der port.scan meldet.
