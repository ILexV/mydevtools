TCP-Verbindung

Öffnet eine TCP-Verbindung zu einem Host und einem Port und zeigt, wie lange der Handshake dauerte.

Die Prüfung läuft auf Ihrem Computer über den lokalen Agenten. Host, Port und Ergebnis bleiben auf dieser Seite.

Agent einrichten

Laden Sie den lokalen Agenten herunter, starten Sie ihn und kehren Sie zu dieser Seite zurück.

Über den Agenten und Download
  1. Starten Sie MyDevTools Agent. Für eine private oder Loopback-Adresse aktivieren Sie „Allow local network and this PC as targets“ im Agentenfenster.
  2. Kopieren Sie den Kopplungscode aus dem Agentenfenster.
  3. Fügen Sie den Code unten ein. Wenn der Browser nach lokalem Netzwerkzugriff fragt, erlauben Sie ihn für diese Verbindung.

Der Browser sendet Host, Port und Zeitlimit nur an den Agenten auf 127.0.0.1. Der Agent öffnet eine TCP-Verbindung und schließt sie wieder. Er sendet keine Daten und probiert keinen Portbereich. Die Prüfung geht nicht an einen MyDevTools-Server. Dieser Browser merkt sich das Zeitlimit. Host, Port und Ergebnis speichert er nicht.

Hostrechner
Ein Hostname oder eine IP-Adresse. Private und Loopback-Adressen brauchen „Allow local network and this PC as targets“ im Agentenfenster. Ein Portbereich wird abgelehnt.
TCP-Port
Ein Port von 1 bis 65535.
Zeitlimit
Wie lange auf diese eine Verbindung gewartet wird, von 200 bis 10000 Millisekunden.

Die TCP-Verbindung bittet den lokalen Agenten, eine Verbindung zu dem eingegebenen Host und Port zu öffnen und sie wieder zu schließen. Die Seite zeigt, ob sie offen, abgewiesen, zeitlich abgelaufen oder ohne Route war, und wie viele Millisekunden das dauerte. Das Recht tcp.connect ist getrennt von http.request, icmp.trace und dns.lookup.

Detaillierte Funktionalität

Der Agent nimmt die erste Adresse des Namens und wendet dieselben Zielregeln an wie der HTTP-Client. Private und Loopback-Adressen gelten nur, wenn „Allow local network and this PC as targets“ im Agentenfenster aktiviert ist (oder der Agent mit --allow-private gestartet wurde). Metadata-, Link-local- und Multicast-Adressen bleiben gesperrt, ebenso der eigene Lauschport des Agenten. Die Prüfung ist nur ein Handshake: es werden keine Bytes gesendet und kein Banner gelesen. Ein Zahlenbereich wie 80-443 wird abgelehnt. Höchstens zwei Prüfungen laufen zugleich. Das Zeitlimit bleibt in diesem Browser. Host, Port und Ergebnis nicht.

Praktische Beispiele

  • example.com Port 443 zeigt einen offenen Handshake und die Zeit.
  • 127.0.0.1 auf einem Port ohne Dienst zeigt eine Abweisung.
  • 80-443 im Hostfeld wird abgelehnt. Das ist kein Scan.

So verwenden Sie dieses Tool

  1. 1

    Lokalen Agenten starten

    Laden Sie den Agenten herunter, starten Sie ihn und kopieren Sie den Kopplungscode.

  2. 2

    TCP-Verbindung koppeln

    Fügen Sie den Code ein und verbinden Sie. Die Seite verlangt tcp.connect und behält Rechte, die dieser Browser schon hat.

  3. 3

    Einen Port prüfen

    Geben Sie einen Host und einen Port ein, setzen Sie das Zeitlimit und drücken Sie Prüfen.

  4. 4

    Ergebnis lesen

    Die Seite zeigt Status, Adresse und Zeit. Kopieren Sie es als Text. Ein Neuladen löscht es.

Tipps und Best Practices

  • Eine Abweisung und ein Zeitlimit sind Ergebnisse. Die Prüfung selbst ist dabei nicht gescheitert.
  • Eine Anfrage ist ein Host und ein Port. Ein Bereich gehört nicht in dieses Werkzeug.
  • Höchstens zwei Prüfungen laufen zugleich.
  • Der veröffentlichte Windows-Download kann älter sein als diese Seite. Nötig ist ein Agent, der tcp.connect meldet.
