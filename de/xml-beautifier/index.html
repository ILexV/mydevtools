XML-Formatierer

XML im Browser formatieren oder minifizieren, mit 2/4 Leerzeichen oder Tab; Kommentare, CDATA und Processing Instructions bleiben, Parse-Fehler werden gemeldet.

Eingaben und Dateien bleiben im Browser

XML-Eingabe

Fügen Sie XML ein oder ziehen Sie eine .xml-Datei hierher, um sie einzurücken oder in eine Zeile zu komprimieren.

Im Editor rückt Tab ein. Drücken Sie Esc und dann Tab, um den Editor zu verlassen.

Verwandeln Sie ein einzeiliges oder unordentlich eingerücktes XML-Dokument in einen sauber eingerückten Baum oder minifizieren Sie es für die Übertragung. Die Eingabe liest der XML-Parser des Browsers selbst, daher wird fehlerhaftes Markup mit Zeile und Spalte gemeldet, statt stillschweigend „repariert“ zu werden.

Detaillierte Funktionalität

Formatieren setzt jedes Element in eine eigene Zeile, eingerückt mit 2 Leerzeichen, 4 Leerzeichen oder einem Tab; ein Element, das nur Text enthält, bleibt einzeilig (<to>Ann</to>), und leere Elemente werden als <b/> geschrieben. Kompaktmodus (minifizieren) entfernt den Leerraum zwischen den Tags. XML-Deklaration, Kommentare, <![CDATA[…]]>-Abschnitte, Processing Instructions wie <?xml-stylesheet …?> und der DOCTYPE bleiben erhalten, und Sonderzeichen werden bei der Ausgabe wieder maskiert (&amp;, &lt;, &quot;).

Geparst wird striktes XML, kein HTML: Ein nicht geschlossenes oder nicht passendes Tag, ein fehlendes Anführungszeichen oder eine undefinierte Entität stoppt die Formatierung mit der Meldung des Parsers, z. B. error on line 1 at column 11: Opening and ending tag mismatch in Chrome. Die interne Teilmenge eines DOCTYPE (<!DOCTYPE x [ … ]>) bleibt nicht erhalten, weil der Browser sie nicht bereitstellt.

Öffnen Sie eine .xml-Datei oder ziehen Sie sie in den Editor, kopieren Sie dann das Ergebnis oder speichern Sie es als formatted.xml. Der Editor hebt Tags, Attribute und Kommentare hervor, klappt Elemente ein und bleibt auch bei großen Dateien schnell. Einrückung und Kompaktmodus werden in diesem Browser gespeichert; das XML selbst wird nie gespeichert oder irgendwohin gesendet.

Praktische Beispiele

Ein einzeiliges Dokument einrücken: <note><to>Ann</to><from>Bob</from></note> wird mit 2 Leerzeichen zu vier Zeilen – <note>, <to>Ann</to>, <from>Bob</from>, </note>.

Kommentare und CDATA behalten: In <?xml version="1.0"?><!-- cfg --><config><db host="localhost" port="5432"/><![CDATA[a<b]]></config> landen Deklaration und Kommentar in eigenen Zeilen, und <![CDATA[a<b]]> bleibt innerhalb von <config> unverändert.

Minifizieren: Im Kompaktmodus wird ein eingerücktes <root> mit <a>1</a> und <b/> zu <root><a>1</a><b/></root>.

Ein defektes Tag erkennen: <a><b></a> wird mit „Opening and ending tag mismatch: b line 1 and a“ abgelehnt.

So verwenden Sie dieses Tool

  1. 1

    XML hinzufügen

    Fügen Sie es in den Editor XML-Eingabe ein, klicken Sie auf Öffnen, um eine .xml-Datei zu laden, oder ziehen Sie die Datei in den Editor.

  2. 2

    Ausgabestil wählen

    Wählen Sie die Einrückungsgröße (2 Leerzeichen, 4 Leerzeichen oder Tab) oder aktivieren Sie Kompaktmodus (minifizieren).

  3. 3

    Formatieren

    Klicken Sie auf Formatieren oder drücken Sie Strg+Enter (Cmd+Enter unter macOS). Parse-Fehler erscheinen über dem Editor.

  4. 4

    Ergebnis verwenden

    Klicken Sie auf Kopieren oder auf Speichern, um das Ergebnis als formatted.xml herunterzuladen.

Tipps und Best Practices

  • Eine Änderung von Einrückung oder Kompaktmodus formatiert das aktuelle Dokument sofort neu.
  • Gemischter Inhalt wird aufgeteilt und getrimmt: <p>Hello <b>world</b>!</p> wird zu separaten Zeilen für Hello, <b>world</b> und !. Formatieren Sie keine Dokumente neu, in denen Leerzeichen im Text eine Rolle spielen.
  • HTML-Gewohnheiten machen XML kaputt: <br> ohne Schrägstrich oder &nbsp; ohne DTD sind hier Fehler.
  • Klicken Sie auf die Pfeile neben den Zeilennummern, um Elemente einzuklappen; Strg/Cmd+F durchsucht das ganze Dokument.
  • Im Editor fügt Tab eine Einrückung ein; drücken Sie Esc und dann Tab, um den Fokus zu verlassen.
  • Kein Upload: Das Dokument wird in der Seite verarbeitet, die nach dem ersten Besuch auch offline funktioniert.
