# Этап 2 — визуальное направление, moodboard, anti-references

## Характер бренда

MyDevTools — **локальная верстак-библиотека** (workbench), не сервис и не SaaS.
Три факта, которые дизайн обязан транслировать в первые 5 секунд:

1. **39 инструментов, 0 серверов.** Всё считается в браузере (WASM/JS), файлы не покидают устройство.
2. **10 языков** — это не английский сайт с переводом, а мультиязычный продукт.
3. **Утилитарность.** Пользователь пришёл с задачей («раскодировать JWT», «посчитать хэш»), а не «поизучать продукт». Скорость пути «открыл → вставил → получил результат» — главная метрика UX.

Аудитория: разработчики, DevOps, QA, аналитики. Люди, живущие в IDE/терминале, ценящие плотность информации, клавиатуру и предсказуемость.

Ключевые эмоции: **точность, спокойствие, контроль**. Никакого маркетингового восторга, градиентных фейерверков и «AI-powered» шума.

Отличие от типового dashboard: нет bento-сетки фич, нет стеклянных карточек, нет иллюстраций людей с ноутбуками. Интерфейс — это каталог рабочих инструментов, а не витрина.

## Moodboard (референсы и что берём)

| Источник | Что берём | Что НЕ берём |
|---|---|---|
| **Верстак/pegboard** (физика мастерской) | Идея: каждый инструмент на своём месте, подписан, доступен одним движением | Скевоморфизм, текстуры дерева/металла |
| **Техническая документация / datasheet** | Плотность, табличная точность, микро-подписи, нумерация разделов | Скучная безликость gov-сайтов |
| **IDE/терминал** (VS Code, iTerm, lazygit) | Моноширинные акценты, статус-строки, клавиатурность, тёмная тема как первоклассная | Скевоморфный «хакерский» зелёный-on-black |
| **Швейцарская типографика** (Vignelli, Müller-Brockmann) | Жёсткая сетка, нумерация, один сигнальный цвет, дисциплина whitespace | Холодная неприступность галерейного дизайна |
| **Инженерный чертёж / blueprint** | Волосяные линии, точечная сетка, метки-выноски, инверсия светлое↔чертёжное | Декоративный «техно»-шум без смысла |
| **linear.app, raycast.com** | Дисциплина motion (150–250 мс), сдержанная палитра | Их hero-градиенты и glow — это именно «типовой SaaS» |
| **godly.website / surfacetension patterns** | Калибр «узнаваемости»: один сильный мотив вместо десяти слабых | — |

## Anti-references (запрещено без явной причины)

- **Bento-сетка** одинаковых прямоугольников с фичами — визитка SaaS 2023–2025.
- **Glassmorphism**: blur + полупрозрачность как самоцель; blur допустим только для overlay/служебных слоёв.
- **Случайные градиенты**, mesh-градиенты, aurora-фоны, glow-тени вокруг карточек.
- **Фиолетово-синий «стартапный» акцент** (#6366f1 и соседи) — самый заезженный спектр.
- **Иллюстрации** людей, ракет, абстрактных 3D-фигур; stock anything.
- **Border-radius roulette**: карточки 16px, кнопки 999px, инпуты 8px без системы.
- **Тени как декор**: elevation должен означать слой (overlay > surface), а не «красиво».
- **Анимация ради анимации**: parallax-hero, бесконечные floating-элементы.
- **Эмодзи в UI** как замена иконок.
- **«AI»-словарь** в microcopy.

## Три концепции (см. `concepts/*.html`, скриншоты в чек-листе TODO)

- **A «Workbench Terminal»** — тёмный-first кокпит разработчика: моноширинные метки, статус-строки, один янтарный сигнальный цвет, prompt-мотив `>`.
- **B «Blueprint»** — светлый инженерный лист: тёплая бумага, волосяные линии, точечная сетка, метки `FIG. 02`; тёмная тема = классический чертёжный navy/cyan.
- **C «Index»** — швейцарская типографика: чёрный/белый + сигнальный красный, нумерованный каталог 01–39, нулевые радиусы, дисплейный гротеск.

Общее для всех трёх: реальные названия инструментов, один акцентный цвет на экран, моноширинный шрифт для данных (хэши, JWT, IP, даты), светлая+тёмная темы как равноправные.
