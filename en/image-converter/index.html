Convert an image between PNG, JPEG, WebP, GIF, BMP, ICO, TIFF and TGA in the browser — for favicons, legacy formats or switching a screenshot to WebP. The file is processed locally and never uploaded.

Detailed Functionality

Any of the eight formats can be the input; the output is chosen in Target Format. The quality slider appears only for JPEG and WebP (default 90); the other formats ignore it. ICO images larger than 256 px are scaled down to fit 256×256 with the proportions kept, JPEG gets a white background where the source was transparent, and 16-bit sources are reduced to 8 bits per channel.

WebP is encoded lossy by the browser at the chosen quality; where the browser cannot do that, a lossless WebP is produced and a note explains that quality was not applied. The EXIF orientation is applied to the pixels and metadata is not copied. Only the first frame of an animated GIF is converted.

Browsers cannot display TIFF and TGA, so for those results only the size is shown — the file still downloads. Conversion runs in a Web Worker with Rust/WebAssembly and can be cancelled.

Practical Examples

Logo to favicon: a 1024×1024 PNG logo converted to ICO becomes a 256×256 icon of 10.24 KB, saved as logo.ico.

Transparent PNG to JPEG: transparent areas come out white instead of black.

JPEG to WebP: a 1920×1280 photo of 476.38 KB at quality 90 gives 433.54 KB; lower the quality for bigger savings.

Game texture: a 640×480 texture.tga converted to PNG opens anywhere as texture.png.

How to Use This Tool

  1. 1

    Choose an image

    Click Choose file or drop a PNG, JPEG, WebP, GIF, BMP, ICO, TIFF or TGA file onto the zone.

  2. 2

    Pick the target format

    Select the format in Target Format. For JPEG and WebP, set Quality (JPEG, WebP).

  3. 3

    Convert

    Click Convert. A long job can be stopped with Cancel.

  4. 4

    Download

    Check Output Size: and the preview, then click Download to save <name>.<ext>.

Tips and Best Practices

  • Use PNG for screenshots and text, JPEG or WebP for photos.
  • For a favicon start from a square image of at least 256×256 px; larger images are scaled down to 256 px.
  • Converting JPEG to PNG does not bring back lost detail — it only makes the file bigger.
  • TIFF and TGA results have no preview in the browser, but the downloaded file is complete.
  • Animated GIFs lose their animation: only the first frame is kept.
