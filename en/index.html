Why Choose MyDevTools?

MyDevTools is a free collection of browser-based developer utilities: formatters and validators for JSON, XML and YAML, Base64, Hex and URL encoders, hash and HMAC calculators, JWT and X.509 tools, a regex tester, image and PDF utilities, and generators for UUIDs, passwords and QR codes. There is nothing to install and no account to create.

Privacy comes from the architecture: the site is a set of static pages, and every tool processes your input inside the browser. Compute-heavy tools such as hashing, encryption, image, PDF and QR processing run in WebAssembly modules compiled from Rust; lighter ones, like the JSON formatter or the text diff, are plain JavaScript. The passwords, keys and files you work with are never uploaded.

  • Privacy First

    Your input is processed in the browser and is never sent to a server.

  • WebAssembly Where It Matters

    Hashing, encryption, image and PDF processing run in Rust-compiled WebAssembly; simpler tools are lightweight JavaScript.

  • Works Offline

    Once a page has been opened, it keeps working without a connection. Install the PWA for quick access.

  • Multilingual

    The interface and tool guides are available in 10 languages.

  • Completely Free

    All tools are free. No hidden payments or subscriptions.

  • Your Own Toolset

    Star the tools you use most. Favorites and recently used tools are kept in your browser.
