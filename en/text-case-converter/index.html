Convert a variable name, a heading or a whole paragraph between nine letter cases with one click: camelCase, snake_case, kebab-case, Title Case, Sentence case, UPPER, lower, alternating and inverse. Useful when moving identifiers between JavaScript, Python, CSS and SQL naming conventions.

Detailed Functionality

The identifier-style conversions understand existing word boundaries: spaces, hyphens and underscores separate words, and so do lowercase→uppercase transitions, letter↔digit transitions and acronyms. getHTTPResponse therefore splits into get, HTTP, Response, and XMLHttpRequest2 into XML, Http, Request, 2. Runs of separators collapse into one, leading and trailing separators are trimmed, and other punctuation stays attached to its word.

Line breaks and tabs are kept, so a list of names converts line by line. Sentence case lowercases everything and capitalizes the first letter after ., ! or ?. Inverse Case swaps the case of every letter and leaves everything else untouched; Alternating Case alternates lower and upper case letter by letter. Cyrillic, Greek, accented Latin and other cased alphabets work; Chinese, Japanese or Hindi have no letter case, so only separators change.

The conversion runs in the page's JavaScript — the text is not sent anywhere. The result replaces the text in the same field, so several conversions can be applied in a row.

Practical Examples

JavaScript to Python: getHTTPResponse code with Snake Case becomes get_http_response_code.

CSS property to JavaScript: background-color with Camel Case becomes backgroundColor.

Acronym and digit: XMLHttpRequest2 with Kebab Case becomes xml-http-request-2.

Fixing capitalization: hello world. how are you? with Sentence case becomes Hello world. How are you?.

Tips and Best Practices

  • UPPER CASE, lower case and Title Case also treat _ and - as word separators and replace them with spaces: user_id becomes USER ID. To get USER_ID, apply Inverse Case to the all-lowercase user_id.
  • Sentence case lowercases proper nouns and acronyms too (HTTP server becomes Http server) — fix those by hand.
  • Title Case capitalizes every word, including short ones: the lord of the rings becomes The Lord Of The Rings; it does not follow style-guide exceptions.
  • A capital letter inside a word starts a new word: iPhone with Snake Case becomes i_phone.
  • The conversion overwrites the field, so keep the original elsewhere if you want to compare variants.
