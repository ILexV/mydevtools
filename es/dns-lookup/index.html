Configurar el agente

Descargue y arranque el agente local, luego vuelva a esta página.

Sobre el agente y descarga
  1. Arranque MyDevTools Agent. Usa el resolver DNS ya configurado en este equipo.
  2. Copie el código de emparejamiento de la ventana del agente.
  3. Pegue el código abajo. Si el navegador pide acceso a la red local, permítalo para esta conexión.

El navegador envía el nombre y el tipo de registro solo al agente en 127.0.0.1. El agente pregunta al resolver DNS de este equipo. La consulta no va a un servidor de MyDevTools ni usa un DNS-over-HTTPS público. Este navegador recuerda el tipo de registro elegido. No guarda el nombre, la respuesta ni el código.

Nombre
Un nombre de host o, si el tipo es PTR, una dirección IP. Los nombres internacionales van en punycode (xn--). El agente pregunta al resolver de este equipo, no a un DoH público.
Tipo
Un tipo de registro. PTR invierte una dirección IP. La lista de búsqueda de este equipo sigue aplicándose.

La consulta DNS pregunta al resolver configurado en su equipo por un nombre y un tipo de registro. El navegador no envía la consulta. El agente local concede dns.lookup aparte de http.request e icmp.trace.

Funcionalidad detallada

Los tipos son A, AAAA, CNAME, MX, NS, TXT, SOA y PTR. Una dirección IP solo vale para PTR y el agente la invierte a in-addr.arpa o ip6.arpa. La sección de respuesta se muestra tal como llegó, incluido un CNAME junto a las direcciones. Un NOERROR vacío es «sin registros» y NXDOMAIN significa que el nombre no está en DNS. La consulta usa el resolver del sistema, así que el DNS dividido y la lista de búsqueda del equipo siguen vigentes. No va a un servidor de MyDevTools ni a un DNS-over-HTTPS público. El tipo elegido permanece en este navegador. El nombre y los registros, no.

Ejemplos prácticos

  • example.com de tipo A muestra las direcciones IPv4 del resolver de este equipo.
  • example.com de tipo MX muestra los servidores de correo y su preferencia.
  • 1.1.1.1 de tipo PTR pide el nombre inverso.

Cómo usar esta herramienta

  1. 1

    Arranque el agente local

    Descargue el agente, arránquelo y copie el código de emparejamiento.

  2. 2

    Empareje la consulta DNS

    Pegue el código y conecte. La página pide dns.lookup y conserva los permisos que este navegador ya tiene.

  3. 3

    Consulte un nombre

    Escriba un nombre de host, elija A, AAAA, CNAME, MX, NS, TXT, SOA o PTR y pulse Consultar. Para PTR, escriba una dirección IP.

  4. 4

    Lea la respuesta

    La tabla muestra nombre, tipo, TTL, preferencia MX y datos. Copie la respuesta como texto. Recargar la página la borra.

Consejos y mejores prácticas

  • Una consulta perdida o rechazada es un error. Una respuesta NOERROR vacía no lo es.
  • No se consulta el archivo hosts. Solo responde el resolver DNS.
  • Hay como máximo cuatro consultas a la vez. No es un barrido de la red ni de tipos.
  • La descarga publicada para Windows puede ser anterior a esta página. La consulta DNS necesita un agente que anuncie dns.lookup.
