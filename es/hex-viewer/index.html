El visor hexadecimal abre cualquier archivo local como un volcado hex virtual. Cada fila muestra 16 bytes en hex, ASCII y UTF-8. Solo se leen las filas en pantalla, así que un binario grande no se convierte en una página interminable.

Funcionalidad detallada

El archivo permanece en este dispositivo. Los primeros 512 bytes se comparan con una firma conocida (PNG, JPEG, GIF, WebP, PDF, ZIP, gzip, ELF, PE, MP3, MP4 y los demás tipos que el sitio ya reconoce). Si no hay firma, una prueba UTF-8 marca el archivo como texto o lo deja como binario desconocido.

La búsqueda acepta texto o hex (89 50 4e 47 o 0x89504e47). Lee de 1 MiB en 1 MiB, solapa el patrón para que una coincidencia pueda cruzar el límite de un trozo y se detiene a las 200 coincidencias. Puede cancelar. La entropía usa bloques de 4 KiB. Hasta 1 MiB se cubre entero; por encima se toman 256 muestras uniformes. El gráfico estima el azar, no guarda un histograma de cada byte de un archivo de varios gigabytes.

La exportación descarga un intervalo inclusivo como un corte del archivo original, hasta 256 MiB, sin una segunda copia de todo el archivo en la página. No se editan bytes ni se desensambla código.

Ejemplos prácticos

Firma PNG: un archivo que empieza por 89 50 4E 47 se etiqueta como PNG. Los primeros bytes aparecen sobre la tabla y la columna de desplazamiento empieza en 00000000.

Salto: escriba 0x20 o 32 y pulse Ir. La tabla virtual se desplaza hasta la fila que contiene ese byte.

Búsqueda de texto o hex: busque Hello como texto, o 48 65 6c 6c 6f como hex. Cada coincidencia es un desplazamiento en el que puede pulsar. En datos repetidos la búsqueda se detiene a las 200 coincidencias.

Exportar un intervalo: primer byte 0 y último 15 descarga esos 16 bytes. El nombre del archivo incluye el intervalo hex.

Cómo usar esta herramienta

  1. 1

    Abra un archivo local

    Suelte o elija cualquier archivo. Un archivo vacío se rechaza. La lectura de la cabecera comprueba los primeros bytes y muestra el tamaño, el tipo detectado y el número de filas.

  2. 2

    Recorra el volcado

    Desplace la tabla virtual o escriba un desplazamiento decimal o 0x. Cada fila tiene 16 bytes: hex, ASCII (un punto si el byte no es imprimible) y UTF-8 (un carácter partido es un punto).

  3. 3

    Busque o mida la entropía

    Busque texto o hex. Cancelar deja el archivo abierto. Mida la entropía para dibujar una barra por bloque de 4 KiB, o 256 muestras si el archivo supera 1 MiB. Pulse una barra para saltar allí.

  4. 4

    Exporte un intervalo

    Escriba el primer y el último byte, ambos incluidos. La descarga es un corte de como máximo 256 MiB. El resto del archivo no se copia.

Consejos y mejores prácticas

  • La tabla solo lee la ventana visible con cortes del archivo. Saltar cerca del final de un archivo grande no carga el medio.
  • Un patrón hex debe tener un número par de dígitos. Se ignoran espacios, dos puntos y guiones, y se admite un 0x inicial.
  • El solapamiento conserva una coincidencia que empieza en un trozo de 1 MiB y termina en el siguiente. No se lista dos veces.
  • La entropía de un bloque de bytes idénticos es 0. Una mezcla uniforme de los 256 valores es 8 bits/byte.
  • Más de 200 coincidencias detienen la exploración. Acote el patrón si necesita un hallazgo posterior.
  • Esta página no modifica bytes, no guarda un proyecto y no envía el archivo.

Codificación

  • B64Codificador / Decodificador Base64Codifica texto o archivos en Base64 y decodifícalos: alfabeto estándar o URL-safe, relleno, saltos cada 76 caracteres y vista previa de imágenes. En tu navegador.
  • B32Codificador / Decodificador Base32Codifica y decodifica Base32 con los alfabetos RFC 4648, Crockford o z-base-32, opciones de relleno y mayúsculas, para texto y archivos, en tu navegador.
  • B58Codificador / Decodificador Base58Codifica y decodifica Base58 con el alfabeto de Bitcoin, Flickr o Ripple para texto y archivos de hasta 1 MiB. En local, en tu navegador, sin subir nada.
  • 0xCodificador / Decodificador HexConvierte texto o archivos a hexadecimal y viceversa. Elige codificación y mayúsculas; decodifica hex con espacios, dos puntos, guiones o 0x. En tu navegador.
