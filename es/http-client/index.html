Cliente HTTP

Envía solicitudes HTTP desde Windows mediante un agente local, sin cuenta ni proxy de MyDevTools.

Las solicitudes van directamente de tu equipo Windows al destino

    Secretos

    Los valores se guardan en el almacén cifrado del agente y nunca vuelven a la página. Pon {{secret:name}} en la URL, un encabezado o el cuerpo: el agente lo sustituye solo para los hosts indicados y lo oculta en la respuesta.

      Entornos

      Usa {{nombre}} en la URL, parámetros, encabezados, cuerpo y autorización. El entorno activo prevalece sobre las variables de carpeta y estas sobre las globales. Para un valor de solo escritura, asigna {{secret:nombre}} a la variable.

      Ajustes del cliente

      Proxy

      El agente se conecta mediante un proxy HTTP: CONNECT para https y URL absolutas para http. La contraseña del proxy se guarda con el espacio de trabajo.

      Certificados de cliente (mTLS)

      El agente presenta un certificado a los hosts https de su lista cuando el servidor lo pide. La clave privada se guarda cifrada en el agente y nunca vuelve a la página. Usa archivos PEM con la clave sin cifrar; convierte antes un .pfx: openssl pkcs12 -in cert.pfx -out cert.pem -nodes

      Conecta un agente con almacén de secretos para añadir certificados de cliente.

          Variables

          Disponibles como {{nombre}} para todas las solicitudes de esta carpeta y sus subcarpetas; prevalece la carpeta más cercana.

          Scripts

          Se ejecutan para cada solicitud de esta carpeta y sus subcarpetas, antes de los scripts de la propia solicitud.

          Datos

          Las solicitudes se ejecutan una tras otra en el orden del árbol con sus scripts; se guardan las variables que cambian los scripts. Con un archivo de datos hay una iteración por fila, disponible como pm.iterationData y {{columna}}. Cerrar esta ventana detiene la ejecución.

                        Envía solicitudes HTTP y HTTPS sin crear una cuenta ni pasar credenciales de API por un servidor de MyDevTools. Un pequeño agente en Windows realiza la conexión y devuelve estado, tiempo, cabeceras y cuerpo.
                        Funcionalidad detallada
                        El navegador se empareja explícitamente con el agente en 127.0.0.1 mediante un código de un solo uso. El token de conexión se guarda en este navegador hasta 8 horas o hasta que se reinicie el agente; el código no se guarda. El token solo concede http.request. Las solicitudes van directamente al destino. Los destinos privados y LAN requieren activar «Allow local network and this PC as targets» en la ventana del agente (o --allow-private); las redirecciones están desactivadas por defecto y las cabeceras sensibles se eliminan al cambiar de origen. Los borradores, incluidas las URL, cabeceras y secretos, y los cuerpos se guardan automáticamente en este navegador para volver a abrirlos; las respuestas no se guardan. El token de conexión se guarda por separado hasta 8 horas o hasta que se reinicie el agente. Con un agente actual, los borradores los guarda cifrados el agente en el equipo en lugar del navegador.
                        Ejemplos prácticos
                        Usa GET para JSON, POST con Content-Type: application/json para una API o HEAD para metadatos. Añade Authorization: Bearer … solo si el destino lo necesita; se envía al destino, no a MyDevTools.
                        Cómo usar esta herramienta
                        1. 1
                          Instala e inicia el agente
                          Descarga el agente Windows x64 e inícialo.
                        2. 2
                          Empareja
                          Solicita un código en la ventana del agente, introdúcelo y pulsa Conectar.
                        3. 3
                          Prepara la solicitud
                          Elige método, URL HTTP o HTTPS, cabeceras y cuerpo UTF-8.
                        4. 4
                          Envía e inspecciona
                          Consulta estado, tiempo, URL final, cabeceras y vista de texto. Descarga cuerpos binarios byte a byte.
