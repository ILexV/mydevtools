Explorador de JSON / JSONL grandes

Abre, indexa, busca y exporta archivos JSON y JSONL grandes localmente, con tabla virtual, árbol diferido y números exactos.

Tus datos de entrada y archivos no salen del navegador

Archivo local

Suelta un archivo JSON, JSONL o NDJSON

El archivo permanece en este navegador. JSONL se lee incrementalmente; el JSON normal usa el límite de memoria configurado.

El JSON normal se carga hasta el límite elegido de 8–64 MiB. JSONL se transmite en bloques de 1 MiB, con 1–8 MiB por registro y profundidad máxima 256. Son límites de seguridad explícitos, no memoria ilimitada.

Los archivos, búsquedas y columnas derivadas no salen del dispositivo ni se guardan; solo se recuerdan el formato y los límites.

Procesando archivo

Registros

Elige un JSON o JSONL local para examinar su estructura y registros.

Buscar, filtrar y proyectar

Un JSON Pointer RFC 6901 por línea, hasta 100 campos. Una lista vacía conserva las columnas superiores automáticas. Escapa ~ como ~0 y / como ~1. El JSONL proyectado usa un objeto plano cuyas claves son los punteros exactos; un campo ausente se convierte en null.

Las columnas automáticas muestrean los primeros 10.000 registros y muestran hasta 100 campos superiores. No se añaden automáticamente nombres cuyo JSON Pointer codificado supere 256 caracteres ni metadatos de nombres que superen 16.384 caracteres. Ningún campo se elimina: usa un JSON Pointer exacto. La vista previa se limita a 512 caracteres; inspección y exportación usan valores completos.

Explora matrices JSON grandes y JSON delimitado por líneas sin subir datos privados. La herramienta crea un índice disperso local, representa solo una pequeña ventana de tabla virtual y carga cada registro o rama cuando se solicita.
Funcionalidad detallada
JSONL / NDJSON se decodifica como UTF-8 en bloques de 1 MiB. Admite BOM, CRLF y una línea final sin salto; un error indica línea física y columna. Solo conserva puntos de control dispersos y metadatos acotados, y vuelve a leer para ventanas lejanas, filtros y exportaciones.



JSON normal admite objetos, matrices y raíces escalares con un árbol diferido; una matriz raíz también se navega como registros. Un documento único requiere un límite explícito de 8–64 MiB y se analiza en un worker. La profundidad máxima es 256 y cada registro JSONL se limita a 1–8 MiB.



Los lexemas numéricos se conservan: 9007199254740993, 1.0 y exponentes no pasan por Number. El filtro recorre todo sin crear una matriz completa de coincidencias.
Ejemplos prácticos
Registros de API: abre .ndjson, busca timeout y filtra /service por billing; selecciona una fila para ver el original completo.



Campos anidados: proyecta /id y /user/name; /a~1b apunta a la clave a/b. CSV usa esos punteros como columnas y JSONL como claves.



IDs grandes: {"id":9007199254740993,"price":1.0} conserva ambas grafías al exportar.



Matriz grande: expande solo ramas necesarias y desplázate sin crear una fila DOM por elemento.
Cómo usar esta herramienta
  1. 1
    Elige formato y límites
    Selecciona detección automática, JSON o JSONL/NDJSON y configura los límites.
  2. 2
    Abre el archivo local
    Suéltalo o elígelo. El worker muestra bytes, tiempo, velocidad y ETA; cancelar descarta la sesión.
  3. 3
    Busca o proyecta
    Busca claves o valores, indica una ruta RFC 6901 y subcadena, o enumera punteros de proyección.
  4. 4
    Inspecciona y exporta
    Desplázate, abre el registro completo, expande el árbol o descarga todas las coincidencias en JSONL o CSV.
Consejos y mejores prácticas
    

  • Usa .jsonl o .ndjson para una detección fiable; elige explícitamente formatos ambiguos.
    • 

  • Las líneas JSONL vacías se omiten, pero los errores usan líneas físicas.
    • 

  • JSONL vacío es un resultado válido de cero registros; JSON normal vacío no es válido.
    • 

  • JSON Pointer usa /, ~0 para tilde y ~1 para barra.
    • 

  • La protección CSV para =, +, - y @ está activa por defecto.
    • 

  • La exportación incluye todas las filas filtradas y se detiene antes de 256 MiB.
    •
