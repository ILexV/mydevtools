LOG

Analizador de logs de gran tamaño

Procesa, filtra, representa y exporta localmente logs muy grandes de Serilog, .NET, Nginx, JSON Lines y texto.

Tus datos de entrada y archivos no salen del navegador

Suelta aquí un archivo de log

Suelta aquí un archivo de log

.log, .txt, .jsonl o .ndjson. El archivo permanece en este dispositivo.

Un Web Worker local analiza el archivo en bloques de tamaño limitado. El contenido y los filtros nunca se suben ni se almacenan.

Ajustes de importación

Límites de seguridad: 2 MiB por línea, 100 millones de registros, 512 caracteres por filtro y etiqueta agregada, 2,000 valores agregados distintos y 4,096 minutos de marca de tiempo distintos.

      El Analizador de logs de gran tamaño examina logs de producción íntegramente en tu navegador. Admite JSON de Serilog y Compact Log Event Format, texto .NET convencional, logs de acceso y errores de Nginx, NDJSON genérico y texto sin formato, sin subir datos operativos.
      Funcionalidad detallada
      El analizador lee un bloque de tamaño limitado cada vez mediante un Web Worker y solo conserva posiciones dispersas del archivo y contadores agregados limitados. Extrae marcas de tiempo, gravedad, origen, IDs de solicitud o correlación, mensajes renderizados, plantillas de mensajes y tipos de excepción. Los filtros vuelven a analizar el origen completo, mientras que la tabla virtual solicita únicamente una pequeña página visible. Las líneas estructuradas con formato incorrecto permanecen visibles y se contabilizan en lugar de desaparecer sin aviso.
      


      Las exportaciones vuelven a analizar el resultado filtrado completo y transmiten los bytes UTF-8 originales de cada línea con sus terminadores LF, CRLF o CR. Se muestra el texto renderizado de Serilog en @m, mientras que @mt sigue siendo la clave de agrupación para los recuentos de mensajes principales. Ninguna entrada ni resultado se almacena en localStorage.
      Ejemplos prácticos
      Serilog CLEF: {"@t":"2026-10-17T10:01:00Z","@l":"Error","@mt":"El pago falló para {OrderId}","@m":"El pago falló para 17"} agrupa los IDs de pedido variables bajo una sola plantilla.
      


      Acceso de Nginx: a las solicitudes en formato combined log se les asigna una gravedad según el grupo del código de estado HTTP.
      


      Búsqueda por correlación: introduce un ID de solicitud para aislar eventos entre distintos orígenes y exporta después cada línea original coincidente.
      Cómo usar esta herramienta
      1. 1
        Elige un formato
        Usa la detección automática para archivos normales o selecciona explícitamente Serilog/.NET, Nginx, JSON Lines o texto.
      2. 2
        Abre el log
        Suelta un archivo local y consulta los bytes exactos, el tiempo transcurrido y la velocidad de procesamiento. Cancelar destruye la sesión parcial del trabajador.
      3. 3
        Filtra e inspecciona
        Combina límites de tiempo inclusivos, gravedad, origen, ID de solicitud/correlación y búsqueda de texto libre. Explora la tabla virtual de resultados y selecciona una fila para ver el texto original.
      4. 4
        Exporta
        Descarga el resultado filtrado completo. El trabajador vuelve a analizar el archivo original y transmite todas las coincidencias con contrapresión.
      Consejos y mejores prácticas
        

      • Selecciona el preajuste explícito JSON Lines cuando los objetos JSON arbitrarios no deban interpretarse como Serilog.
        • 

      • Los recuentos de formato incorrecto se refieren a líneas que no coinciden con el preajuste estructurado elegido; el texto genérico acepta todas las líneas UTF-8 válidas.
        • 

      • Una selección de gravedad vacía no produce coincidencias. Los límites de tiempo excluyen los registros sin una marca de tiempo interpretada.
        • 

      • La cardinalidad de las etiquetas agregadas y los minutos de marca de tiempo está limitada para proteger la memoria, pero los recuentos totales, el filtrado, la paginación y la exportación siguen siendo exactos.
        • 

      • La búsqueda de texto libre coincide con la línea original decodificada exacta y no distingue entre mayúsculas y minúsculas.
        •
