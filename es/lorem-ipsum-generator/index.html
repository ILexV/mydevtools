Genera texto de relleno Lorem Ipsum para maquetas, plantillas y pruebas de interfaz: de 1 a 1000 párrafos, frases o palabras, empezando si quieres por el clásico «Lorem ipsum dolor sit amet…», en texto plano, HTML o Markdown.

Funcionalidad detallada

El texto se arma con una lista de unas 160 palabras latinas. Una frase tiene de 5 a 15 palabras, empieza con mayúscula y termina en punto; un párrafo tiene de 3 a 7 frases. En modo palabras obtienes exactamente las que pides, útil para probar recortes y límites de campos. Con la opción clásica, el resultado comienza con la frase canónica «Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.»

Los párrafos se separan con una línea en blanco, que también es Markdown válido. En formato HTML cada párrafo puede envolverse en <p>…</p>; la opción solo está activa para párrafos en HTML. El texto se regenera con cada cambio y los contadores de palabras y caracteres muestran el tamaño del resultado, etiquetas incluidas.

La generación es JavaScript en la página y el texto es aleatorio cada vez, así que dos ejecuciones nunca coinciden. Puedes copiar el resultado o descargarlo como lorem-ipsum.txt. No se envía nada a ningún servidor.

Ejemplos prácticos

Número exacto de palabras: Palabras, cantidad 5, inicio clásico activado → lorem ipsum dolor sit amet.

HTML para una plantilla: Párrafos, cantidad 3, formato HTML con <p> → tres bloques <p>…</p> separados por líneas en blanco, listos para pegar.

Texto corto de interfaz: Oraciones, cantidad 2, inicio clásico activado → la frase canónica «Lorem ipsum dolor sit amet…» seguida de una frase aleatoria de 5 a 15 palabras.

Prueba de diseño con mucho texto: Párrafos, cantidad 50, genera varios miles de palabras para comprobar el desplazamiento y el contenido largo.

    Elige la unidad

  2. 2

    Elige la salida

    Selecciona el Formato de salida; marca Comenzar con "Lorem ipsum dolor sit amet..." y, para párrafos HTML, Envolver párrafos con etiquetas

    .

  3. 3

    Genera y reutiliza

    El texto se regenera con cada cambio; pulsa Generar para otra variante aleatoria y luego Copiar o Descargar como TXT.

Consejos y mejores prácticas

  • Las cantidades mayores de 1000 se limitan a 1000 y 0 pasa a 1, así que un error al teclear no bloquea la página.
  • Cada generación es aleatoria; si necesitas el mismo texto en varias ejecuciones, guarda el resultado.
  • Lorem Ipsum tiene palabras latinas cortas; para probar palabras largas, la partición de líneas o alfabetos no latinos usa texto real en el idioma de destino.
  • El contador de caracteres incluye espacios, saltos de línea y etiquetas HTML, útil para comprobar límites maxlength.
  • Sustituye el texto de relleno antes de publicar: buscadores y lectores de pantalla lo tratan como contenido real.
