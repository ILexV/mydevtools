Claves OpenSSH genera pares de claves SSH (Ed25519, ECDSA P-256/P-384, RSA 3072/4096) y convierte claves entre los formatos OpenSSH, PKCS#8 y SPKI PEM. Las claves se crean y convierten en tu navegador; la clave privada no se envía a ninguna parte.

Funcionalidad detallada

La generación produce una clave privada OpenSSH (-----BEGIN OPENSSH PRIVATE KEY-----) y la línea pública correspondiente (ssh-ed25519 AAAA…), lista para authorized_keys. Con frase de contraseña, la clave privada se cifra como lo hace ssh-keygen: bcrypt-pbkdf con 16 rondas y aes256-ctr. La frase se usa tal cual, espacios incluidos. La generación corre en un Web Worker: Ed25519 y ECDSA tardan milisegundos, RSA 4096 de unos segundos a cerca de un minuto; mientras tanto la página sigue usable, muestra el tiempo transcurrido y ofrece Cancelar.

Importar acepta una clave pegada o un archivo de clave (también arrastrando): una línea pública OpenSSH (ssh-ed25519, ecdsa-sha2-nistp256/384, ssh-rsa), una clave privada OpenSSH, un PEM SPKI PUBLIC KEY o un PEM PKCS#8 PRIVATE KEY / ENCRYPTED PRIVATE KEY. De una clave privada obtiene la línea pública; de una pública muestra algoritmo y comentario. Convertir pasa una clave privada OpenSSH a PKCS#8, una línea pública OpenSSH a SPKI PEM y viceversa, y PKCS#8 a OpenSSH.

Los resultados se copian o se descargan como id_key / id_key.pub (generadas) o imported.key / imported.pub (importadas). Las advertencias señalan opciones débiles, como RSA de menos de 3072 bits. Las claves creadas por versiones anteriores, que recortaban la frase, siguen abriéndose: si la frase escrita se rechaza, se prueba la variante sin espacios al principio y al final y una nota lo indica.

Ejemplos prácticos

Clave nueva para un servidor: elige Ed25519, pulsa Generar claves, añade la línea pública (empieza por ssh-ed25519 AAAAC3NzaC1lZDI1NTE5) a ~/.ssh/authorized_keys del servidor y guarda la privada como ~/.ssh/id_ed25519 con permisos 600.

RSA para un sistema antiguo: elige RSA 4096 si un dispositivo no acepta Ed25519. La generación tarda; se muestran los segundos transcurridos y Cancelar la detiene.

Clave pública OpenSSH a PEM: pega ssh-ed25519 AAAA… user@host y pulsa Convertir para obtener un SPKI PEM que empieza por -----BEGIN PUBLIC KEY----- y MCowBQYDK2VwAyEA, el formato que esperan OpenSSL, Java y otras bibliotecas.

Usar una clave SSH en código: pega una OPENSSH PRIVATE KEY (con su frase en el campo), pulsa Convertir y obtén un bloque PKCS#8 -----BEGIN PRIVATE KEY----- para bibliotecas que no leen el formato OpenSSH.

Cómo usar esta herramienta

  1. 1

    Elige el tipo de clave

    En Generar selecciona el Algoritmo: Ed25519 (Recommended), ECDSA P-256/P-384 o RSA 3072/4096. Tamaño de clave solo está activo para RSA.

  2. 2

    Pon una frase de contraseña si quieres

    Escribe una frase en Frase de contraseña (opcional) para cifrar la clave privada; déjalo vacío para una clave sin cifrar.

  3. 3

    Genera

    Pulsa Generar claves. Con RSA aparece una barra de progreso con el tiempo transcurrido y Cancelar.

  4. 4

    Guarda las claves

    Usa Copiar o Descargar en Clave pública y Clave privada.

  5. 5

    Importa o convierte claves existentes

    Pega una clave en Importar o arrastra un archivo, y pulsa Importar para examinarla o Convertir para cambiar su formato.

Consejos y mejores prácticas

  • Las claves Ed25519 son cortas, rápidas y las aceptan OpenSSH 6.5+ y los grandes servicios Git; usa RSA solo donde sea obligatorio.
  • La advertencia «ssh-rsa uses SHA-1» se refiere al esquema de firma antiguo; OpenSSH actual firma con claves RSA usando rsa-sha2-256/512.
  • Una clave privada sin frase es tan segura como el disco donde está; ponle una a las claves de portátiles.
  • Una frase que empieza o termina con espacio es otra frase; el campo muestra un aviso para que no sea un accidente.
  • Las claves privadas descargadas necesitan chmod 600 antes de que ssh las use.
