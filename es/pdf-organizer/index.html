      Organizar páginas PDF muestra cada página de un PDF como miniatura para que puedas girar, eliminar y reordenar páginas y después guardar un PDF o dividirlo en varios archivos. Todo se ejecuta en tu navegador; el documento no se sube.

      Funcionalidad detallada

      Abre un PDF y cada página aparece como una tarjeta con su vista previa, tamaño de papel y posición. Selecciona páginas con la casilla o haciendo clic en la miniatura y aplica a la vez Girar a la izquierda, Girar a la derecha o Eliminar, o usa los botones de una tarjeta. Cambia el orden arrastrando tarjetas o con Mover antes y Mover después; una página movida indica de dónde viene («era la 7»). Restablecer recupera el orden original.

      Guardar ofrece tres salidas: Un PDF con las páginas de arriba, Dividir cada N páginas y Dividir por rangos como 1-3, 5, 8-, donde las posiciones siguen el orden en pantalla y cada rango se convierte en un archivo (8- significa hasta la última página y 5-3 va al revés). Las partes se muestran con su número de páginas y tamaño y se pueden descargar una a una o juntas en un ZIP.

      Las páginas se mueven, no se vuelven a renderizar: texto, fuentes, imágenes y gráficos vectoriales quedan exactamente como en el original y el giro se guarda en el valor /Rotate de la página, así que no se pierde calidad. El trabajo se ejecuta en un Web Worker con Rust/WebAssembly (lopdf); las vistas previas las dibuja pdf.js solo para las páginas cercanas a la pantalla. Al eliminar páginas se quitan los marcadores, los destinos con nombre, el árbol de etiquetas de accesibilidad, los enlaces a páginas eliminadas y los campos de formulario que solo estaban en ellas, para que el resultado no arrastre las páginas eliminadas; al reordenar se quitan las etiquetas de página personalizadas. Los PDF que necesitan contraseña para abrirse no se procesan.

      Ejemplos prácticos

      Corregir un escaneo: las páginas 2 y 5 están al revés; selecciona ambas, pulsa Girar a la derecha dos veces y Crear PDF; obtendrás scan_organized.pdf con todas las páginas derechas.

      Extraer capítulos: elige Dividir por rangos y escribe 1-12, 13-30, 31- para obtener book_p1-12.pdf, book_p13-30.pdf y book_p31-48.pdf de un libro de 48 páginas, o pulsa Descargar todo (ZIP).

      Un archivo por página: Dividir cada N páginas con 1 convierte un lote de 10 facturas en diez PDF de una página.

      Quitar una página en blanco y mover la portada: elimina la página vacía, arrastra la tarjeta de la portada al primer lugar y crea el PDF.

      Cómo usar esta herramienta

      1. 1

        Abre el PDF

        Arrastra un PDF a Arrastra un PDF aquí o haz clic en Elegir PDF. Las miniaturas aparecen a medida que se cargan las páginas.

      2. 2

        Edita las páginas

        Selecciona páginas y usa Girar a la izquierda, Girar a la derecha o Eliminar, o los botones de cada tarjeta. Arrastra tarjetas o usa las flechas para cambiar el orden.

      3. 3

        Elige el resultado

        En Guardar elige un PDF, Dividir cada N páginas o Dividir por rangos e indica el número o los rangos.

      4. 4

        Crea y descarga

        Haz clic en Crear PDF o Dividir PDF y descarga cada archivo o todas las partes en un ZIP.

      Consejos y mejores prácticas

      • Los rangos cuentan posiciones después de tus cambios: si moviste o eliminaste páginas, los números siguen el orden que ves.
      • El giro no pierde calidad; cuatro giros devuelven la página a su estado original.
      • Para sacar unas pocas páginas de un archivo grande, usa Dividir por rangos solo con ellas, por ejemplo 4, 9-10.
      • Los marcadores se conservan si solo giras o reordenas páginas; al eliminar páginas o dividir se quitan porque podrían apuntar a páginas que no están en el archivo.
      • Para combinar varios PDF primero, usa Unir PDF y después organiza aquí el archivo resultante.
