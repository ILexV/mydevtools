Escáner de puertos

Escanee los puertos TCP de un host desde su equipo: una lista habitual, 1–1024, los 65535 o sus propios rangos.

Preparar el agente

Descargue y arranque el agente local, luego vuelva a esta página.

Sobre el agente y la descarga
  1. Arranque MyDevTools Agent. Para escanear una dirección privada o de bucle, active «Allow local network and this PC as targets» en la ventana del agente.
  2. Copie el código de emparejamiento de la ventana del agente.
  3. Pegue el código abajo. Si el navegador pide acceso a la red local, permítalo para esta conexión.

El navegador envía el host, la lista de puertos y el tiempo de espera solo al agente en 127.0.0.1. El agente abre conexiones TCP con ese único host y cierra cada una al instante. No envía datos ni lee banners. El escaneo no va a un servidor de MyDevTools. Este navegador recuerda el preajuste, su lista de puertos, el tiempo de espera y el número de conexiones en paralelo. No guarda el host ni los resultados.

Equipo
Un nombre de host o una dirección IP. Las direcciones privadas y de bucle necesitan «Allow local network and this PC as targets» activado en la ventana del agente.
Espera por puerto
Cuánto esperar cada conexión, de 200 a 5000 milisegundos. Un puerto que no responde a tiempo se marca como filtrado.
En paralelo
Cuántas conexiones se abren a la vez, de 1 a 64. Redúzcalo con un enlace lento o un host que limita las conexiones.
Lista de puertos
Puertos y rangos separados por comas o espacios, por ejemplo 22, 80, 8000-8100. Como máximo 1024 rangos distintos.

Escáner de puertos pide al agente local de su equipo Windows que intente conexiones TCP con un host y muestra cada puerto como abierto, cerrado o filtrado. Elija 70 puertos de servicios habituales, el rango conocido 1–1024, los 65535 puertos o su propia lista de puertos y rangos. Los resultados llegan mientras avanza el escaneo, y Detener lo termina en el agente. El permiso es port.scan, distinto de tcp.connect y de las demás herramientas de red.

Funcionalidad detallada

Es un escaneo connect: el agente completa el saludo TCP y cierra el socket al instante, sin enviar datos ni leer un banner. Una conexión rechazada es cerrado, la falta de respuesta dentro de la espera es filtrado, y la falta de ruta es inalcanzable. Se ejecutan hasta 64 conexiones a la vez, y cada puerto espera de 200 a 5000 milisegundos. Con hasta 1024 puertos se lista cada puerto; en un escaneo mayor solo los abiertos, con recuentos del resto. El agente aplica las mismas reglas de destino que sus otras herramientas: direcciones privadas y de bucle solo con «Allow local network and this PC as targets» activado en la ventana del agente, direcciones metadata, de enlace local y multicast nunca, y su propio puerto de escucha aparece como bloqueado. Como mucho hay dos escaneos a la vez. Escanee solo hosts que sean suyos o que tenga permiso para probar.

Ejemplos prácticos

  • 127.0.0.1 con la lista habitual muestra qué escucha en su propio PC (active antes el acceso a la red local en la ventana del agente).
  • 192.168.1.1 con 1–1024 lista los servicios que expone su router.
  • example.com con 80, 443, 8080-8090 comprueba un servidor web y sus puertos alternativos.

Cómo usar esta herramienta

  1. 1

    Arranque el agente local

    Descargue el agente, arránquelo y copie el código de emparejamiento.

  2. 2

    Empareje el escáner de puertos

    Pegue el código y conecte. La página pide port.scan y conserva los permisos que este navegador ya tiene.

  3. 3

    Elija el host y los puertos

    Escriba un host, elija un preajuste de puertos o escriba su propia lista, y fije la espera y el número de conexiones en paralelo.

  4. 4

    Escanee y lea los resultados

    Pulse Escanear. Los puertos abiertos aparecen a medida que se encuentran, con su servicio habitual. Pulse Detener para terminar antes y copie los resultados como texto.

Consejos y mejores prácticas

  • Filtrado suele significar que un cortafuegos descarta los paquetes. Una espera más larga distingue un host lento de un puerto filtrado.
  • Un escaneo completo 1–65535 con una espera de 1000 ms puede tardar varios minutos contra un host filtrado; reduzca la espera para un host de su propia red.
  • El servicio habitual es la asignación común del puerto, no lo que el host ejecuta en realidad.
  • La descarga publicada para Windows puede ser anterior a esta página. El escáner necesita un agente que anuncie port.scan.
