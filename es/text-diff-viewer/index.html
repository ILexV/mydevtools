    Pega dos versiones de un archivo de configuración, un fragmento de código o un documento y verás exactamente qué líneas se añadieron, eliminaron o cambiaron, en vista lado a lado o línea por línea (unificada), como un Git diff.

    Funcionalidad detallada

    La comparación es por líneas: jsdiff genera un parche unificado y diff2html lo muestra con números de línea, hasta 4 líneas de contexto sin cambios alrededor de cada cambio y resaltado de las palabras modificadas dentro de las líneas. Solo se muestran las zonas cambiadas (hunks), no el texto completo. Los espacios y las mayúsculas cuentan, así que una sangría distinta o un espacio al final de línea es un cambio.

    Cada lado se puede escribir, pegar o cargar desde un archivo de texto local (leído como UTF-8). Los finales de línea se normalizan, de modo que un archivo de Windows (CRLF) y uno de Unix (LF) con las mismas líneas se consideran idénticos. Si ambos lados se cargan desde archivos, la comparación empieza sola; con entradas idénticas se indica que no hay diferencias.

    El diff se calcula en tu navegador y los archivos se leen localmente: no se sube nada. Para que la página siga respondiendo, hay un límite: si difieren más de 1.000 líneas, la herramienta muestra un aviso en lugar del diff.

    Ejemplos prácticos

    Cambio de configuración: las líneas host=localhost, port=8080, debug=true frente a host=0.0.0.0, port=8080, debug=false: las líneas de host y debug aparecen como eliminadas y añadidas con las palabras cambiadas resaltadas, mientras que port=8080 queda como contexto sin cambios.

    Una línea en un archivo largo: en un texto de 20 líneas donde solo cambió la línea 11, el diff muestra un único bloque @@ -7,9 +7,9 @@: el cambio más 4 líneas de contexto a cada lado.

    Comparar dos archivos: elige la versión antigua y la nueva con los botones de archivo; el diff aparece en cuanto se cargan ambos.

    Comprobar una copia: al comparar dos textos idénticos se indica que no se encontraron diferencias.

    Cómo usar esta herramienta

    1. 1

      Añade el original

      Pega el texto en Texto original o pulsa Elegir archivo original.

    2. 2

      Añade la versión modificada

      Pega el texto en Texto modificado o pulsa Elegir archivo modificado.

    3. 3

      Compara

      Pulsa Comparar. Si ambos lados vienen de archivos, el diff aparece automáticamente.

    4. 4

      Cambia la vista

      En Modo de vista, elige Lado a lado o Unificado; Limpiar vacía ambos campos.

    Consejos y mejores prácticas

    • Lado a lado se lee mejor en pantallas anchas y Unificado en el móvil.
    • Solo se puede comparar texto plano; no se admiten imágenes, PDF ni documentos de Word.
    • Si difieren más de 1.000 líneas, compara los archivos por partes.
    • Formatea antes el JSON o el código minificado (un elemento por línea): una sola línea larga produce una sola línea cambiada.
    • Tras la primera visita, la página también funciona sin conexión.
