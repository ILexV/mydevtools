Embellecedor XML

Formatea o minifica XML en el navegador con sangría de 2/4 espacios o tabulación; conserva comentarios, CDATA e instrucciones de procesamiento y avisa de errores.

Tus datos de entrada y archivos no salen del navegador

XML de entrada

Pegue XML o suelte aquí un archivo .xml para indentarlo o compactarlo en una línea.

En el editor, Tab inserta sangría. Pulsa Esc y luego Tab para salir del editor.

Convierte un documento XML de una sola línea o mal indentado en un árbol con una sangría limpia, o minifícalo para transmitirlo. La entrada la lee el propio parser XML del navegador, así que el marcado mal formado se notifica con línea y columna en lugar de «arreglarse» en silencio.

Funcionalidad detallada

Formatear coloca cada elemento en su propia línea, con sangría de 2 espacios, 4 espacios o una tabulación; un elemento que solo contiene texto se queda en una línea (<to>Ann</to>) y los elementos vacíos se escriben como <b/>. Modo compacto (minificar) elimina los espacios entre etiquetas. Se conservan la declaración XML, los comentarios, las secciones <![CDATA[…]]>, las instrucciones de procesamiento como <?xml-stylesheet …?> y el DOCTYPE, y los caracteres especiales se vuelven a escapar en la salida (&amp;, &lt;, &quot;).

El análisis es XML estricto, no HTML: una etiqueta sin cerrar o que no coincide, una comilla que falta o una entidad no definida detienen el formateo con el mensaje del parser, por ejemplo error on line 1 at column 11: Opening and ending tag mismatch en Chrome. El subconjunto interno de un DOCTYPE (<!DOCTYPE x [ … ]>) no se conserva, porque el navegador no lo expone.

Abre un archivo .xml o suéltalo sobre el editor; después copia el resultado o guárdalo como formatted.xml. El editor resalta etiquetas, atributos y comentarios, pliega elementos y sigue siendo rápido con archivos grandes. La sangría y el modo compacto se recuerdan en este navegador; el XML en sí nunca se guarda ni se envía a ninguna parte.

Ejemplos prácticos

Indentar un documento de una línea: <note><to>Ann</to><from>Bob</from></note> con 2 espacios se convierte en cuatro líneas: <note>, <to>Ann</to>, <from>Bob</from>, </note>.

Conservar comentarios y CDATA: en <?xml version="1.0"?><!-- cfg --><config><db host="localhost" port="5432"/><![CDATA[a<b]]></config> la declaración y el comentario quedan en líneas propias, y <![CDATA[a<b]]> permanece sin cambios dentro de <config>.

Minificar: con el Modo compacto, un <root> indentado que contiene <a>1</a> y <b/> se convierte en <root><a>1</a><b/></root>.

Detectar una etiqueta rota: <a><b></a> se rechaza con «Opening and ending tag mismatch: b line 1 and a».

Cómo usar esta herramienta

  1. 1

    Añade el XML

    Pégalo en el editor XML de entrada, haz clic en Abrir para cargar un archivo .xml o suelta el archivo sobre el editor.

  2. 2

    Elige el estilo de salida

    Selecciona el Tamaño de indentación (2 espacios, 4 espacios o Tabulación) o activa Modo compacto (minificar).

  3. 3

    Formatea

    Haz clic en Formatear o pulsa Ctrl+Enter (Cmd+Enter en macOS). Los errores de análisis aparecen encima del editor.

  4. 4

    Usa el resultado

    Haz clic en Copiar, o en Guardar para descargar el resultado como formatted.xml.

Consejos y mejores prácticas

  • Al cambiar la sangría o el Modo compacto, el documento actual se vuelve a formatear de inmediato.
  • El contenido mixto se divide y se recorta: <p>Hello <b>world</b>!</p> se convierte en líneas separadas para Hello, <b>world</b> y !. No reformatees documentos en los que importan los espacios dentro del texto.
  • Las costumbres de HTML rompen el XML: <br> sin barra o &nbsp; sin DTD son errores aquí.
  • Haz clic en las flechas junto a los números de línea para plegar elementos; Ctrl/Cmd+F busca en todo el documento.
  • En el editor, Tab inserta sangría; pulsa Esc y luego Tab para sacar el foco.
  • Sin subidas: el documento se procesa en la página, que además funciona sin conexión tras la primera visita.
