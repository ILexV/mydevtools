HTTP

Client HTTP

Envoyez des requêtes HTTP depuis Windows via un agent local, sans compte ni proxy MyDevTools.

Les requêtes vont directement de votre PC Windows vers la cible

Requêtes enregistrées

Conserve les 100 dernières requêtes envoyées telles qu’écrites — les variables et les secrets ne sont pas résolus, les réponses ne sont pas conservées. Stocké là où se trouve l’espace de travail.

    i Faites glisser les éléments dans des dossiers ou dans un espace vide pour les déplacer à la racine. Faites un clic droit ou appuyez sur Maj+F10 pour ouvrir les actions.

    Les URL, en-têtes (y compris les secrets) et corps des requêtes sont enregistrés automatiquement dans ce navigateur uniquement. Les réponses ne sont pas enregistrées.

    Déplacer vers un dossier

    Secrets

    Les valeurs restent dans le coffre chiffré de l'agent et ne reviennent jamais à la page. Placez {{secret:name}} dans l'URL, un en-tête ou le corps : l'agent le remplace uniquement pour les hôtes listés et le masque dans la réponse.

      Environnements

      Utilisez {{nom}} dans l'URL, les paramètres, les en-têtes, le corps et l'autorisation. L'environnement actif l'emporte sur les variables de dossier, qui l'emportent sur les globales. Pour une valeur en écriture seule, donnez {{secret:nom}} à la variable.

      Paramètres du client

      Proxy

      L’agent se connecte via un proxy HTTP : CONNECT pour https, URL absolues pour http. Le mot de passe du proxy est enregistré avec l’espace de travail.

      Certificats client (mTLS)

      L’agent présente un certificat aux hôtes https de sa liste quand le serveur le demande. La clé privée est stockée chiffrée dans l’agent et ne revient jamais sur la page. Utilisez des fichiers PEM avec une clé non chiffrée ; convertissez d’abord un .pfx : openssl pkcs12 -in cert.pfx -out cert.pem -nodes

      Connectez un agent avec coffre de secrets pour ajouter des certificats client.

        Aucun certificat client pour l’instant.

        Ajouter un certificat

        Laissez les deux fichiers vides pour garder le certificat et la clé enregistrés.

        Cookies

        Les cookies des réponses arrivent ici et partent avec les requêtes correspondantes : l’agent les choisit par domaine, chemin et Secure à chaque saut, redirections comprises. Sans « Conserver les cookies », ils durent jusqu’à la fermeture de la page.

          Autorisation

          Variables

          Disponibles sous la forme {{nom}} pour toutes les requêtes de ce dossier et de ses sous-dossiers ; le dossier le plus proche l'emporte.

          Scripts

          Exécutés pour chaque requête de ce dossier et de ses sous-dossiers, avant les scripts de la requête elle-même.

          Données

          Les requêtes s’exécutent l’une après l’autre dans l’ordre de l’arborescence avec leurs scripts ; les variables modifiées par les scripts sont enregistrées. Avec un fichier de données, une itération par ligne, accessible via pm.iterationData et {{colonne}}. Fermer cette fenêtre arrête l’exécution.

                        4. Conseils et bonnes pratiques
                        Envoyez des requêtes HTTP et HTTPS sans compte et sans faire transiter vos identifiants API par un serveur MyDevTools. Un petit agent Windows exécute la connexion et renvoie état, durée, en-têtes et corps.
                        Fonctionnalité détaillée
                        Le navigateur s’associe explicitement à l’agent sur 127.0.0.1 avec un code à usage unique. Le jeton de connexion est stocké dans ce navigateur pendant 8 heures au maximum ou jusqu’au redémarrage de l’agent ; le code n’est pas stocké. Le jeton n’accorde que http.request. Les requêtes vont directement à la cible. Les réseaux privés exigent d’activer « Allow local network and this PC as targets » dans la fenêtre de l’agent (ou --allow-private) ; les redirections sont désactivées par défaut et les en-têtes sensibles sont retirés lors d’un changement d’origine. Les brouillons, y compris les URL, en-têtes et secrets, ainsi que les corps sont enregistrés automatiquement dans ce navigateur pour être rouverts plus tard ; les réponses ne sont pas enregistrées. Le jeton de connexion est enregistré séparément pendant 8 heures au maximum ou jusqu’au redémarrage de l’agent. Avec un agent à jour, les brouillons sont conservés chiffrés sur l'ordinateur par l'agent plutôt que par le navigateur.
                        Exemples pratiques
                        Utilisez GET pour du JSON, POST avec Content-Type: application/json pour une API ou HEAD pour les métadonnées. Ajoutez Authorization: Bearer … seulement si la cible l’exige ; il va à la cible, pas à MyDevTools.
                        Comment utiliser cet outil
                        1. 1
                          installer et lancer l’agent
                          Téléchargez le compagnon Windows x64 et lancez-le.
                        2. 2
                          associer
                          Demandez un code dans la fenêtre de l’agent, saisissez-le puis cliquez sur Connecter.
                        3. 3
                          préparer la requête
                          Choisissez méthode, URL HTTP ou HTTPS, en-têtes et corps UTF-8.
                        4. 4
                          envoyer et examiner
                          Consultez état, durée, URL finale, en-têtes et aperçu texte. Téléchargez les corps binaires octet pour octet.
