Compagnon Windows

Connectez les outils du navigateur à votre PC Windows

L’agent local accorde à certains outils MyDevTools une capacité explicitement autorisée sur votre ordinateur. L’installateur le place dans votre profil utilisateur, sans compte, et il se contrôle depuis la zone de notification Windows.

Téléchargez, lancez et associez

Le téléchargement est un installateur pour l’utilisateur actuel. Il place l’agent dans votre profil utilisateur. Relancer un installateur plus récent remplace cette copie.

  1. 1

    Téléchargez

    Téléchargez l’installateur. Le relancer avec une version plus récente remplace l’agent installé.

  2. 2

    Lancez

    Ouvrez l’installateur. Il arrête un agent déjà ouvert, puis écrit la nouvelle copie. Windows peut demander de confirmer l’exécution d’une application téléchargée. Les droits administrateur ne sont pas requis.

  3. 3

    Associez

    Saisissez dans l’outil MyDevTools le nouveau code affiché par l’agent. L’association n’accorde que la capacité demandée par cet outil.

Un modèle d’autorisation limité

L’agent n’est ni un compte, ni un service distant, ni un exécuteur général de commandes.

  • Aucune inscription, connexion ou passerelle cloud MyDevTools.
  • Aucun droit administrateur et aucun service Windows. L’installateur concerne uniquement l’utilisateur actuel.
  • Un code unique renouvelé démarre une session de navigateur temporaire. Le navigateur stocke le jeton de connexion pendant 8 heures au maximum ou jusqu’au redémarrage de l’agent, mais jamais le code d’association.
  • Il écoute uniquement sur ce PC. Les requêtes et les sondes vont directement de l’agent à la cible, ou par un proxy seulement si vous en définissez un. Les cibles de réseau privé sont bloquées tant que vous ne les autorisez pas dans la fenêtre de l’agent. Les routeurs vus sur le chemin sont affichés même avec une adresse privée.

Vous gardez le contrôle

Fermer la petite fenêtre la masque ; l’icône de la zone de notification la rouvre.

  • Consultez la version et le code d’association actuel.
  • Le démarrage automatique est facultatif et désactivé par défaut. Il utilise vos paramètres utilisateur Windows et suit l’agent installé lorsqu’un installateur plus récent le remplace.
  • « Allow local network and this PC as targets » est désactivé par défaut. L’activer permet aux outils d’atteindre les adresses privées et de bouclage et d’analyser votre propre réseau ; le choix est mémorisé, et le désactiver arrête une analyse en cours d’une cible privée.
  • Quitter arrête le serveur local et révoque entièrement les sessions actives.

Un coffre chiffré sur ce PC

Les outils qui demandent le coffre gardent leurs données dans l’agent plutôt que dans le navigateur.

  • Chaque fichier est chiffré en AES-256-GCM ; Windows protège la clé pour votre compte utilisateur.
  • Les secrets et les clés des certificats client sont en écriture seule : une page peut les utiliser dans des requêtes, mais jamais les relire.
  • Chaque site a son propre coffre : un site ne peut pas lire les données d’un autre.
  • Pour le déplacer vers un autre ordinateur, utilisez « Export vault… » et « Import vault… » dans la fenêtre de l’agent : un seul fichier pour tous les sites, chiffré avec votre mot de passe (Argon2id et AES-256-GCM). Une page ne peut pas lancer d’export.

Capacité disponible

Cette version peut associer des requêtes HTTP, des connexions WebSocket, des Server-Sent Events, le coffre pour les espaces de travail et les secrets, des traces de chemin ICMP, une recherche DNS, une vérification TCP, une inspection TLS, WHOIS, une recherche ASN, le scanner de ports et le scanner de réseau. Chaque outil demande sa propre capacité nommée ; l’association n’accorde pas automatiquement de futures capacités, donc après une mise à jour un outil peut vous demander de l’associer à nouveau.

Vérifiez le téléchargement

Cet installateur n’est pas signé numériquement ; Windows SmartScreen peut afficher un avertissement ou le bloquer. Ne désactivez pas la protection Windows. Comparez son SHA-256 à la valeur ci-dessus pour vérifier l’intégrité ; un hachage identique ne remplace pas la signature de l’éditeur.
