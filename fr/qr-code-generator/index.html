Créez un QR code pour un lien, un texte ou une chaîne Wi-Fi, choisissez les couleurs, le style, la correction d'erreur et la taille, ajoutez un logo et téléchargez-le en PNG ou SVG. Le code est généré dans votre navigateur.

Fonctionnalité détaillée

Le contenu est encodé en octets UTF-8 : toutes les écritures et les emoji fonctionnent. Les niveaux de correction d'erreur L, M, Q et H récupèrent environ 7, 15, 25 et 30 % de dommages ; plus le niveau est élevé, plus le code est dense. La capacité va jusqu'à 2953 octets au niveau L et 1273 octets au niveau H — un contenu plus long affiche une erreur au lieu d'un code inutilisable.

Le PNG mesure exactement 256, 512, 1024 ou 2048 px, avec une zone de silence d'au moins quatre modules. Les styles Carré, Points et Arrondi modifient les modules de données, tandis que les trois carrés de repérage restent toujours carrés : chaque style reste lisible. Un logo (PNG, JPEG ou WebP) est placé au centre sur un fond ; sa taille augmente avec le niveau de correction d'erreur (jusqu'à 30 % de la largeur du code au niveau H) — utilisez Q ou H avec un logo et testez le code avec de vrais téléphones : aucune taille de logo ne garantit la lecture. Le SVG est proposé pour le style carré sans logo.

Les couleurs se règlent avec le sélecteur ou en valeur hexadécimale (#RRGGBB) ; une valeur invalide est signalée, et le contraste entre les deux couleurs est affiché, avec un avertissement s'il est faible ou inversé. La génération s'exécute avec Rust/WebAssembly dans le navigateur, et l'aperçu se met à jour automatiquement pendant la saisie ou au changement d'une option.

Exemples pratiques

Lien de site web : https://example.com au niveau M en 512 × 512 donne un qrcode.png d'exactement 512×512 px ; le Scanner QR le relit et propose un bouton Ouvrir le lien.

Accès Wi-Fi : WIFI:T:WPA;S:MyNet;P:secret123;; encode les identifiants du réseau, que l'appareil photo du téléphone propose de rejoindre.

Code à l'image de la marque : Branded code avec un logo rond, le niveau H, le style Arrondi et 1024 × 1024 se décode toujours en texte d'origine.

Trop de données : 3000 caractères dépassent la capacité maximale et l'outil affiche une erreur au lieu d'un code.

Comment utiliser cet outil

  1. 1

    Saisir le contenu

    Tapez une URL ou un texte dans Contenu.

  2. 2

    Choisir l'apparence

    Réglez Couleur du QR Code et Couleur de fond, puis choisissez Style, Niveau de correction d'erreur et Taille de l'image.

  3. 3

    Ajouter un logo (facultatif)

    Déposez une image PNG, JPEG ou WebP sous Logo (optionnel) et passez au niveau Q ou H.

  4. 4

    Vérifier et télécharger

    L'aperçu se met à jour pendant la saisie. Une fois à jour, téléchargez le PNG ou, pour le style carré sans logo, le SVG.

Conseils et bonnes pratiques

  • Gardez un contraste marqué : des modules foncés sur fond clair se scannent le plus sûrement ; certains lecteurs ne gèrent pas les couleurs inversées.
  • Un contenu plus court donne un code moins dense, plus facile à scanner de loin — utilisez une URL courte si possible.
  • Avec un logo, choisissez le niveau H et testez le code avec un téléphone avant d'imprimer.
  • Pour l'impression, prenez le SVG (style carré sans logo) ou un PNG de 2048 px.
  • Laissez la bordure blanche autour du code : les lecteurs ont besoin de la zone de silence.
