Lisez un QR code avec la caméra de votre appareil ou depuis une capture d'écran ou une photo : le texte décodé s'affiche, prêt à copier, et les liens reçoivent un bouton Ouvrir le lien. Tout est décodé localement dans votre navigateur.

Fonctionnalité détaillée

Les images PNG, JPEG et WebP sont prises en charge ; le GIF et les autres formats donnent un message d'erreur. Le décodage utilise rxing, un portage Rust de ZXing compilé en WebAssembly, dans un Web Worker : même une photo d'environ 3800 px ne fige pas la page, et choisir un autre fichier annule l'analyse précédente.

Scanner avec la caméra ouvre la caméra arrière avec un cadre de visée ; si l'appareil a plusieurs caméras, la liste Caméra permet d'en changer. Les images sont réduites à 1024 px au maximum et décodées dans le même Web Worker, et une nouvelle image n'est capturée qu'une fois la précédente traitée : la page reste fluide. L'analyse s'arrête au premier code trouvé (Scanner à nouveau la relance), et la caméra est coupée avec Arrêter la caméra, lorsque l'onglet est masqué ou lorsque vous importez un fichier. La caméra nécessite HTTPS (ou localhost) et votre autorisation ; les images sont traitées sur l'appareil et ne sont jamais envoyées nulle part.

Le contenu complet s'affiche sous forme de texte : URL, texte brut, chaînes Wi-Fi, cartes de contact, Unicode et emoji. Seuls les liens http et https reçoivent Ouvrir le lien ; les autres schémas, comme javascript:, ne sont jamais transformés en liens. Si aucun code n'est trouvé, essayez une image plus nette où le code entier et sa bordure blanche sont visibles.

Exemples pratiques

Lien depuis une capture d'écran : un PNG créé avec le Générateur de QR Code pour https://example.com/path?q=1 affiche cette URL et un bouton Ouvrir le lien.

Caméra : cliquez sur Scanner avec la caméra, autorisez l'accès et placez un code imprimé dans le cadre — le texte s'affiche en moins d'une seconde et la caméra s'éteint.

Grande photo : un JPEG de 3848×3848 px se décode en 1 à 1,5 seconde environ sur un ordinateur de bureau, sans que la page se fige.

Pas de code dans l'image : vous obtenez « Aucun code QR trouvé dans l'image. Veuillez essayer une autre image. »

Comment utiliser cet outil

  1. 1

    Choisir une image ou démarrer la caméra

    Cliquez sur Choisir un fichier ou déposez dans la zone une image PNG, JPEG ou WebP — ou cliquez sur Scanner avec la caméra et autorisez l'accès à la caméra.

  2. 2

    Lire le résultat

    Une image est décodée automatiquement ; avec la caméra, visez le code jusqu'à ce qu'il soit reconnu. Le texte apparaît sous Contenu scanné.

  3. 3

    Utiliser le contenu

    Cliquez sur Copier, ou sur Ouvrir le lien pour une adresse http(s). Utilisez Scanner à nouveau pour lire le code suivant avec la caméra.

Conseils et bonnes pratiques

  • Recadrez large : gardez le code entier et une marge blanche autour sur l'image ou dans le champ de la caméra.
  • Évitez les reflets et le flou de bougé sur les photos d'écrans ou de codes imprimés ; tenez le téléphone immobile un instant.
  • Si la caméra est bloquée, autorisez-la dans les paramètres du site du navigateur ; sur une page sans HTTPS, la caméra n'est pas disponible : importez plutôt une image.
  • Les codes inversés (clair sur foncé) ou très peu contrastés peuvent ne pas être détectés.
  • Vérifiez l'adresse affichée avant de cliquer sur Ouvrir le lien — les QR codes servent souvent à dissimuler des liens d'hameçonnage.
