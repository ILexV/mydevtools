    Collez deux versions d’un fichier de configuration, d’un extrait de code ou d’un document et voyez exactement quelles lignes ont été ajoutées, supprimées ou modifiées — côte à côte ou ligne par ligne (diff unifié), comme un Git diff.

    Fonctionnalité détaillée

    La comparaison se fait par lignes : jsdiff construit un patch unifié et diff2html l’affiche avec les numéros de ligne, jusqu’à 4 lignes de contexte inchangées autour de chaque modification et un surlignage des mots modifiés à l’intérieur des lignes. Seules les zones modifiées (hunks) sont affichées, pas le texte entier. Les espaces et la casse comptent : une indentation modifiée ou un espace en fin de ligne est une modification.

    Chaque côté peut être saisi, collé ou chargé depuis un fichier texte local (lu en UTF-8). Les fins de ligne sont normalisées : un fichier Windows (CRLF) et un fichier Unix (LF) contenant les mêmes lignes sont jugés identiques. Quand les deux côtés viennent de fichiers, la comparaison démarre automatiquement ; des entrées identiques sont signalées comme sans différence.

    Le diff est calculé dans votre navigateur et les fichiers sont lus localement — rien n’est envoyé. Pour que la page reste fluide, les textes très différents sont plafonnés : si plus de 1 000 lignes diffèrent, l’outil affiche un message au lieu du diff.

    Exemples pratiques

    Changement de configuration : les lignes d’origine host=localhost, port=8080, debug=true face à host=0.0.0.0, port=8080, debug=false — les lignes host et debug apparaissent supprimées puis ajoutées, avec les mots modifiés surlignés, tandis que port=8080 reste en contexte inchangé.

    Une ligne dans un long fichier : dans un texte de 20 lignes où seule la ligne 11 change, le diff affiche un seul hunk @@ -7,9 +7,9 @@ — la modification plus 4 lignes de contexte de chaque côté.

    Comparer deux fichiers : choisissez l’ancienne et la nouvelle version avec les boutons de fichier ; le diff apparaît dès que les deux sont chargés.

    Vérifier une copie : comparer deux textes identiques indique qu’aucune différence n’a été trouvée.

    Comment utiliser cet outil

    1. 1

      Ajoutez l’original

      Collez le texte dans Texte original ou cliquez sur Choisir le fichier original.

    2. 2

      Ajoutez la version modifiée

      Collez le texte dans Texte modifié ou cliquez sur Choisir le fichier modifié.

    3. 3

      Comparez

      Cliquez sur Comparer. Si les deux côtés viennent de fichiers, le diff s’affiche automatiquement.

    4. 4

      Changez l’affichage

      Dans Mode d’affichage, choisissez Côte à côte ou Unifié ; Effacer vide les deux champs.

    Conseils et bonnes pratiques

    • Côte à côte se lit mieux sur grand écran, Unifié sur téléphone.
    • Seul le texte brut peut être comparé ; images, PDF ou documents Word ne sont pas pris en charge.
    • Si plus de 1 000 lignes diffèrent, comparez les fichiers par morceaux plus petits.
    • Reformatez d’abord le JSON ou le code minifié (un élément par ligne) — une seule longue ligne produit une seule ligne modifiée.
    • Après la première visite, la page fonctionne aussi sans connexion réseau.
