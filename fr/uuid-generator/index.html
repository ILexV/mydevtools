    Génère des UUID conformes à la RFC 9562 dans votre navigateur : version 4 aléatoire ou version 7 ordonnée dans le temps, un par un ou jusqu'à 100 par lot. Choisissez le format avec tirets, sans tirets, entre accolades ou URN, en minuscules ou majuscules, puis copiez un identifiant, tout copier ou téléchargez un fichier texte.

    Fonctionnalité détaillée

    La version 4 remplit 122 bits avec des données aléatoires du générateur cryptographiquement sûr du navigateur (Web Crypto getRandomValues) ; les six bits restants indiquent la version et la variante. La version 7 commence par un horodatage Unix de 48 bits en millisecondes, suivi d'un compteur de 12 bits et de 62 bits aléatoires. Le compteur suit la RFC 9562 §6.2 : les identifiants créés dans la même milliseconde, ou après un recul de l'horloge système, restent strictement croissants ; un lot de v7 se trie donc dans l'ordre de création. Cela fait du v7 une bonne clé primaire pour les index B-tree, alors que le v4 ne révèle rien de sa date de création.

    Quatre formats sont disponibles : la forme canonique avec tirets 8-4-4-4-12, 32 chiffres hexadécimaux sans tirets, les accolades {…} des GUID de Windows et .NET, et l'URN urn:uuid:…. MAJUSCULES ne modifie que les chiffres hexadécimaux ; le préfixe URN reste en minuscules.

    La génération s'effectue entièrement en JavaScript dans la page, sans WebAssembly ni requête serveur : les identifiants ne quittent pas votre appareil. Le téléchargement est un simple fichier .txt avec un UUID par ligne.

    Exemples pratiques

    Clé de base de données : la version 4 avec tirets donne des valeurs comme xxxxxxxx-xxxx-4xxx-Yxxx-xxxxxxxxxxxx ; le 13e chiffre hexadécimal vaut toujours 4 et Y vaut 8, 9, a ou b.

    Identifiants triables : un UUID v7 créé à 2023-11-14T22:13:20Z (Unix 1700000000000 ms) commence par 018bcfe5-6800-7 — les 12 premiers chiffres sont l'horodatage, donc un lot se trie par date.

    Style .NET et registre : le format entre accolades en MAJUSCULES produit des GUID du type {9F2C…}, prêts pour des attributs C# ou des fichiers .reg.

    Données de test : réglez le nombre sur 100, générez un lot et utilisez Télécharger en TXT pour obtenir un fichier de 100 lignes.

    Comment utiliser cet outil

    1. 1

      Choisir la version

      Dans Version UUID, cochez Version 4 (Aléatoire) ou Version 7 (Temporel).

    2. 2

      Régler format, casse et nombre

      Choisissez le Format et la Casse, puis réglez le curseur Nombre d'UUID (1–100).

    3. 3

      Générer

      Cliquez sur Générer ; chaque clic remplace la liste par un nouveau lot.

    4. 4

      Copier ou télécharger

      Copiez un UUID avec le bouton de sa ligne, la liste entière avec Tout copier, ou enregistrez-la avec Télécharger en TXT.

    Conseils et bonnes pratiques

    • Utilisez v7 pour les clés primaires et les identifiants de corrélation dans les logs : l'ordre temporel garde les insertions d'index localisées.
    • Un UUID v7 révèle son heure de création à la milliseconde ; utilisez v4 quand elle doit rester privée.
    • Un UUID est un identifiant unique, pas un secret : ne l'utilisez pas comme mot de passe ou jeton de session.
    • La plupart des analyseurs acceptent les deux casses, mais la RFC 9562 recommande les minuscules ; les majuscules servent pour des systèmes comme le registre Windows.
    • La forme à 32 chiffres tient dans une colonne CHAR(32) ; si votre base propose un type UUID natif sur 16 octets, préférez-le.
