JSON फॉर्मेटेर

ब्राउज़र में JSON को फॉर्मेट, मिनिफाई और वैलिडेट करें: 2/4 स्पेस या टैब इंडेंट, रिकर्सिव की सॉर्टिंग, बड़े नंबर बिल्कुल वैसे ही, .json फ़ाइल खोलें और सहेजें।

आपका इनपुट और फ़ाइलें ब्राउज़र में ही रहते हैं

इनपुट JSON

फ़ॉर्मैट, मिनिफ़ाई या कुंजियाँ क्रमबद्ध करने के लिए JSON पेस्ट करें या .json फ़ाइल यहाँ छोड़ें।

एडिटर में Tab इंडेंट करता है। एडिटर से बाहर जाने के लिए Esc दबाएँ, फिर Tab।

इस पृष्ठ पर
  1. विस्तृत कार्यक्षमता
  2. व्यावहारिक उदाहरण
  3. इस उपकरण का उपयोग कैसे करें
  4. सुझाव और सर्वोत्तम प्रथाएं

JSON डॉक्यूमेंट पेस्ट करें या फ़ाइल खोलें और उसे पढ़ने में आसान, एक-समान इंडेंट वाले टेक्स्ट में बदलें — या वापस एक लाइन में मिनिफाई करें। एडिटर सिंटैक्स हाइलाइट करता है, ऑब्जेक्ट और ऐरे को फोल्ड करता है और पार्सर की त्रुटि की जगह दिखाता है; आपका डेटा कहीं नहीं भेजा जाता।

विस्तृत कार्यक्षमता

फॉर्मेट डॉक्यूमेंट को हर लेवल पर 2 स्पेस, 4 स्पेस या एक टैब के साथ दोबारा लिखता है, और कॉम्पैक्ट मोड (मिनिफाई) हर गैर-ज़रूरी स्पेस और लाइन ब्रेक हटा देता है। कीज़ सॉर्ट करें हर नेस्टिंग लेवल पर हर ऑब्जेक्ट की कीज़ को क्रम में लगाता है, जिससे दो JSON फ़ाइलों को diff में तुलना करना आसान हो जाता है। नंबर ठीक वैसे ही लिखे जाते हैं जैसे सोर्स में हैं — 12345678901234567890 और 1.0 न राउंड होते हैं, न छोटे — उन ब्राउज़रों में जो JSON.rawJSON सपोर्ट करते हैं (मौजूदा Chrome, Edge और Firefox)।

इनपुट को ब्राउज़र का सख़्त JSON पार्सर जाँचता है: कमेंट, ट्रेलिंग कॉमा और सिंगल कोट अस्वीकार किए जाते हैं, और संदेश समस्या की जगह बताता है, जैसे Chrome में Expected double-quoted property name in JSON at position 7 (line 1 column 8)। कई मेगाबाइट की फ़ाइलों पर भी एडिटर तेज़ रहता है, एक लाइन में मिनिफाई किए गए JSON पर भी, और Ctrl/Cmd+F उसके अंदर खोजता है।

.json फ़ाइल खोलें या उसे एडिटर पर ड्रॉप करें, फिर नतीजा कॉपी करें या formatted.json के रूप में डाउनलोड करें। इंडेंट, सॉर्टिंग और कॉम्पैक्ट सेटिंग इस ब्राउज़र में याद रखी जाती हैं; JSON टेक्स्ट ख़ुद कभी सेव या अपलोड नहीं होता।

व्यावहारिक उदाहरण

रिस्पॉन्स मिनिफाई करना: कॉम्पैक्ट मोड चालू होने पर कई लाइनों में फैला { "a": [1, 2], "b": "x" } बन जाता है {"a":[1,2],"b":"x"}।

हर लेवल पर कीज़ सॉर्ट करना: कीज़ सॉर्ट करें और कॉम्पैक्ट मोड के साथ {"b":1,"a":{"d":true,"c":[1,2]}} से मिलता है {"a":{"c":[1,2],"d":true},"b":1}।

बड़ी ID सुरक्षित रखना: {"id": 12345678901234567890, "price": 1.0} मिनिफाई होकर {"id":12345678901234567890,"price":1.0} बनता है; साधारण JSON.parse + JSON.stringify राउंड ट्रिप ID को 12345678901234567000 और प्राइस को 1 कर देगा।

सिंटैक्स त्रुटि ढूँढना: {"a":1,} फॉर्मेट नहीं होता; त्रुटि पोज़िशन 7 (लाइन 1, कॉलम 8) बताती है — } से पहले का ट्रेलिंग कॉमा।

इस उपकरण का उपयोग कैसे करें

  1. 1

    अपना JSON जोड़ें

    टेक्स्ट को इनपुट JSON एडिटर में पेस्ट करें, .json फ़ाइल लोड करने के लिए खोलें पर क्लिक करें, या फ़ाइल को एडिटर पर ड्रॉप करें।

  2. 2

    फॉर्मेटिंग चुनें

    इंडेंट साइज़ (2 स्पेस, 4 स्पेस या टैब) चुनें और ज़रूरत हो तो कीज़ सॉर्ट करें या कॉम्पैक्ट मोड (मिनिफाई) चालू करें।

  3. 3

    फॉर्मेट करें

    फॉर्मेट पर क्लिक करें या Ctrl+Enter (macOS पर Cmd+Enter) दबाएँ। अमान्य JSON की सूचना एडिटर के ऊपर दिखती है और आपका टेक्स्ट जस का तस रहता है।

  4. 4

    नतीजे का उपयोग करें

    नतीजा क्लिपबोर्ड पर रखने के लिए कॉपी पर क्लिक करें या उसे formatted.json के रूप में सहेजने के लिए डाउनलोड पर।

सुझाव और सर्वोत्तम प्रथाएं

  • इंडेंट, कीज़ सॉर्ट करें या कॉम्पैक्ट मोड बदलते ही मौजूदा टेक्स्ट तुरंत दोबारा फॉर्मेट हो जाता है।
  • JSON5 जैसा इनपुट (कमेंट, ट्रेलिंग कॉमा, सिंगल कोट, बिना कोट की कीज़) वैध JSON नहीं है — पार्सर ऐसे पहले कैरेक्टर पर रुक जाता है।
  • कीज़ सॉर्ट करें साधारण कैरेक्टर क्रम इस्तेमाल करता है, इसलिए "B" "a" से पहले आता है, और "2" व "10" जैसी इंटीजर जैसी कीज़ हमेशा सबसे पहले आती हैं (JavaScript ऑब्जेक्ट का नियम)।
  • बड़े ऑब्जेक्ट और ऐरे फोल्ड करने के लिए लाइन नंबरों के पास के तीरों पर क्लिक करें; Ctrl/Cmd+F स्क्रॉल होकर दिखने से बाहर गई लाइनों में भी टेक्स्ट ढूँढ लेता है।
  • एडिटर में Tab इंडेंटेशन डालता है; फ़ोकस बाहर ले जाने के लिए Esc और फिर Tab दबाएँ।
  • पहली बार खोलने के बाद पेज ऑफ़लाइन भी काम करता है, और JSON कभी आपके ब्राउज़र से बाहर नहीं जाता।

  • J{}बड़ी JSON / JSONL फ़ाइल एक्सप्लोररबड़ी JSON और JSONL फ़ाइलें स्थानीय रूप से खोलें, इंडेक्स करें, खोजें और निर्यात करें—वर्चुअल तालिका, लेज़ी ट्री और सटीक संख्याओं के साथ।
  • CSVबड़ी CSV/TSV फ़ाइल एक्सप्लोररइंक्रीमेंटल पार्सिंग और वर्चुअल टेबल की मदद से बहुत बड़ी CSV या TSV फ़ाइलें लोकल रूप से खोलें, फ़िल्टर करें, जाँचें और एक्सपोर्ट करें।
  • </>XML फॉर्मेटेरब्राउज़र में XML को 2/4 स्पेस या टैब इंडेंट से फॉर्मेट या मिनिफाई करें; कमेंट, CDATA और प्रोसेसिंग इंस्ट्रक्शन बने रहते हैं, पार्स त्रुटियाँ दिखती हैं।
