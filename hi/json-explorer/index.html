बड़ी JSON / JSONL फ़ाइल एक्सप्लोरर

बड़ी JSON और JSONL फ़ाइलें स्थानीय रूप से खोलें, इंडेक्स करें, खोजें और निर्यात करें—वर्चुअल तालिका, लेज़ी ट्री और सटीक संख्याओं के साथ।

आपका इनपुट और फ़ाइलें ब्राउज़र में ही रहते हैं

स्थानीय फ़ाइल

JSON, JSONL या NDJSON फ़ाइल छोड़ें

फ़ाइल इसी ब्राउज़र में रहती है। JSONL क्रमशः पढ़ी जाती है; सामान्य JSON चुनी हुई मेमोरी सीमा उपयोग करती है।

सामान्य JSON केवल चुनी 8–64 MiB सीमा तक लोड होता है। JSONL 1 MiB खंडों में, प्रति रिकॉर्ड 1–8 MiB और अधिकतम गहराई 256 के साथ स्ट्रीम होती है। ये स्पष्ट सुरक्षा सीमाएँ हैं।

फ़ाइलें, खोज और बने कॉलम डिवाइस से बाहर नहीं जाते और सहेजे नहीं जाते; केवल प्रारूप और सुरक्षा सेटिंग याद रहती हैं।

फ़ाइल संसाधित हो रही है

रिकॉर्ड

संरचना और रिकॉर्ड देखने के लिए स्थानीय JSON या JSONL फ़ाइल चुनें।

खोजें, फ़िल्टर करें और प्रोजेक्ट करें

हर पंक्ति में एक RFC 6901 JSON Pointer, अधिकतम 100 फ़ील्ड दें। खाली सूची स्वचालित शीर्ष-स्तरीय कॉलम रखती है। ~ को ~0 और / को ~1 लिखें। प्रोजेक्टेड JSONL सटीक पॉइंटर कुंजियों वाला समतल ऑब्जेक्ट है; अनुपस्थित फ़ील्ड null होता है।

स्वचालित कॉलम पहले 10,000 रिकॉर्ड का नमूना लेकर अधिकतम 100 फ़ील्ड दिखाते हैं। जिन कॉलम नामों का एन्कोडेड JSON Pointer 256 वर्ण से बड़ा है और कुल 16,384 वर्ण से अधिक नाम मेटाडेटा अपने आप नहीं जुड़ता। कोई फ़ील्ड हटता नहीं: सटीक JSON Pointer उपयोग करें। सेल पूर्वावलोकन 512 वर्ण तक है; निरीक्षण और निर्यात पूरे मान उपयोग करते हैं।

चुना गया रिकॉर्ड

पूरा मूल रिकॉर्ड लोड करने के लिए तालिका की पंक्ति चुनें।

JSON संरचना
इस मान के कोई बच्चे नहीं हैं।
वर्तमान परिणाम निर्यात करें
निर्यात केवल दिखाई देने वाली पंक्तियाँ नहीं, सभी मिलते रिकॉर्ड दोबारा स्कैन करता है। आउटपुट सीमित खंडों में बनता है और ब्राउज़र सीमा 256 MiB है। CSV RFC 4180, CRLF और UTF-8 BOM उपयोग करता है।
इस पृष्ठ पर
  1. विस्तृत कार्यक्षमता
  2. व्यावहारिक उदाहरण
  3. इस उपकरण का उपयोग कैसे करें
  4. सुझाव और सर्वोत्तम प्रथाएं
निजी डेटा अपलोड किए बिना बड़े JSON ऐरे और पंक्ति-विभाजित JSON देखें। उपकरण स्थानीय विरल इंडेक्स बनाता है, वर्चुअल तालिका का छोटा भाग ही दिखाता है और रिकॉर्ड या ट्री शाखा माँगने पर लोड करता है।
विस्तृत कार्यक्षमता
JSONL / NDJSON को 1 MiB खंडों में UTF-8 के रूप में डीकोड किया जाता है। BOM, CRLF और बिना नई पंक्ति वाली अंतिम पंक्ति संभाली जाती है; त्रुटि वास्तविक पंक्ति और कॉलम बताती है। केवल विरल चेकपॉइंट और सीमित कॉलम मेटाडेटा रखा जाता है; दूर के दृश्य, फ़िल्टर और निर्यात फ़ाइल फिर पढ़ते हैं।



सामान्य JSON ऑब्जेक्ट, ऐरे और स्केलर रूट के लिए लेज़ी संरचना ट्री देता है। रूट ऐरे रिकॉर्ड तालिका में भी देखा जा सकता है। एक दस्तावेज़ की स्पष्ट 8–64 MiB सीमा है और worker में पार्स होता है। अधिकतम गहराई 256 और JSONL रिकॉर्ड 1–8 MiB है।



संख्या के मूल लेक्सेम सुरक्षित रहते हैं। 9007199254740993, 1.0 और घात रूप निर्यात में JavaScript Number से नहीं गुजरते। फ़िल्टर पूरी मिलान सूची बनाए बिना सभी रिकॉर्ड स्कैन करता है।
व्यावहारिक उदाहरण
API लॉग: .ndjson खोलें, मानों में timeout खोजें और /service को billing से फ़िल्टर करें; पंक्ति चुनकर पूरा मूल JSON देखें।



नेस्टेड फ़ील्ड: /id और /user/name प्रोजेक्ट करें; /a~1b कुंजी a/b को दर्शाता है। CSV में पॉइंटर कॉलम और JSONL में कुंजियाँ बनते हैं।



बड़ी ID: {"id":9007199254740993,"price":1.0} दोनों संख्या रूपों को सुरक्षित रखता है।



बड़ा ऐरे: केवल आवश्यक शाखाएँ खोलें और हर आइटम के लिए DOM पंक्ति बनाए बिना स्क्रॉल करें।
इस उपकरण का उपयोग कैसे करें
  1. 1
    प्रारूप और सीमाएँ चुनें
    स्वचालित, JSON या JSONL/NDJSON तथा फ़ाइल, रिकॉर्ड और गहराई सीमा चुनें।
  2. 2
    स्थानीय फ़ाइल खोलें
    फ़ाइल छोड़ें या चुनें। Worker बाइट, समय, गति और अनुमान दिखाता है; रद्द करने पर सत्र हट जाता है।
  3. 3
    खोजें या प्रोजेक्ट करें
    कुंजी या मान खोजें, RFC 6901 पथ और उप-स्ट्रिंग दें, या प्रोजेक्शन पॉइंटर सूचीबद्ध करें।
  4. 4
    निरीक्षण और निर्यात
    स्क्रॉल करें, पूरा रिकॉर्ड खोलें, ट्री फैलाएँ या सभी मिलान JSONL अथवा CSV में डाउनलोड करें।
सुझाव और सर्वोत्तम प्रथाएं
    

  • भरोसेमंद पहचान के लिए .jsonl या .ndjson उपयोग करें; अस्पष्ट फ़ाइल का प्रारूप स्वयं चुनें।
    • 

  • खाली JSONL पंक्तियाँ छोड़ दी जाती हैं, लेकिन त्रुटियाँ वास्तविक पंक्ति संख्या देती हैं।
    • 

  • खाली JSONL शून्य रिकॉर्ड का वैध परिणाम है; खाली सामान्य JSON अमान्य है।
    • 

  • JSON Pointer में / विभाजक, ~0 टिल्ड और ~1 स्लैश है।
    • 

  • =, +, -, @ के लिए CSV फ़ॉर्मूला सुरक्षा डिफ़ॉल्ट रूप से चालू है।
    • 

  • निर्यात सभी फ़िल्टर की गई पंक्तियाँ शामिल करता है और 256 MiB से पहले रुकता है।
    •

  • TSJSON से TypeScript कनवर्टरJSON सैंपल से TypeScript इंटरफ़ेस या टाइप एलियास बनाएँ: नेस्टेड टाइप, ऐरे आइटम का मर्ज, वैकल्पिक फ़ील्ड, export कीवर्ड। आपके ब्राउज़र में चलता है।
  • CSVबड़ी CSV/TSV फ़ाइल एक्सप्लोररइंक्रीमेंटल पार्सिंग और वर्चुअल टेबल की मदद से बहुत बड़ी CSV या TSV फ़ाइलें लोकल रूप से खोलें, फ़िल्टर करें, जाँचें और एक्सपोर्ट करें।
  • </>XML फॉर्मेटेरब्राउज़र में XML को 2/4 स्पेस या टैब इंडेंट से फॉर्मेट या मिनिफाई करें; कमेंट, CDATA और प्रोसेसिंग इंस्ट्रक्शन बने रहते हैं, पार्स त्रुटियाँ दिखती हैं।
