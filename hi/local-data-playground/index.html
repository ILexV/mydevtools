लोकल डेटा प्लेग्राउंड

लोकल CSV, JSON, JSONL या Parquet फ़ाइलें आयात करें और ब्राउज़र में DuckDB SQL से क्वेरी करें।

आपका इनपुट और फ़ाइलें ब्राउज़र में ही रहते हैं

लोकल डेटा आयात करें

डेटा फ़ाइल यहाँ छोड़ें

CSV, TSV, JSON, JSONL, NDJSON या Parquet। टेबल JOIN के लिए कई फ़ाइलें आयात करें।

उदाहरण नाम को quote करते हैं, इसलिए space और non-Latin अक्षर समर्थित हैं।

फ़ाइलें इसी डिवाइस पर रहती हैं। DuckDB self-hosted Web Worker में चलता है; SQL URL या अन्य ब्राउज़र फ़ाइलें नहीं पढ़ सकता।

सीमाएँ: प्रति इनपुट 1 GiB, टेक्स्ट रूपांतरण 128 MiB, DuckDB मेमोरी 512 MiB, प्रीव्यू 100,000 पंक्तियाँ, प्रति पेज 500 पंक्तियाँ और फ़ॉलबैक डाउनलोड या Parquet 512 MiB। JSON/JSONL को chunks में नहीं, बल्कि पूरे flat record set के रूप में मेमोरी में decode किया जाता है। रद्द करने पर सभी टेबल मुक्त होते हैं।

लोकल कार्य

आयातित टेबल

अभी कोई टेबल आयात नहीं हुआ।

    SQL क्वेरी

    Ctrl या Cmd + Enter दबाएँ। केवल एक लोकल read-only SELECT या WITH statement मान्य है।

    परिणाम worker में materialize होता है और सीमित पेजों में पढ़ा जाता है।
    क्वेरी परिणाम

    परिणाम देखने के लिए टेबल आयात कर क्वेरी चलाएँ।

    पूरा परिणाम एक्सपोर्ट करें

    CSV, JSON और JSONL चुनी फ़ाइल में chunks में लिखे जाते हैं। Parquet एक सीमित buffer में बनता है। fallback डाउनलोड 512 MiB तक है।

    इस पृष्ठ पर
    1. विस्तृत कार्यक्षमता
    2. व्यावहारिक उदाहरण
    3. इस उपकरण का उपयोग कैसे करें
    4. सुझाव और सर्वोत्तम प्रथाएं

    लोकल डेटा प्लेग्राउंड ब्राउज़र में DuckDB-WASM चलाता है, इसलिए CSV, JSON, JSONL और Parquet को upload किए बिना query किया जा सकता है। हर फ़ाइल को SQL टेबल नाम मिलता है और कई फ़ाइलें JOIN हो सकती हैं।

    विस्तृत कार्यक्षमता

    DuckDB और Web Worker MyDevTools से ही मिलते हैं और पहले import पर लोड होते हैं। SharedArrayBuffer, cross-origin isolation, server या बाहरी CDN की आवश्यकता नहीं है। बाहरी access, extension installation, URL readers और database बदलने वाला SQL बंद है।

    Editor SELECT और WITH, filter, group, aggregate, order और JOIN समर्थित करता है। Preview की स्पष्ट सीमा 100,000 पंक्तियाँ है और virtual table एक बार में अधिकतम 500 पंक्तियाँ माँगता है। Integer और decimal JavaScript Number में convert नहीं होते।

    CSV, JSON और JSONL backpressure के साथ chunks में export होते हैं। Parquet एक buffer में बनता है। Fallback download और Parquet 512 MiB तक सीमित हैं।

    व्यावहारिक उदाहरण

    SELECT: orders.csv को orders नाम से आयात कर SELECT * FROM "orders" LIMIT 100 चलाएँ।

    WHERE: स्थिति के अनुसार लोकल filter करें।

    GROUP BY: देश के अनुसार group कर राशि जोड़ें।

    JOIN: customers.parquet आयात कर साझा key पर टेबल जोड़ें।

    इस उपकरण का उपयोग कैसे करें

    1. 1

      फ़ाइलें आयात करें

      फ़ॉर्मेट, टेबल नाम और CSV विकल्प चुनें।

    2. 2

      लोकल SQL लिखें

      SELECT, WHERE, GROUP BY या JOIN उदाहरण संपादित कर Ctrl/Cmd + Enter दबाएँ।

    3. 3

      परिणाम देखें

      Virtual table केवल छोटा page transfer और render करता है।

    4. 4

      एक्सपोर्ट या restart करें

      CSV, JSON, JSONL या Parquet एक्सपोर्ट करें। Cancel या restart worker और डेटा मुक्त करता है।

    सुझाव और सर्वोत्तम प्रथाएं

    • टेबल और कॉलम नाम double quotes में रखें।
    • बड़ी फ़ाइलों पर LIMIT और चयनात्मक WHERE उपयोग करें।
    • CSV type inference शुरुआती zero वाले identifier को संख्या बना सकता है; text सुरक्षित रखने के लिए Data Format Converter उपयोग करें।
    • BIGINT और DECIMAL Number से round नहीं होते।
    • Cancel के बाद फ़ाइलें फिर आयात करनी होती हैं।
    • CSV/JSON/JSONL stream हो सकते हैं; Parquet 512 MiB तक buffer होता है।

    इस पृष्ठ पर

    1. विस्तृत कार्यक्षमता
    2. व्यावहारिक उदाहरण
    3. इस उपकरण का उपयोग कैसे करें
    4. सुझाव और सर्वोत्तम प्रथाएं

    स्ट्रक्चर्ड डेटा

    • {}JSON फॉर्मेटेरब्राउज़र में JSON को फॉर्मेट, मिनिफाई और वैलिडेट करें: 2/4 स्पेस या टैब इंडेंट, रिकर्सिव की सॉर्टिंग, बड़े नंबर बिल्कुल वैसे ही, .json फ़ाइल खोलें और सहेजें।
    • TSJSON से TypeScript कनवर्टरJSON सैंपल से TypeScript इंटरफ़ेस या टाइप एलियास बनाएँ: नेस्टेड टाइप, ऐरे आइटम का मर्ज, वैकल्पिक फ़ील्ड, export कीवर्ड। आपके ब्राउज़र में चलता है।
    • J{}बड़ी JSON / JSONL फ़ाइल एक्सप्लोररबड़ी JSON और JSONL फ़ाइलें स्थानीय रूप से खोलें, इंडेक्स करें, खोजें और निर्यात करें—वर्चुअल तालिका, लेज़ी ट्री और सटीक संख्याओं के साथ।
    • CSVबड़ी CSV/TSV फ़ाइल एक्सप्लोररबहुत बड़ी CSV या TSV फ़ाइलें लोकल रूप से खोलें, फ़िल्टर करें, सॉर्ट करें, ग्रुप करें, जाँचें और एक्सपोर्ट करें — कॉलम टाइप और CSV, JSONL या Parquet एक्सपोर्ट के साथ।
