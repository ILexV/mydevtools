मार्कडाउन पूर्वावलोकन

लाइव HTML पूर्वावलोकन के साथ Markdown लिखें: GFM टेबल, टास्क लिस्ट, strikethrough। साफ़ (sanitized) HTML कॉपी करें या .html फ़ाइल डाउनलोड करें।

आपका इनपुट और फ़ाइलें ब्राउज़र में ही रहते हैं

यहाँ Markdown लिखें या पेस्ट करें, या कोई उदाहरण लोड करें।

पूर्वावलोकन

टाइप करते ही रेंडर किया गया प्रीव्यू यहाँ दिखेगा।

इस पृष्ठ पर

  2. व्यावहारिक उदाहरण

  4. सुझाव और सर्वोत्तम प्रथाएं

एक तरफ़ Markdown टाइप करें और दूसरी तरफ़ टाइप करते ही रेंडर हुआ नतीजा देखें — README, issue टिप्पणियाँ, दस्तावेज़ और release notes का ड्राफ़्ट बनाने और फिर उन्हें HTML में निर्यात करने के लिए उपयोगी।

विस्तृत कार्यक्षमता

रेंडरिंग GitHub Flavored Markdown के साथ marked लाइब्रेरी से होती है: टेबल, टास्क लिस्ट - [x], strikethrough ~~text~~, fenced code blocks और सादे URL के लिए अपने-आप लिंक। एक लाइन ब्रेक <br> बन जाता है, जैसे GitHub टिप्पणियों में, इसलिए लाइनें एक पैराग्राफ में नहीं मिलतीं। Code blocks monospace फ़ॉन्ट में दिखते हैं, syntax coloring के बिना।

Markdown के अंदर का raw HTML साफ़ किया जाता है: scripts, iframes, forms, styles और onclick जैसे event attributes हटा दिए जाते हैं और javascript: लिंक ब्लॉक होते हैं, जबकि <kbd>, <details> या <sub> जैसे हानिरहित टैग बने रहते हैं। लिंक नए टैब में खुलते हैं। पूर्वावलोकन में headings एक स्तर नीचे दिखती हैं ताकि वे पेज के शीर्षक से न टकराएँ; HTML कॉपी करें और HTML डाउनलोड करें मूल <h1>–<h6> बनाए रखते हैं।

टूलबार कर्सर पर bold, italic, heading, link, image, inline code और list का सिंटैक्स डालता है, और सिंक स्क्रॉल दोनों पैनलों को एक ही सापेक्ष स्थिति पर रखता है। सब कुछ ब्राउज़र में चलता है और टूल आपका टेक्स्ट सेव नहीं करता — पेज बंद करने से पहले उसे कॉपी कर लें।

व्यावहारिक उदाहरण

टास्क लिस्ट: - [x] tests और - [ ] docs एक चेक और एक अनचेक चेकबॉक्स के रूप में दिखते हैं।

लाइन ब्रेक: दो लाइनें line one और line two ~~old~~ से <p>line one<br>line two <del>old</del></p> बनता है।

टेबल: पंक्तियाँ | A | B |, |---|---|, | 1 | 2 | header row वाली HTML टेबल बन जाती हैं।

असुरक्षित HTML: <script>alert(1)</script><b onclick=x>hi</b> सिर्फ़ <b>hi</b> के रूप में निर्यात होता है।

इस उपकरण का उपयोग कैसे करें

  1. 1

    Markdown लिखें

    मार्कडाउन एडिटर में टाइप करें। पहली बार खोलने पर एक सैंपल दस्तावेज़ दिखता है; ख़ाली पेज से शुरू करने के लिए साफ़ करें दबाएँ।

  2. 2

    टूलबार से फ़ॉर्मेट करें

    टेक्स्ट चुनें और सिंटैक्स डालने के लिए फ़ॉर्मेटिंग बटन (bold, italic, heading, link, image, code, list) इस्तेमाल करें।

  3. 3

    पूर्वावलोकन जाँचें

    पूर्वावलोकन पैनल हर कीस्ट्रोक पर अपडेट होता है; दोनों पैनल साथ स्क्रॉल करने के लिए सिंक स्क्रॉल चालू करें।

  4. 4

    निर्यात करें

    HTML कॉपी करें या मार्कडाउन कॉपी करें इस्तेमाल करें, या बुनियादी styles के साथ markdown-preview.html सेव करने के लिए HTML डाउनलोड करें।

सुझाव और सर्वोत्तम प्रथाएं

  • img/logo.png जैसे relative image paths यहाँ resolve नहीं हो सकते; इमेज देखने के लिए पूरे https:// URL इस्तेमाल करें।
  • दूसरी साइटों की इमेज आपका ब्राउज़र सीधे उन्हीं सर्वरों से लोड करता है।
  • सिर्फ़ GitHub वाली सुविधाएँ — @mentions, :smile: जैसे emoji shortcodes, Mermaid diagrams और गणित — सादे टेक्स्ट के रूप में दिखती हैं।
  • <kbd>Ctrl</kbd> या <details> जैसा inline HTML काम करता है, पर style और class attributes हटा दिए जाते हैं।
  • डाउनलोड की गई फ़ाइल हल्की styles वाला स्वतंत्र पेज है, जो प्रिंट या अटैच करने के लिए तैयार है।
