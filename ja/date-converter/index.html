日付変換

秒・ミリ秒の Unix タイムスタンプを ISO 8601、RFC 5322、UTC、ローカル時刻、カスタム形式に変換。逆変換も入力と同時に行います。

入力内容とファイルはブラウザ内に留まります

Unix タイムスタンプ（秒またはミリ秒）または ISO 8601 形式の日付を入力してください。

変換後の日付がここに表示されます。

Unix タイムスタンプを読みやすい日付に、日付文字列をタイムスタンプに変換します。秒・ミリ秒・ISO 8601 を自動判別し、ISO、RFC 5322、UTC、ローカル時刻、ヨーロッパ形式、独自パターンで出力できます。

詳細な機能

自動検出では、整数部が 11 桁以下の数値を Unix 秒、それより長い数値をミリ秒として読み取ります。負の値（1970 年より前）や小数も扱えます。それ以外は日付文字列として解析します：ISO 8601（2024-02-29T12:00:00Z）、RFC 5322（Tue, 14 Nov 2023 22:13:20 GMT）、そのほかブラウザの日付パーサーが理解できる形式です。入力タイプを秒・ミリ秒・ISO 8601 に固定することもでき、その場合 0x10 や 1e3 のような 16 進・指数表記は推測せずエラーにします。

出力形式は 8 種類：ミリ秒付き UTC の ISO 8601、ヨーロッパ形式 dd.MM.yyyy HH:mm:ss、UTC 文字列、ページの言語とタイムゾーンで表したローカル時刻、数値ゾーン +0000 付きの RFC 2822/5322、Unix 秒、Unix ミリ秒、そして yyyy・MM・dd・HH・mm・ss・SSS を組み合わせたカスタム形式です。結果は入力と同時に更新され、現在時刻ボタンで今の時刻を入れられます。

処理はすべてブラウザ標準の Date と Intl API を使う JavaScript で行い、貼り付けた値はどこにも送信されません。扱える範囲は JavaScript の日付と同じく 1970 年の前後約 27 万 3 千年で、範囲外はエラーになります。

実用例

ログのタイムスタンプ：1700000000（秒）→ ISO 8601 2023-11-14T22:13:20.000Z。同じ時刻のミリ秒値 1700000000000 も自動で判別されます。

日付から Unix 時刻へ：2024-02-29T12:00:00Z を Unix 秒で出力すると 1709208000。

エポック以前：-86400 → 1969-12-31T00:00:00.000Z（1970 年 1 月 1 日のちょうど 1 日前）。

メールヘッダーの日付：1700000000 を RFC 2822 / 5322 で出力すると Tue, 14 Nov 2023 22:13:20 +0000。

このツールの使い方

  1. 1

    値を貼り付け

    「日付 / タイムスタンプ」に Unix タイムスタンプか日付文字列を入力するか、「現在時刻 (現在)」で現在時刻を入れます。

  2. 2

    入力タイプを確認

    「入力タイプ」は「自動検出」のままで構いません。値があいまいなときは秒・ミリ秒・ISO 8601 を明示的に選びます。

  3. 3

    出力形式を選ぶ

    「出力フォーマット」で形式を選びます。「カスタムフォーマット」では yyyy-MM-dd HH:mm のようなパターンを入力します。

  4. 4

    結果をコピー

    結果は自動で更新されます（「変換」で手動再計算も可能）。「コピー」でコピーします。

ヒントとベストプラクティス

  • 1973 年 3 月より前のミリ秒値は 11 桁以下なので、自動検出では秒として読まれます。入力タイプでミリ秒を選んでください。
  • タイムゾーンのない ISO 文字列（2024-02-29T12:00）はローカルタイムゾーンで解釈されます。Z や +09:00 などのオフセットを付けると環境に依存しません。
  • ISO 8601・UTC・RFC の出力は常に UTC、ヨーロッパ形式とカスタム形式はブラウザのローカルタイムゾーンです。
  • カスタム形式では MM が月、mm が分です。それ以外の文字はそのまま出力されます。
  • ローカル時刻はページの言語で表示されるため、同じ時刻でも日本語ページと英語ページで表記が異なります。
