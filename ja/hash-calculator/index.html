ハッシュ計算機

テキストや複数ファイルを 39 種類のアルゴリズムで順番にハッシュ化。期待値との照合、速度・残り時間の表示、TXT・CSV・JSON 出力に対応。

入力内容とファイルはブラウザ内に留まります

テキストを入力または貼り付けるか、1 つ以上のファイルを追加するか、例を読み込んでください。

ファイルはテキストより優先されます。新しく選択またはドロップしたファイルは一覧に追加され、個別に削除できます。

    ハッシュ値

    選択したアルゴリズムと比較する 16 進数のダイジェスト。大文字・小文字と前後の空白は無視されます。

    ハッシュ計算機は、テキストや複数ファイルに対して最大 39 種類のハッシュ・チェックサムを計算します。MD5、SHA-1、SHA-2/SHA-3 ファミリー、BLAKE2/BLAKE3、RIPEMD、Streebog、CRC32、xxHash などに対応。ファイルはブラウザの Web Worker 内で順番に処理され、アップロードされません。ファイルごとに結果またはエラーが保持されます。

    詳細な機能

    39 種類のアルゴリズムを自由に組み合わせて選べます（名前で絞り込み可能、デフォルトに戻す で MD5・SHA-1・SHA-256 に戻ります）。localStorage に保存されるのはアルゴリズムの選択だけです。テキストは入力どおりの UTF-8 バイト列（空白や改行を含む）として計算され、結果は小文字の 16 進数で表示されます。

    選択またはドラッグ＆ドロップでファイルを追加できます。新しい選択は一覧に追加され、各ファイルは個別に削除でき、ファイルがある場合はテキストより優先されます。Rust/WebAssembly モジュールが Web Worker 内で 1 ファイルずつ 1 MiB のブロックに分けて読み込み、選択したすべてのアルゴリズムへ 1 回の読み込みで渡します。進捗には処理済みバイト数、速度、経過時間、残り時間が表示されます。あるファイルでエラーが起きても後続ファイルは処理されます。キャンセル は実行中の Worker を直ちに停止し、完了済みの結果を残したまま、処理中と未処理のファイルをキャンセル済みにします。計算 を再度押すと新しい処理が始まります。

    任意の期待する 16 進ダイジェストは再計算なしで、完了したテキストまたは各ファイルの結果と比較され、一致するアルゴリズムの行だけがマークされます。テキスト、ファイル、アルゴリズムを変更すると、次に計算するまで結果は古い状態になります。ダウンロードできる TXT・CSV・JSON レポートには、入力種別、ファイル名とサイズ、状態、処理時間、アルゴリズム ID とダイジェスト、最終エラーが含まれますが、元の内容は含まれません。完了・失敗・キャンセル済みの項目はいずれも出力に残ります。

    暗号学的ハッシュ（SHA-2、SHA-3、BLAKE2/BLAKE3、Streebog）は改ざん検知に使えます。MD5 と SHA-1 は既存のチェックサムとの照合用です。CRC32、Adler-32、xxHash、FNV-1a、FxHash、SeaHash、MetroHash は高速な非暗号チェックサムで、SipHash/HighwayHash はすべてゼロの鍵で計算されます。鍵付き MAC やパスワードハッシュは扱いません。

    実用例

    短い文字列のハッシュ: hello の MD5 は 5d41402abc4b2a76b9719d911017c592、SHA-1 は aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d、SHA-256 は 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824 です。

    末尾の改行でハッシュが変わる: hello の後に Enter を押すと SHA-256 は 5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03 になり、echo hello | sha256sum と一致します。printf hello | sha256sum は上の値と一致します。

    ダウンロードの検証: ダウンロードしたファイルを選び、SHA-256 を選択したまま、配布元のチェックサムと比較します。空の入力は常に e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 です。

    ASCII 以外の文字: привет は UTF-8 で計算されるため SHA-256 は e58f1e8c55fa105bdd3f40e5037eb0b039b5998d52c05e6cd98878dd2da5cab2 となり、その単語を含む UTF-8 ファイルへの sha256sum と同じです。

    このツールの使い方

    1. 1

      テキストを入力するかファイルを追加する

      入力テキスト に入力・貼り付けするか、ファイル（任意） で 1 つ以上のファイルを選択またはドロップします。追加の選択は一覧に加わり、各ファイルは削除できます。ファイルがある場合はテキストより優先されます。

    2. 2

      アルゴリズムと期待するダイジェストを選ぶ

      アルゴリズム で必要なものにチェックを入れます。必要なら、完了した各結果と比較する 16 進ダイジェストを貼り付けます。

    3. 3

      計算またはキャンセルする

      計算 をクリックします。ファイルは順番に処理され、バイト数、速度、経過時間、残り時間が表示されます。キャンセル は処理中のファイルを止め、完了済みの結果を保持し、未処理ファイルをキャンセル済みにします。

    4. 4

      確認して出力する

      ファイルごとのハッシュ、一致表示、状態、エラーを確認します。個別のダイジェストをコピーするか、現在の結果を TXT・CSV・JSON でダウンロードします。

    ヒントとベストプラクティス

    • sha256sum ファイル と同じ結果が欲しい場合は、内容を貼り付けずにファイル自体を計算してください。コピー時に改行コードが変わったり、最後の改行が失われたりします。
    • 整数型のチェックサム（CRC32、Adler-32、xxHash、FNV-1a）は数値の 16 進表記で表示され、zlib や crc32、xxhsum の出力と一致します。hello の CRC32 は 3610a686 です。
    • MD5 と SHA-1 は実用的な衝突が知られています。既存のチェックサムとの照合にとどめ、新しく作るなら SHA-256、SHA-3、BLAKE3 を使いましょう。
    • ファイルは 1 つずつ処理され、選択した全アルゴリズムが各ファイルの 1 回の読み込みを共有します。ブラウザのメモリ制限は引き続き適用されます。
    • 1 つのファイルの失敗で後続ファイルは止まりません。キャンセルしても完了済み結果は残り、失敗・キャンセル済みの行も TXT・CSV・JSON に出力できます。
    • API リクエストの署名や Webhook の検証には鍵付きハッシュが必要です。HMAC 計算機を使ってください。
