エンコーディング

6
B64Base64 エンコーダー / デコーダーテキストやファイルを Base64 にエンコード／デコード。標準・URLセーフのアルファベット、パディング、76文字折り返し、画像プレビューに対応。ブラウザ内で処理します。
B32Base32 エンコーダー / デコーダーRFC 4648・Crockford・z-base-32 の各アルファベットで Base32 をエンコード／デコード。パディングと大文字小文字を設定でき、テキストもファイルもブラウザ内で処理。
B58Base58 エンコーダー / デコーダーBitcoin・Flickr・Ripple のアルファベットで Base58 をエンコード／デコード。テキストと 1 MiB までのファイルに対応し、ブラウザ内でローカルに処理します。
0x16進数エンコーダー / デコーダーテキストやファイルを16進数に変換し、元に戻します。文字セットと大文字小文字を選択でき、スペース・コロン・ハイフン・0x 付きの hex もデコード可能。
%20URL エンコーダー / デコーダーURL やクエリ文字列をコンポーネント・URI・フォームの各モードでパーセントエンコード／デコード。UTF-8・UTF-16・Latin-1 に対応し、ブラウザ内で処理。
&;HTML エンティティ エンコーダー / デコーダーHTML の特殊文字を名前付き・10進数・16進数のエンティティにエスケープし、エンティティをテキストに戻します。絵文字も正しく処理。すべてブラウザ内で動作。

構造化データ

8
{}JSON フォーマッターブラウザで JSON を整形・圧縮・検証。2/4 スペースやタブのインデント、キーの再帰ソート、大きな数値をそのまま保持し、.json ファイルの読み込みと保存にも対応。
TSJSON → TypeScript コンバーターJSON サンプルから TypeScript の interface / type エイリアスを生成。ネスト型、配列要素のマージ、オプショナル、export に対応しブラウザで動作。
J{}大容量 JSON / JSONL エクスプローラー大容量の JSON と JSONL をローカルで開き、索引化、検索、エクスポート。仮想テーブル、遅延ツリー、正確な数値に対応します。
CSV大容量 CSV/TSV エクスプローラー非常に大きな CSV または TSV ファイルをローカルで開き、フィルター、確認、エクスポートできます。増分解析と仮想化テーブルを使用します。
</>XML フォーマッターブラウザで XML を整形・圧縮。2/4 スペースやタブのインデントに対応し、コメント、CDATA、処理命令を保持してパースエラーも表示します。
Y:YAML ビューティファイア/バリデータYAML を検証し、2 スペースインデントのすっきりしたブロックスタイルに整形。エラーは行と列で表示。WebAssembly でローカル実行します。
*/5Cron 式ジェネレーター分・時・日・月・曜日をフィールドごとに入力して cron 式を作成。検証、わかりやすい説明、次の 5 回の実行時刻も表示します。
cronCron 式パーサーcron 式をわかりやすい言葉で説明し、各フィールドを検証して、次の 5 回の実行時刻をローカルのタイムゾーンで表示。プリセットと @ マクロにも対応。

3
wc単語・文字数カウンター単語数・文字数・行数・段落数・文数を入力しながらカウントし、読む時間と話す時間も表示。絵文字や日本語・中国語のテキストも正しく数えます。
Aaテキストケースコンバーターテキストを camelCase、snake_case、kebab-case、タイトルケース、文のケース、大文字、小文字にワンクリックで変換。XMLHttpRequest のような識別子も正しく分割します。

4

AESAEAD ファイル暗号化/復号化AES-256-GCM または (X)ChaCha20-Poly1305 と Argon2id でファイルをパスワード暗号化し、復号も可能。ファイルはブラウザから出ません。
sshOpenSSH 鍵Ed25519・ECDSA・RSA の SSH 鍵ペアを生成（パスフレーズ任意）し、OpenSSH・PKCS#8・SPKI PEM 間で変換。すべてブラウザ内で処理。
509X.509 証明書Ed25519 または ECDSA 鍵で自己署名 X.509 証明書と CSR を作成し、PEM/DER の証明書や CSR をブラウザ内で解析します。

MyDevToolsを選ぶ理由は？

MyDevTools は、ブラウザで動く無料の開発者向けユーティリティ集です。JSON・XML・YAML の整形と検証、Base64・Hex・URL のエンコーダー、ハッシュと HMAC の計算、JWT と X.509 のツール、正規表現テスター、画像と PDF のツール、UUID・パスワード・QR コードの生成ツールがそろっています。インストールもアカウント登録も不要です。

プライバシーは仕組みそのものから生まれます。サイトは静的ページの集まりで、各ツールは入力をブラウザの中で処理します。ハッシュ計算、暗号化、画像・PDF・QR の処理など計算量の多いツールは Rust からコンパイルした WebAssembly モジュールで動き、JSON 整形やテキスト比較のような軽いツールは通常の JavaScript です。扱うパスワード、鍵、ファイルがアップロードされることはありません。

  • プライバシー第一

    入力はブラウザ内で処理され、サーバーに送信されることはありません。

  • 必要な所に WebAssembly

    ハッシュ、暗号化、画像や PDF の処理は Rust 製の WebAssembly で実行し、シンプルなツールは軽量な JavaScript で動きます。

  • オフライン対応

    一度開いたページはオフラインでも動作します。PWA をインストールすればすぐに起動できます。

  • 多言語対応

    インターフェースとツールの説明は 10 言語で利用できます。

  • 完全無料

    すべてのツールは無料です。隠れた支払いやサブスクリプションはありません。

  • 自分だけのツールセット

    よく使うツールに星を付けましょう。お気に入りと最近使ったツールはブラウザに保存されます。
