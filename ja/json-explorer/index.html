大容量 JSON / JSONL エクスプローラー

大容量の JSON と JSONL をローカルで開き、索引化、検索、エクスポート。仮想テーブル、遅延ツリー、正確な数値に対応します。

入力内容とファイルはブラウザ内に留まります

ローカルファイル

JSON、JSONL、NDJSON ファイルをドロップ

ファイルはブラウザー内に留まります。JSONL は逐次読み込み、通常 JSON は設定したメモリ上限を使います。

通常 JSON は選択した 8–64 MiB まで読み込みます。JSONL は 1 MiB チャンク、1 レコード 1–8 MiB、最大深度 256 でストリーム処理します。これは明示的な安全上限です。

ファイル、検索、派生列は端末外へ送信・保存されません。形式と安全設定だけを記憶します。

ファイルを処理中

レコード

構造とレコードを調べるローカル JSON または JSONL を選択してください。

検索・フィルター・投影

1 行に 1 つ、最大 100 フィールドの RFC 6901 JSON Pointer を入力します。空なら自動検出した最上位列を使います。~ は ~0、/ は ~1 でエスケープします。投影 JSONL は正確なポインターをキーに持つフラットなオブジェクトで、欠損フィールドは null です。

自動列は先頭 10,000 レコードを標本化し、最大 100 フィールドを表示します。エンコード後の JSON Pointer が 256 文字を超える列名と、合計 16,384 文字を超える列名メタデータは自動追加しません。入力フィールドは削除されず、正確な JSON Pointer で指定できます。セル表示は 512 文字まで、検査と出力は完全な値を使います。

選択したレコード

テーブル行を選択すると完全な元レコードを読み込みます。

個人データをアップロードせずに、大きな JSON 配列と行区切り JSON を探索できます。ローカルに疎な索引を作り、仮想テーブルの小さな範囲だけを描画し、レコードやツリー分岐を必要時に読み込みます。
詳細な機能
JSONL / NDJSON は UTF-8 を 1 MiB ずつ復号します。BOM、CRLF、改行のない最終行に対応し、エラーは物理行と列を示します。保持するのは疎なチェックポイントと上限付き列メタデータだけで、遠いテーブル範囲、フィルター、出力では再読込します。



通常 JSON はオブジェクト、配列、スカラーのルートと遅延構造ツリーに対応し、ルート配列はレコード表でも閲覧できます。単一文書は 8–64 MiB の明示上限内で worker が解析します。深度は最大 256、JSONL レコードは 1–8 MiB です。



数値の字句を保持します。9007199254740993、1.0、指数表記は出力時に JavaScript Number を通りません。フィルターは一致配列全体を作らず全件を走査します。
実用例
API ログ：.ndjson を開き、値から timeout を検索し、/service を billing で絞ります。行選択で完全な元 JSON を表示します。



ネスト項目：/id と /user/name を投影します。/a~1b は a/b キーです。CSV はポインターを列、JSONL はキーに使います。



大きな ID：{"id":9007199254740993,"price":1.0} は両方の数値表記を保持します。



大きな配列：必要な枝だけを展開し、要素ごとの DOM 行を作らずスクロールします。
このツールの使い方
  1. 1
    形式と上限を選択
    自動、JSON、JSONL/NDJSON と、ファイル・レコード・深度の上限を選びます。
  2. 2
    ローカルファイルを開く
    ドロップまたは選択します。Worker がバイト、時間、速度、残り時間を表示し、キャンセルするとセッションを破棄します。
  3. 3
    検索または投影
    キーや値を検索し、RFC 6901 パスと部分文字列、または投影ポインターを入力します。
  4. 4
    検査と出力
    スクロール、完全レコード表示、ツリー展開を行い、全一致を JSONL または CSV で保存します。
ヒントとベストプラクティス
    

  • 確実な自動検出には .jsonl または .ndjson を使い、曖昧なファイルは明示指定してください。
    • 

  • 空の JSONL 行は無視しますが、エラー位置は物理行番号です。
    • 

  • 空 JSONL は 0 件の有効結果、空の通常 JSON は無効です。
    • 

  • JSON Pointer は / で区切り、~0 がチルダ、~1 がスラッシュです。
    • 

  • =、+、-、@ の CSV 数式保護は既定で有効です。
    • 

  • 出力は全フィルター行を含み、256 MiB 上限前で停止します。
    •

  • {}JSON フォーマッターブラウザで JSON を整形・圧縮・検証。2/4 スペースやタブのインデント、キーの再帰ソート、大きな数値をそのまま保持し、.json ファイルの読み込みと保存にも対応。
  • TSJSON → TypeScript コンバーターJSON サンプルから TypeScript の interface / type エイリアスを生成。ネスト型、配列要素のマージ、オプショナル、export に対応しブラウザで動作。
  • CSV大容量 CSV/TSV エクスプローラー非常に大きな CSV または TSV ファイルをローカルで開き、フィルター、確認、エクスポートできます。増分解析と仮想化テーブルを使用します。
