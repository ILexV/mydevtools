Windows コンパニオン

ブラウザーツールを Windows PC に接続

ローカルエージェントは、選択した MyDevTools ツールに、PC 上で明示的に許可された機能を提供します。インストーラーは現在のユーザーのプロファイルに配置し、アカウントは不要で、Windows トレイから制御できます。

ダウンロード、実行、ペアリング

ダウンロードするのは現在のユーザー向けインストーラーです。エージェントをユーザープロファイルに配置します。新しいインストーラーを実行すると、そのコピーを置き換えます。

  1. 1

    ダウンロード

    インストーラーをダウンロードします。より新しいビルドで再実行すると、インストール済みのエージェントを置き換えます。

  2. 2

    実行

    インストーラーを開きます。すでに起動しているエージェントを止めてから、新しいコピーを書き込みます。Windows がダウンロード済みアプリの実行確認を求める場合があります。管理者権限は不要です。

  3. 3

    ペアリング

    エージェントに表示された最新コードを MyDevTools ツールに入力します。ペアリングで許可されるのは、そのツールが要求した機能だけです。

限定的な権限モデル

エージェントはアカウント、リモートサービス、汎用コマンド実行機能ではありません。

  • 登録、ログイン、MyDevTools クラウドプロキシは不要です。
  • 管理者権限は不要で、Windows サービスもインストールしません。インストーラーは現在のユーザーだけに適用されます。
  • 更新されるワンタイムコードで、期限付きブラウザーセッションを開始します。ブラウザーは接続トークンを最長 8 時間またはエージェントの再起動まで保存しますが、ペアリングコードは保存しません。
  • この PC 上だけで待ち受けます。リクエストとプローブはエージェントから対象へ直接送られ、プロキシを設定した場合だけプロキシを経由します。プライベートネットワーク宛ては、エージェントのウィンドウで許可するまでブロックされます。経路上のルーターは私有アドレスでも表示されます。

制御するのはあなたです

小さなウィンドウを閉じると非表示になり、トレイアイコンから再度開けます。

  • バージョンと現在のペアリングコードを確認できます。
  • 自動起動は任意で、既定ではオフです。Windows のユーザー設定を使用し、新しいインストーラーがエージェントを置き換えてもその設定は追従します。
  • 「Allow local network and this PC as targets」は既定でオフです。オンにすると、ツールがプライベートとループバックのアドレスに到達し、自分のネットワークをスキャンできるようになります。選択は記憶され、オフにすると実行中のプライベート宛てのスキャンは停止します。
  • 終了するとローカルサーバーが停止し、アクティブなセッションが完全に取り消されます。

この PC 上の暗号化ボールト

ボールトを要求したツールは、データをブラウザーではなくエージェントに保存します。

  • 各ファイルは AES-256-GCM で暗号化され、鍵はユーザー アカウント用に Windows が保護します。
  • シークレットとクライアント証明書の秘密鍵は書き込み専用です。ページはリクエストで使えますが、読み戻すことはできません。
  • サイトごとに専用のボールトがあり、あるサイトが別のサイトのデータを読むことはできません。
  • 別のコンピューターへ移すには、エージェントのウィンドウで「Export vault…」と「Import vault…」を使います。すべてのサイトが 1 つのファイルにまとまり、パスワードで暗号化されます（Argon2id と AES-256-GCM）。ページからエクスポートを始めることはできません。

利用可能な機能

このリリースは HTTP リクエスト、WebSocket 接続、Server-Sent Events、ワークスペースとシークレット用のボールト、ICMP 経路追跡、DNS 検索、TCP 確認、TLS 検査、WHOIS、ASN 検索、ポートスキャナー、ネットワークスキャナーをペアリングできます。各ツールは固有の名前付き機能を要求し、将来の機能が自動的に許可されることはないため、更新後にツールが再ペアリングを求めることがあります。

ダウンロードを確認

このインストーラーにはデジタル署名がないため、Windows SmartScreen が警告またはブロックする場合があります。Windows の保護を無効にしないでください。上記の SHA-256 値とダウンロードしたファイルを比較して整合性を確認できますが、一致しても発行元の署名の代わりにはなりません。
