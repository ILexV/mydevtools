ローカルデータプレイグラウンド

ローカルの CSV、JSON、JSONL、Parquet を読み込み、ブラウザー内で DuckDB SQL を実行します。

入力内容とファイルはブラウザ内に留まります

ローカルデータを読み込む

データファイルをここにドロップ

CSV、TSV、JSON、JSONL、NDJSON、Parquet。複数ファイルを読み込んで JOIN できます。

生成例では名前を引用するため、空白や非ラテン文字も使用できます。

ファイルはこの端末内に留まります。DuckDB はセルフホストされた専用 Web Worker で動作し、SQL から URL や他のファイルは読めません。

上限：入力 1 GiB、文字コード変換 128 MiB、DuckDB メモリ 512 MiB、プレビュー 100,000 行、1 ページ 500 行、代替ダウンロードまたは Parquet 512 MiB。JSON/JSONL は分割処理せず、フラットなレコード集合として全体をメモリ上でデコードします。キャンセルすると全テーブルを解放します。

ローカル処理

読み込み済みテーブル

テーブルはまだありません。

    SQL クエリ

    Ctrl または Cmd + Enter で実行します。ローカルの読み取り専用 SELECT または WITH 1 文だけを許可します。

    結果は worker 内で実体化され、上限付きページで読み取られます。
    クエリ結果

    テーブルを読み込み、クエリを実行すると結果を閲覧できます。

    結果全体をエクスポート

    CSV、JSON、JSONL は選択先へ分割書き込みします。Parquet は単一の上限付きバッファーで生成します。代替ダウンロードは 512 MiB までです。

    ローカルデータプレイグラウンドは DuckDB-WASM をブラウザー内で実行し、アップロードせずに CSV、JSON、JSONL、Parquet を検索します。各ファイルに SQL テーブル名を付け、複数ファイルを JOIN できます。

    詳細な機能

    DuckDB と Web Worker は MyDevTools から配信され、最初のインポート時だけ読み込まれます。SharedArrayBuffer、クロスオリジン分離、サーバー、外部 CDN は不要です。外部アクセス、拡張機能、URL リーダー、データベース変更 SQL は無効です。

    エディターは SELECT と WITH、フィルター、集計、並べ替え、JOIN に対応します。プレビュー上限は明示的に 100,000 行で、仮想テーブルは一度に最大 500 行だけ要求します。整数と小数は JavaScript Number に変換しません。

    CSV、JSON、JSONL はバックプレッシャー付きで分割出力します。Parquet は単一バッファーで生成します。代替ダウンロードと Parquet は 512 MiB までです。

    実用例

    SELECT：orders.csv を orders として読み込み、SELECT * FROM "orders" LIMIT 100 を実行します。

    WHERE：状態でローカル絞り込みします。

    GROUP BY：国別にグループ化して金額を合計します。

    JOIN：customers.parquet を追加し、共通キーで結合します。

    このツールの使い方

    1. 1

      ファイルを読み込む

      形式、テーブル名、CSV オプションを選びます。

    2. 2

      ローカル SQL を書く

      SELECT、WHERE、GROUP BY、JOIN の例を編集し、Ctrl/Cmd + Enter を押します。

    3. 3

      結果を見る

      仮想テーブルは小さなページだけを転送・描画します。

    4. 4

      エクスポートまたは再起動

      CSV、JSON、JSONL、Parquet に出力できます。キャンセルや再起動で worker とデータを解放します。

    ヒントとベストプラクティス

    • テーブル名と列名を二重引用符で囲んでください。
    • 大きなファイルでは LIMIT と限定的な WHERE を使ってください。
    • CSV 型推論は先頭が 0 の識別子を数値化することがあります。文字列を保つ場合はデータ形式コンバーターを使います。
    • BIGINT と DECIMAL は Number 経由で丸めません。
    • キャンセル後はファイルの再読み込みが必要です。
    • CSV/JSON/JSONL はストリーム出力でき、Parquet は 512 MiB までバッファーします。

    構造化データ

    • {}JSON フォーマッターブラウザで JSON を整形・圧縮・検証。2/4 スペースやタブのインデント、キーの再帰ソート、大きな数値をそのまま保持し、.json ファイルの読み込みと保存にも対応。
    • TSJSON → TypeScript コンバーターJSON サンプルから TypeScript の interface / type エイリアスを生成。ネスト型、配列要素のマージ、オプショナル、export に対応しブラウザで動作。
    • J{}大容量 JSON / JSONL エクスプローラー大容量の JSON と JSONL をローカルで開き、索引化、検索、エクスポート。仮想テーブル、遅延ツリー、正確な数値に対応します。
    • CSV大容量 CSV/TSV エクスプローラー非常に大きな CSV または TSV ファイルをローカルで開き、フィルター、確認、エクスポートできます。増分解析と仮想化テーブルを使用します。
