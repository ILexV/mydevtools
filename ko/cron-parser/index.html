cron

Cron 표현식 파서

Cron 표현식을 쉬운 말로 설명하고 각 필드를 검증하며, 다음 5회 실행 시간을 로컬 시간대로 보여 줍니다. 빠른 프리셋과 @매크로도 지원합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

다섯 필드의 cron 표현식이나 @매크로를 입력하면 언제 실행되는지, 각 필드가 무슨 뜻인지, 다음 다섯 번의 실행 시간을 쉬운 말로 보여 줍니다. 검사가 엄격해서 분 값 61이나 */0 같은 단계 오타를 무시하지 않고 짚어 줍니다.

상세 기능

지원 문법: *, 단일 값, 범위 1-5, 목록 1,15, 단계 */15와 0-30/10, 월 이름 JAN–DEC, 요일 이름 SUN–SAT, 일요일을 뜻하는 7, 날짜 필드의 L(그 달의 마지막 날)과 ?, 그리고 @yearly, @monthly, @weekly, @daily, @hourly, @reboot. 모든 필드는 허용 범위와 비교해 검사되며, 오류 메시지는 해당 필드와 허용되는 값을 알려 줍니다.

설명은 인터페이스 언어로 작성됩니다. 예를 들어 0 9 * * MON-FRI는 “평일 09:00에”로 읽힙니다. 일(day of month)과 요일(day of week)이 모두 지정되면 Vixie cron 규칙에 따라 둘 중 하나만 맞아도 실행됩니다. 다음 실행 시간은 브라우저 시간대로 최대 30년 앞까지 계산되며, 존재하지 않는 날짜(0 0 30 2 *)는 예정된 실행이 없다고 표시됩니다.

결과는 입력하는 즉시 갱신되고, 빠른 프리셋 버튼으로 자주 쓰는 스케줄을 채울 수 있습니다. 다음 실행 시간은 시간대 오프셋이 포함된 ISO 8601, 미국식, 로캘 형식 등 여러 날짜 형식으로 볼 수 있으며 선택한 형식은 기억됩니다. 서버로는 아무것도 전송되지 않습니다.

실용적인 예제

야간 백업: 0 2 * * * — “매일 02:00에”.

폴링: */15 * * * * — “15분마다”.

월말 보고서: 0 0 L * * — “매월 마지막 날 00:00에”.

일 또는 요일: 0 0 13 * 5 — “매월 13일 또는 매주 금요일 00:00에”: 13일의 금요일에만이 아니라 매월 13일과 매주 금요일에 실행됩니다.

이 도구 사용 방법

  1. 1

    표현식 입력

    Cron 표현식 필드에 입력하거나 빠른 프리셋 중 하나를 누릅니다.

  2. 2

    설명 읽기

    사람이 읽을 수 있는 형식은 스케줄을 문장으로 보여 주고, 표현식 구성 요소는 다섯 필드 각각의 의미를 나열합니다.

  3. 3

    실행 시간 확인

    다음 실행 시간을 확인하고 필요하면 날짜 형식을 바꿉니다.

  4. 4

    복사

    복사를 눌러 설명을 복사합니다. 예를 들어 코드 주석에 넣을 수 있습니다.

팁 및 모범 사례

  • Cron에는 시간대 필드가 없습니다. 서버는 자체 시간대(흔히 UTC)로 작업을 실행하지만, 여기 표시되는 시간은 브라우저 시간대 기준입니다.
  • 클래식한 다섯 필드만 지원합니다. 초나 연도 필드가 있는 Quartz 스타일 표현식은 거부됩니다.
  • 단계는 상위 단위마다 다시 시작합니다. 0 */7 * * *는 00:00, 07:00, 14:00, 21:00에 실행되고 다시 00:00에 실행됩니다.
  • @reboot는 시스템 시작 시 한 번만 실행되므로 다음 실행 시간이 없습니다.
  • 개별 필드로 표현식을 만들려면 Cron 표현식 생성기를 사용하세요.

구조화된 데이터

  • {}JSON 포맷터브라우저에서 JSON을 포맷·압축·검증합니다. 2/4칸 공백 또는 탭 들여쓰기, 재귀적 키 정렬, 큰 숫자 원형 유지, .json 파일 열기와 저장 지원.
  • TSJSON → TypeScript 변환기JSON 샘플에서 TypeScript 인터페이스나 타입 별칭을 생성합니다. 중첩 타입, 배열 항목 병합, 선택적 필드, export 키워드 지원. 브라우저에서 실행.
  • J{}대용량 JSON / JSONL 탐색기대용량 JSON과 JSONL을 로컬에서 열고 색인, 검색, 내보내기하세요. 가상 표, 지연 트리, 정확한 숫자를 제공합니다.
  • CSV대용량 CSV/TSV 탐색기증분 파싱과 가상화 테이블을 사용해 매우 큰 CSV 또는 TSV 파일을 로컬에서 열고 필터링하고 살펴보고 내보냅니다.
