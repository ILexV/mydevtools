해시 계산기

텍스트나 여러 파일을 39가지 알고리즘으로 순서대로 해시합니다. 예상 다이제스트 비교, 속도·남은 시간 표시, TXT·CSV·JSON 내보내기를 지원합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

텍스트를 입력하거나 붙여넣고, 파일을 하나 이상 추가하거나 예제를 불러오세요.

파일이 텍스트보다 우선합니다. 새로 선택하거나 끌어 놓은 파일은 목록에 추가되며 개별 삭제할 수 있습니다.

    알고리즘

    해시 값

    계산을 누르면 선택한 알고리즘의 해시 값이 여기에 표시됩니다.

    선택한 알고리즘과 비교할 16진수 다이제스트입니다. 대소문자와 앞뒤 공백은 무시됩니다.

    해시 계산기는 텍스트나 여러 파일에 대해 최대 39가지 해시·체크섬 알고리즘을 계산합니다. MD5, SHA-1, SHA-2·SHA-3 계열, BLAKE2/BLAKE3, RIPEMD, Streebog, CRC32, xxHash 등을 지원합니다. 파일은 브라우저의 Web Worker에서 순서대로 처리되며 업로드되지 않고, 파일마다 자체 결과나 오류가 유지됩니다.

    상세 기능

    39가지 알고리즘을 원하는 대로 조합해 선택할 수 있습니다(이름으로 목록 필터링 가능, 기본값으로 초기화를 누르면 MD5, SHA-1, SHA-256으로 돌아갑니다). localStorage에는 알고리즘 선택만 저장됩니다. 텍스트는 입력한 그대로의 UTF-8 바이트(공백과 줄바꿈 포함)로 계산되며 결과는 소문자 16진수로 표시됩니다.

    선택하거나 끌어 놓아 파일을 추가할 수 있습니다. 새 선택은 목록에 이어 붙고 파일마다 삭제할 수 있으며, 파일이 있으면 텍스트보다 우선합니다. Rust/WebAssembly 모듈이 Web Worker 안에서 파일을 하나씩 1 MiB 단위로 읽고 한 번의 읽기로 선택한 모든 알고리즘에 데이터를 전달합니다. 진행 상황에는 처리한 바이트, 속도, 경과 시간, 남은 시간이 표시됩니다. 한 파일의 오류가 뒤의 파일 처리를 막지 않습니다. 취소는 실행 중인 Worker를 즉시 종료하고 완료된 결과를 보존하며, 처리 중인 파일과 남은 파일을 취소됨으로 표시합니다. 계산을 다시 누르면 새 실행을 시작합니다.

    선택 사항인 예상 16진수 다이제스트는 다시 해시하지 않고 완료된 텍스트나 각 파일 결과와 비교되며, 일치하는 알고리즘 행만 표시됩니다. 텍스트, 파일 또는 알고리즘을 바꾸면 다시 계산할 때까지 결과가 오래된 상태가 됩니다. 다운로드 가능한 TXT, CSV, JSON 보고서에는 원본 유형, 파일 이름과 크기, 상태, 소요 시간, 알고리즘 ID와 다이제스트, 최종 오류가 포함되지만 원본 내용은 포함되지 않습니다. 완료, 실패, 취소된 항목 모두 내보내기에 남습니다.

    암호학적 해시(SHA-2, SHA-3, BLAKE2/BLAKE3, Streebog)는 무결성 검증에 적합하고, MD5와 SHA-1은 기존 체크섬과 대조할 때만 쓰세요. CRC32, Adler-32, xxHash, FNV-1a, FxHash, SeaHash, MetroHash는 빠른 비암호 체크섬이며 SipHash/HighwayHash는 0으로 채운 키로 계산됩니다. 키 기반 MAC이나 비밀번호 해시는 계산하지 않습니다.

    실용적인 예제

    짧은 문자열의 해시: hello의 MD5는 5d41402abc4b2a76b9719d911017c592, SHA-1은 aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d, SHA-256은 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824입니다.

    끝의 줄바꿈이 해시를 바꿉니다: hello 뒤에 Enter를 누르면 SHA-256이 5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03로, echo hello | sha256sum과 같습니다. printf hello | sha256sum은 위의 값과 같습니다.

    다운로드 검증: 받은 파일을 선택하고 SHA-256을 유지한 채 다운로드 링크 옆에 게시된 체크섬과 비교합니다. 빈 입력은 항상 e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855입니다.

    ASCII가 아닌 텍스트: привет은 UTF-8로 계산되어 SHA-256이 e58f1e8c55fa105bdd3f40e5037eb0b039b5998d52c05e6cd98878dd2da5cab2이며, 이 단어가 담긴 UTF-8 파일에 sha256sum을 실행한 결과와 같습니다.

    이 도구 사용 방법

    1. 1

      텍스트 입력 또는 파일 추가

      입력 텍스트에 입력하거나 붙여넣고, 또는 파일 (선택 사항)에서 파일을 하나 이상 선택하거나 끌어 놓습니다. 추가 선택은 목록에 이어 붙고 파일마다 삭제할 수 있으며, 파일이 있으면 텍스트보다 우선합니다.

    2. 2

      알고리즘과 예상 다이제스트 선택

      알고리즘에서 필요한 항목을 체크합니다. 필요하면 완료된 각 결과와 비교할 16진수 다이제스트를 붙여넣습니다.

    3. 3

      계산 또는 취소

      계산을 클릭합니다. 파일은 순서대로 처리되고 바이트, 속도, 경과 시간, 남은 시간이 표시됩니다. 취소는 처리 중인 파일을 멈추고 완료된 결과를 보존하며 처리되지 않은 파일을 취소됨으로 표시합니다.

    4. 4

      확인 및 내보내기

      파일별 해시, 일치 표시, 상태 또는 오류를 확인합니다. 개별 다이제스트를 복사하거나 현재 결과를 TXT, CSV 또는 JSON으로 다운로드합니다.

    팁 및 모범 사례

    • sha256sum 파일과 같은 결과를 원하면 내용을 붙여넣지 말고 파일 자체를 계산하세요. 복사 과정에서 줄바꿈 형식이 바뀌거나 마지막 줄바꿈이 사라질 수 있습니다.
    • 정수형 체크섬(CRC32, Adler-32, xxHash, FNV-1a)은 숫자를 16진수로 표시하며 zlib, crc32, xxhsum의 출력과 같습니다. hello의 CRC32는 3610a686입니다.
    • MD5와 SHA-1은 실제로 충돌을 만들 수 있으므로 기존 체크섬과 비교할 때만 쓰고, 새로 만들 때는 SHA-256, SHA-3, BLAKE3를 쓰세요.
    • 파일은 하나씩 처리되며 선택한 모든 알고리즘이 파일마다 한 번의 읽기를 공유합니다. 브라우저의 메모리 제한은 계속 적용됩니다.
    • 한 파일이 실패해도 뒤의 파일은 계속 처리됩니다. 취소해도 완료된 결과는 남고, 실패하거나 취소된 행도 TXT, CSV, JSON으로 내보낼 수 있습니다.
    • API 요청 서명이나 웹훅 검증에는 키가 있는 해시가 필요합니다. HMAC 계산기를 사용하세요.

    관련 도구

    • ***비밀번호 생성기대문자, 소문자, 숫자, 원하는 기호로 4~128자 무작위 비밀번호를 만듭니다. 브라우저의 안전한 난수 생성기를 사용합니다.
    • MACHMAC 계산기비밀 키로 메시지의 HMAC-SHA256 또는 HMAC-SHA512를 입력하는 즉시 계산합니다. 16진수 출력, UTF-8 입력, 빈 메시지도 지원.
    • uuidUUID/GUID 생성기무작위 UUID v4 또는 시간순 UUID v7을 최대 100개까지 한 번에 생성합니다. 하이픈, 하이픈 없음, 중괄호, URN 형식과 복사·TXT 다운로드를 지원합니다.
    • B64Base64 인코더 / 디코더텍스트나 파일을 Base64로 인코딩하고 다시 디코딩합니다. 표준·URL 안전 알파벳, 패딩, 76자 줄 바꿈, 이미지 미리보기 지원. 브라우저에서 처리.
