HTTP 클라이언트

계정이나 MyDevTools 프록시 없이 Windows 로컬 에이전트로 HTTP 요청을 보냅니다.

요청은 Windows PC에서 대상 서버로 직접 전송됩니다

저장된 요청

보낸 요청을 작성한 그대로 최근 100개까지 보관합니다. 변수와 시크릿은 치환되지 않으며 응답은 저장하지 않습니다. 작업 공간과 같은 곳에 저장됩니다.

    i 항목을 폴더로 끌거나 빈 공간으로 끌어 루트로 이동하세요. 마우스 오른쪽 버튼을 클릭하거나 Shift+F10을 눌러 작업 메뉴를 여세요.

    요청 URL, 헤더(비밀 정보 포함), 본문은 이 브라우저에만 자동 저장됩니다. 응답은 저장되지 않습니다.

    폴더로 이동

    시크릿

    값은 에이전트의 암호화된 저장소에 보관되며 페이지로 다시 돌아오지 않습니다. URL, 헤더 또는 본문에 {{secret:name}}를 넣으면 에이전트가 지정된 호스트에만 값을 대입하고 응답에서는 숨깁니다.

      아직 시크릿이 없습니다.

      시크릿 추가

      환경

      URL, 매개변수, 헤더, 본문, 인증에 {{이름}}을 쓰세요. 활성 환경이 폴더 변수보다, 폴더 변수가 전역 변수보다 우선합니다. 쓰기 전용 값은 변수를 {{secret:이름}}으로 지정하세요.

      클라이언트 설정

      프록시

      에이전트가 HTTP 프록시를 통해 연결합니다. https는 CONNECT, http는 절대 URL을 사용합니다. 프록시 비밀번호는 작업 공간과 함께 저장됩니다.

      클라이언트 인증서 (mTLS)

      서버가 요청하면 에이전트가 목록의 https 호스트에 인증서를 제시합니다. 개인 키는 에이전트에 암호화되어 저장되며 페이지로 돌아오지 않습니다. 암호화되지 않은 키의 PEM 파일을 사용하세요. .pfx는 먼저 변환합니다: openssl pkcs12 -in cert.pfx -out cert.pem -nodes

      클라이언트 인증서를 추가하려면 비밀 보관소가 있는 에이전트에 연결하세요.

        아직 클라이언트 인증서가 없습니다.

        인증서 추가

        저장된 인증서와 키를 유지하려면 두 파일을 모두 비워 두세요.

        쿠키

        응답의 쿠키가 여기에 모이고 일치하는 요청과 함께 전송됩니다. 에이전트가 리디렉션을 포함한 모든 홉에서 도메인, 경로, Secure 기준으로 고릅니다. «쿠키 보관»을 끄면 페이지를 닫을 때까지 유지됩니다.

          아직 쿠키가 없습니다.

          쿠키 추가

          인증

          변수

          이 폴더와 하위 폴더의 모든 요청에서 {{이름}}으로 사용할 수 있습니다. 가까운 폴더가 우선합니다.

          스크립트

          이 폴더와 하위 폴더의 모든 요청에서 요청 자체 스크립트보다 먼저 실행됩니다.

          데이터

          요청은 트리 순서대로 스크립트와 함께 하나씩 실행되며, 스크립트가 바꾼 변수는 저장됩니다. 데이터 파일이 있으면 행마다 한 번씩 반복하며 pm.iterationData와 {{열 이름}}으로 값을 씁니다. 이 창을 닫으면 실행이 중지됩니다.

          요청

              cURL 가져오기

              curl 명령을 붙여 넣으세요. 예: 브라우저 DevTools의 “Copy as cURL”(bash 또는 cmd). 새 요청이 만들어지며, URL 필드에 붙여 넣은 명령은 열린 요청을 대신합니다.

              요청 코드

              열린 요청으로 만듭니다. 변수는 치환되고 {{secret:…}}는 자리표시자로 남으며 파일은 이름으로 참조됩니다. AWS 서명과 OAuth 토큰은 제한된 시간 동안만 유효합니다.

              연결되지 않음연결 설정
              로컬 에이전트
              페어링 코드
              에이전트 창의 최신 코드를 입력하세요. 매 시도 후 지워집니다.
              세션이 만료되거나 에이전트가 다시 시작될 때까지 이 브라우저에 연결이 저장됩니다. 연결 해제하면 삭제됩니다.

              Windows 에이전트 설정
              이 도구에 필요한 Windows 로컬 에이전트를 다운로드하고 실행한 뒤 이 페이지로 돌아오세요.
              Windows 에이전트 안내 및 다운로드
              1. MyDevTools Agent를 실행합니다. Windows 시스템 트레이에 아이콘이 나타납니다.
              2. 트레이 아이콘에서 에이전트 창을 열고 표시된 페어링 코드를 복사합니다.
              3. 아래에 코드를 입력합니다. 브라우저가 로컬 네트워크 권한을 요청하면 이 연결에 허용하세요.
              요청 본문은 최대 1 MiB, 응답은 16 MiB, 제한 시간은 120초입니다.
              사설·루프백·LAN 대상은 기본 차단됩니다. 꼭 필요할 때만 에이전트 창에서 “Allow local network and this PC as targets” 항목을 켜세요. 페어링은 http.request를 추가하고 이 브라우저에 이미 부여된 기능은 유지합니다. 스캐너 권한은 부여하지 않습니다.
              브라우저는 요청 정보를 127.0.0.1의 에이전트에만 보냅니다. 에이전트가 대상에 직접 연결하므로 URL, 헤더와 본문은 PC 밖으로 전송될 수 있습니다. MyDevTools 서버는 이를 받거나 프록시하지 않습니다. URL, 헤더와 비밀 정보를 포함한 요청 초안과 본문은 이 브라우저에 자동 저장되지만 응답은 저장되지 않습니다. 연결 토큰은 별도로 최대 8시간 또는 에이전트가 다시 시작될 때까지 저장되며 페어링 코드는 저장되지 않습니다. 에이전트가 암호화 저장소를 제공하면 초안이 그곳으로 옮겨지고 브라우저에서 삭제됩니다.
              매개변수는 URL과 동기화됩니다. 선택하지 않은 행은 전송되지 않습니다.
              요청에 포함키값행 삭제
              헤더를 키와 값 행으로 추가하세요. 선택하지 않은 행은 전송되지 않습니다. Authorization은 명시적으로 입력한 경우에만 전송됩니다.
              요청에 포함키값행 삭제
              요청이 본문 없이 전송됩니다.
              구문 강조가 제공됩니다. 명시적으로 요청한 경우에만 서식이 적용됩니다. 선택한 형식이 Content-Type을 제공하지만 활성화된 헤더가 있으면 해당 값이 우선합니다.
              체크한 행은 키=값 쌍으로 Content-Type application/x-www-form-urlencoded와 함께 전송됩니다. 활성 헤더가 덮어쓰면 그 값을 씁니다. 키와 값에 {{변수}}를 쓸 수 있습니다.
              체크한 각 행은 텍스트 필드 또는 파일입니다. boundary가 포함된 Content-Type multipart/form-data가 자동으로 설정되며 직접 지정한 값을 대체합니다. 파일은 이 페이지의 메모리에만 보관됩니다. 새로 고친 뒤에는 다시 선택하세요. 파일 안의 변수는 치환되지 않습니다.
              파일이 그대로 전송됩니다. 활성 헤더가 덮어쓰지 않으면 Content-Type은 파일 형식입니다. 파일은 이 페이지의 메모리에만 보관됩니다. 새로 고친 뒤에는 다시 선택하세요. 파일 안의 변수는 치환되지 않습니다.
              JSON {"query", "variables"}로 Content-Type application/json과 함께 전송됩니다. 두 필드 모두 {{변수}}를 쓸 수 있습니다.
              Postman 방식의 JavaScript: pm.environment, pm.variables, pm.request, pm.response, pm.test, pm.expect. 스크립트는 네트워크에 접근할 수 없는 격리된 워커에서 최대 10초 동안 실행됩니다. Ctrl+Enter로 보냅니다.

                        상세 기능
                        브라우저는 일회용 코드로 127.0.0.1 에이전트와 명시적으로 페어링합니다. 연결 토큰은 이 브라우저에 최대 8시간 또는 에이전트가 다시 시작될 때까지 저장되며 코드는 저장되지 않습니다. 토큰은 http.request만 허용합니다. 요청은 대상으로 직접 갑니다. 사설 네트워크에는 에이전트 창의 “Allow local network and this PC as targets” 항목(또는 --allow-private)이 필요하고, 리디렉션은 기본 해제되며 출처가 바뀌면 민감한 헤더가 제거됩니다. URL, 헤더와 비밀 정보를 포함한 요청 초안과 본문은 나중에 다시 열 수 있도록 이 브라우저에 자동 저장되며 응답은 저장되지 않습니다. 연결 토큰은 별도로 최대 8시간 또는 에이전트가 다시 시작될 때까지 저장됩니다. 최신 에이전트에서는 초안을 브라우저 대신 에이전트가 컴퓨터에 암호화해 보관합니다.
                        실용적인 예제
                        JSON에는 GET, API에는 Content-Type: application/json을 지정한 POST, 메타데이터에는 HEAD를 사용하세요. Authorization: Bearer …는 대상이 요구할 때만 추가하며 MyDevTools가 아닌 대상에 전송됩니다.
