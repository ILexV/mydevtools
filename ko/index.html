B32Base32 인코더 / 디코더RFC 4648, Crockford, z-base-32 알파벳으로 Base32를 인코딩·디코딩합니다. 패딩과 대소문자 옵션 지원, 텍스트와 파일 모두 브라우저에서 처리.
B58Base58 인코더 / 디코더Bitcoin, Flickr, Ripple 알파벳으로 Base58을 인코딩·디코딩합니다. 텍스트와 1 MiB 이하 파일 지원, 브라우저에서 로컬로 처리하며 업로드하지 않습니다.
0xHex 인코더 / 디코더텍스트나 파일을 16진수로 변환하고 되돌립니다. 문자셋과 대소문자 선택 가능, 공백·콜론·하이픈·0x 접두사가 있는 hex도 디코딩. 브라우저에서 처리.
%20URL 인코더 / 디코더URL과 쿼리 문자열을 컴포넌트, URI, 폼 모드로 퍼센트 인코딩·디코딩합니다. UTF-8, UTF-16, Latin-1 문자셋 지원, 브라우저에서 로컬로 처리.
&;HTML 엔티티 인코더 / 디코더HTML 특수 문자를 명명된, 10진수, 16진수 엔티티로 이스케이프하고 엔티티를 텍스트로 디코딩합니다. 이모지도 올바르게 처리. 모두 브라우저에서 동작.

MyDevTools를 선택하는 이유는 무엇인가요?

MyDevTools는 브라우저에서 동작하는 무료 개발자 유틸리티 모음입니다. JSON, XML, YAML 포매터와 검증기, Base64, Hex, URL 인코더, 해시와 HMAC 계산기, JWT와 X.509 도구, 정규식 테스터, 이미지와 PDF 도구, UUID·비밀번호·QR 코드 생성기를 제공합니다. 설치할 것도, 만들 계정도 없습니다.

개인정보 보호는 구조에서 나옵니다. 사이트는 정적 페이지로 이루어져 있고, 각 도구는 입력을 브라우저 안에서 처리합니다. 해시, 암호화, 이미지·PDF·QR 처리처럼 계산이 많은 도구는 Rust로 컴파일한 WebAssembly 모듈로 동작하고, JSON 포매터나 텍스트 비교 같은 가벼운 도구는 일반 JavaScript입니다. 작업하는 비밀번호, 키, 파일은 업로드되지 않습니다.

  • 프라이버시 우선

    입력은 브라우저에서 처리되며 서버로 전송되지 않습니다.

  • 필요한 곳에 WebAssembly

    해시, 암호화, 이미지와 PDF 처리는 Rust로 컴파일한 WebAssembly에서 실행되고, 간단한 도구는 가벼운 JavaScript로 동작합니다.

  • 오프라인 지원

    한 번 연 페이지는 연결이 없어도 계속 동작합니다. 빠르게 열려면 PWA를 설치하세요.

  • 다국어 지원

    인터페이스와 도구 설명을 10개 언어로 제공합니다.

  • 완전 무료

    모든 도구는 무료입니다. 숨겨진 결제나 구독이 없습니다.

  • 나만의 도구 모음

    자주 쓰는 도구에 별표를 표시하세요. 즐겨찾기와 최근 사용한 도구는 브라우저에 저장됩니다.
