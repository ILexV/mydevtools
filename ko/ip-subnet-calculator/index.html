IP 서브넷 계산기

IPv4·IPv6 서브넷 계산기: CIDR 또는 IP와 마스크로 네트워크, 브로드캐스트, 넷마스크, 호스트 범위, 주소 수, 주소 유형을 계산합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

    CIDR 표기로 IPv4와 IPv6 서브넷을 계산합니다. 네트워크 주소, 프리픽스 마스크, 호스트·주소 범위와 정확한 주소 개수를 보여 줍니다. IPv4는 점으로 구분한 넷마스크도 입력할 수 있으며 브로드캐스트, 와일드카드 마스크, 2진 보기도 제공합니다.

    상세 기능

    IPv4는 192.168.1.10/24, 주소 뒤에 공백과 마스크(192.168.1.10 255.255.255.0), 또는 주소만(/32로 처리) 입력합니다. 표에는 주소, 넷마스크, 와일드카드 마스크, 프리픽스가 붙은 네트워크, 브로드캐스트, 첫·마지막 사용 가능 호스트, 사용 가능 및 전체 호스트 수, 전통적인 클래스(A–E), 주소 유형(사설 RFC 1918, 공유 CGNAT 100.64.0.0/10, 루프백, 링크 로컬, 문서용, 멀티캐스트, 예약됨, 공인)이 표시됩니다. /31은 사용 가능 주소가 2개인 점대점 링크(RFC 3021), /32는 단일 호스트로 처리합니다.

    콜론이 들어간 입력은 IPv6로 해석합니다: 2001:db8::1/64 또는 프리픽스 없는 주소(/128). 주소의 축약형(RFC 5952)과 전체 표기, 네트워크, 프리픽스 마스크, 첫 주소와 마지막 주소, 정확한 주소 수(최대 2^128까지 생략 없이)를 보여 줍니다. IPv6에는 브로드캐스트가 없으므로 프리픽스의 모든 주소를 셉니다. 유형 배지는 글로벌 유니캐스트, 고유 로컬(fc00::/7), 링크 로컬(fe80::/10), 멀티캐스트, 문서용(2001:db8::/32), 루프백 등 특수 범위를 표시합니다.

    서브넷으로 분할은 계산한 네트워크를 더 긴 프리픽스의 같은 크기 서브넷으로 나눕니다(예: /24를 /26 네 개로, IPv6 /48을 /64 서브넷으로). 전체 서브넷 수(IPv6에서도 정확), 서브넷당 주소 수, 각 서브넷의 호스트 범위(IPv4는 브로드캐스트 포함) 표를 보여 주며, 최대 처음 256개까지 나열하고 목록 복사로 CIDR 형식으로 복사할 수 있습니다.

    계산은 Rust로 컴파일한 작은 WebAssembly 모듈이 수행합니다. 처음 계산 버튼을 누를 때 내려받으며, 입력한 주소는 어디에도 전송되지 않습니다. 존 ID(fe80::1%eth0)나 10.0.0.1-10.0.0.9 같은 범위 표기는 지원하지 않습니다.

    실용적인 예제

    사무실 LAN: 192.168.1.10/24 → 네트워크 192.168.1.0/24, 브로드캐스트 192.168.1.255, 호스트 192.168.1.1–192.168.1.254(사용 가능 254개), 유형 '사설'.

    프리픽스 대신 마스크: 172.16.0.1 255.240.0.0은 /12로 인식됩니다 — 네트워크 172.16.0.0, 브로드캐스트 172.31.255.255, 사용 가능 호스트 1,048,574개.

    점대점 링크: 10.0.0.1/31은 10.0.0.0과 10.0.0.1 두 주소를 모두 사용할 수 있습니다. RFC 3021에 따라 /31에서는 네트워크·브로드캐스트 주소를 예약하지 않습니다.

    IPv6 /64: 2001:db8:abcd:12::1/64 → 네트워크 2001:db8:abcd:12::, 마지막 주소 2001:db8:abcd:12:ffff:ffff:ffff:ffff, 주소 18,446,744,073,709,551,616개(2^64), 유형 '문서용'.

    이 도구 사용 방법

    1. 1

      주소 입력

      'IP 주소 / CIDR'에 IPv4 또는 IPv6 주소를 입력합니다. 프리픽스를 붙이거나(10.20.30.40/22, 2001:db8::/48) IPv4라면 공백 뒤에 마스크를 씁니다.

    2. 2

      계산

      '계산' 버튼을 누르거나 Enter 키를 누릅니다. '예시'의 항목을 클릭하면 입력과 계산이 한 번에 됩니다.

    3. 3

      확인 및 복사

      표에서 네트워크, 범위, 주소 수를 확인하고 복사 아이콘으로 네트워크나 브로드캐스트(IPv6는 마지막 주소)를 복사합니다.

    팁 및 모범 사례

    • 네트워크 주소를 정확히 입력할 필요는 없습니다: 10.20.30.40/22는 네트워크 10.20.28.0으로 정규화됩니다.
    • 프리픽스 없는 IPv4 주소는 /32, IPv6 주소는 /128로 처리됩니다.
    • 유형 배지는 입력한 주소 기준입니다: 100.64.0.1은 RFC 1918 사설 주소는 아니지만 '공인'이 아니라 '공유 (CGNAT)'입니다.
    • IPv6 LAN 서브넷은 보통 /64이고, 점대점 링크에는 /127을 씁니다(RFC 6164).
    • 2진 보기(IPv4 전용)로 마스크가 네트워크 비트와 호스트 비트를 어디서 나누는지 확인할 수 있습니다.

    • UTC날짜 변환기초·밀리초 Unix 타임스탬프를 ISO 8601, RFC 5322, UTC, 현지 시간, 사용자 정의 형식으로 변환하고, 반대로도 입력 즉시 변환합니다.
