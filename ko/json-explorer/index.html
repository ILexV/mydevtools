대용량 JSON / JSONL 탐색기

대용량 JSON과 JSONL을 로컬에서 열고 색인, 검색, 내보내기하세요. 가상 표, 지연 트리, 정확한 숫자를 제공합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

로컬 파일

JSON, JSONL 또는 NDJSON 파일 놓기

파일은 이 브라우저에만 남습니다. JSONL은 점진적으로 읽고 일반 JSON은 설정한 메모리 제한을 사용합니다.

일반 JSON은 선택한 8–64 MiB까지만 불러옵니다. JSONL은 1 MiB 청크, 레코드당 1–8 MiB, 최대 깊이 256으로 스트리밍합니다. 이는 명시적인 안전 제한입니다.

파일, 검색어, 파생 열은 기기를 떠나거나 저장되지 않습니다. 형식과 안전 설정만 기억합니다.

파일 처리 중

레코드

구조와 레코드를 살펴볼 로컬 JSON 또는 JSONL 파일을 선택하세요.

검색, 필터 및 투영

줄마다 RFC 6901 JSON Pointer 하나씩, 최대 100개 필드를 입력합니다. 빈 목록은 자동 최상위 열을 유지합니다. ~는 ~0, /는 ~1로 이스케이프합니다. 투영 JSONL은 정확한 포인터를 키로 쓰는 평면 객체이며 누락 필드는 null입니다.

자동 열은 처음 10,000개 레코드를 표본화하고 최대 100개 필드를 표시합니다. 인코딩된 JSON Pointer가 256자를 넘는 열 이름과 합계 16,384자를 넘는 열 이름 메타데이터는 자동 추가하지 않습니다. 필드는 제거되지 않으며 정확한 JSON Pointer로 지정할 수 있습니다. 셀 미리보기는 512자, 검사와 내보내기는 전체 값을 사용합니다.

선택한 레코드

표 행을 선택하면 완전한 원본 레코드를 불러옵니다.

JSON 구조
이 값에는 하위 항목이 없습니다.
현재 결과 내보내기
보이는 행만이 아니라 일치하는 모든 레코드를 다시 스캔합니다. 출력은 제한된 청크로 만들며 브라우저 한도는 256 MiB입니다. CSV는 RFC 4180, CRLF, UTF-8 BOM을 사용합니다.

비공개 데이터를 업로드하지 않고 큰 JSON 배열과 줄 단위 JSON을 탐색하세요. 로컬 희소 색인을 만들고 가상 표의 작은 창만 렌더링하며 레코드나 트리 가지를 필요할 때 불러옵니다.
상세 기능
JSONL / NDJSON은 UTF-8을 1 MiB 청크로 디코딩합니다. BOM, CRLF, 줄바꿈 없는 마지막 줄을 처리하고 오류는 물리 행과 열을 표시합니다. 희소 체크포인트와 제한된 열 메타데이터만 보관하며 먼 표 범위, 필터, 내보내기에서는 파일을 다시 읽습니다.



일반 JSON은 객체, 배열, 스칼라 루트와 지연 구조 트리를 지원합니다. 루트 배열은 레코드 표로도 볼 수 있습니다. 단일 문서는 8–64 MiB 명시적 제한 안에서 worker가 파싱합니다. 최대 깊이는 256, JSONL 레코드는 1–8 MiB입니다.



숫자 원문을 유지합니다. 9007199254740993, 1.0, 지수 표기는 내보낼 때 JavaScript Number를 거치지 않습니다. 필터는 전체 일치 배열을 만들지 않고 모두 스캔합니다.
실용적인 예제
API 로그: .ndjson을 열고 값에서 timeout을 찾은 뒤 /service를 billing으로 필터링합니다. 행을 선택하면 완전한 원본을 불러옵니다.



중첩 필드: /id와 /user/name을 투영합니다. /a~1b는 a/b 키입니다. CSV는 포인터를 열로, JSONL은 키로 사용합니다.



큰 ID: {"id":9007199254740993,"price":1.0}은 두 숫자 표기를 그대로 유지합니다.



큰 배열: 필요한 가지만 펼치고 항목별 DOM 행 없이 스크롤합니다.
이 도구 사용 방법
  1. 1
    형식과 제한 선택
    자동, JSON 또는 JSONL/NDJSON과 파일·레코드·깊이 제한을 선택합니다.
  2. 2
    로컬 파일 열기
    놓거나 선택합니다. Worker가 바이트, 시간, 처리량, 예상 시간을 표시하며 취소하면 세션을 폐기합니다.
  3. 3
    검색 또는 투영
    키나 값을 검색하고 RFC 6901 경로와 부분 문자열을 입력하거나 투영 포인터를 나열합니다.
  4. 4
    검사 및 내보내기
    스크롤하고 전체 레코드를 열고 트리를 펼치거나 모든 일치 항목을 JSONL 또는 CSV로 받습니다.
팁 및 모범 사례
    

  • 안정적인 자동 감지에는 .jsonl 또는 .ndjson을 쓰고 모호한 파일은 형식을 직접 선택하세요.
    • 

  • 빈 JSONL 줄은 무시하지만 오류는 실제 파일 행 번호를 사용합니다.
    • 

  • 빈 JSONL은 0개 레코드의 유효한 결과이고 빈 일반 JSON은 유효하지 않습니다.
    • 

  • JSON Pointer는 /로 구분하고 ~0은 물결표, ~1은 슬래시입니다.
    • 

  • =, +, -, @ CSV 수식 보호는 기본으로 켜집니다.
    • 

  • 내보내기는 필터된 모든 행을 포함하며 256 MiB 전에 멈춥니다.
    •
