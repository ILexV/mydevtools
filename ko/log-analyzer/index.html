대용량 로그 분석기

매우 큰 Serilog, .NET, Nginx, JSON Lines 및 텍스트 로그를 로컬에서 스트리밍, 필터링, 차트 분석 및 내보내기합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

여기에 로그 파일을 놓으세요

여기에 로그 파일을 놓으세요

.log, .txt, .jsonl 또는 .ndjson. 파일은 이 기기에만 유지됩니다.

로컬 Web Worker가 제한된 크기의 청크로 파일을 스캔합니다. 입력 내용과 필터는 업로드되거나 저장되지 않습니다.

가져오기 설정

안전 제한: 줄당 2 MiB, 레코드 1억 개, 필터 및 집계 레이블당 512자, 고유 집계 값 2,000개 및 고유 타임스탬프 분 4,096개.

주요 오류 유형

    주요 메시지 템플릿

      집계 카디널리티가 안전 제한에 도달했습니다. 레코드 수와 필터링은 계속 정확하지만, 드물게 나타나는 새 레이블이나 타임스탬프 분은 차트에서 생략됩니다.

      정확한 원본 줄

      원본 소스 텍스트를 확인하려면 결과 행을 선택하세요.

      응답성을 위해 화면의 원본 줄은 64 KiB로 축약됩니다. 내보내기에서는 모든 바이트가 보존됩니다.
      필터링된 전체 결과 내보내기
      내보내기는 모든 레코드를 다시 스캔하고 일치하는 원본 줄을 기존 줄 바꿈 문자와 함께 스트리밍합니다. 화면에 표시된 미리보기만 내보내지는 않습니다.
      기본 저장 선택기를 지원하지 않는 브라우저는 최대 512 MiB로 제한된 메모리 내 다운로드 대체 방식을 사용합니다.

      대용량 로그 분석기는 프로덕션 로그를 브라우저에서 완전히 분석합니다. 운영 데이터를 업로드하지 않고 Serilog JSON과 Compact Log Event Format, 일반 .NET 텍스트, Nginx 액세스 및 오류 로그, 일반 NDJSON과 일반 텍스트를 지원합니다.
      상세 기능
      분석기는 Web Worker에서 제한된 크기의 청크를 한 번에 하나씩 읽고, 희소 파일 오프셋과 제한된 집계 카운터만 유지합니다. 타임스탬프, 심각도, 소스, 요청 또는 상관관계 ID, 렌더링된 메시지, 메시지 템플릿 및 예외 유형을 추출합니다. 필터는 전체 소스를 다시 스캔하며, 가상 테이블은 화면에 보이는 작은 페이지만 요청합니다. 비정상 구조화 줄은 자동으로 사라지지 않고 계속 표시되며 개수에도 포함됩니다.
      


      내보내기는 필터링된 전체 결과를 다시 스캔하고 원본 UTF-8 줄 바이트를 LF, CRLF 또는 CR 종결 문자와 함께 스트리밍합니다. 렌더링된 Serilog @m 텍스트가 표시되며, @mt는 주요 메시지 개수를 집계하는 그룹화 키로 유지됩니다. 입력이나 결과는 localStorage에 저장되지 않습니다.
      실용적인 예제
      Serilog CLEF: {"@t":"2026-10-17T10:01:00Z","@l":"Error","@mt":"Payment failed for {OrderId}","@m":"Payment failed for 17"}은 변경되는 주문 ID를 하나의 템플릿으로 그룹화합니다.
      


      Nginx 액세스: 결합 로그 요청에는 HTTP 상태 코드 계열에 따라 심각도가 지정됩니다.
      


      상관관계 검색: 요청 ID를 입력하여 여러 소스의 이벤트를 추려낸 다음, 일치하는 모든 원본 줄을 내보내세요.
      이 도구 사용 방법
      1. 1
        형식 선택
        일반 파일에는 자동 감지를 사용하거나 Serilog/.NET, Nginx, JSON Lines 또는 텍스트를 명시적으로 선택하세요.
      2. 2
        로그 열기
        로컬 파일 하나를 놓고 정확한 바이트 수, 경과 시간 및 처리량을 확인하세요. 취소하면 부분적으로 생성된 Worker 세션이 제거됩니다.
      3. 3
        필터링 및 검사
        포함 범위의 시작 및 종료 시간, 심각도, 소스, 요청/상관관계 ID와 자유 텍스트 검색을 조합하세요. 가상 결과 테이블을 탐색하고 원본 텍스트를 볼 행을 선택하세요.
      4. 4
        내보내기
        필터링된 전체 결과를 다운로드하세요. Worker가 원본 파일을 다시 스캔하고 역압력을 적용하여 일치 항목을 모두 스트리밍합니다.
      팁 및 모범 사례
        

      • 임의의 JSON 객체를 Serilog로 해석하지 않아야 한다면 명시적인 JSON Lines 프리셋을 선택하세요.
        • 

      • 비정상 개수는 선택한 구조화 프리셋과 일치하지 않는 줄을 의미합니다. 일반 텍스트는 유효한 모든 UTF-8 줄을 허용합니다.
        • 

      • 심각도를 선택하지 않으면 결과가 없습니다. 시간 범위는 타임스탬프를 분석할 수 없는 레코드를 제외합니다.
        • 

      • 메모리 안전을 위해 집계 레이블과 타임스탬프 분의 카디널리티가 제한되지만, 전체 개수, 필터링, 페이징 및 내보내기는 계속 정확합니다.
        • 

      • 자유 텍스트 검색은 디코딩된 정확한 원본 줄을 대소문자 구분 없이 검색합니다.
        •

      구조화된 데이터
      • {}JSON 포맷터브라우저에서 JSON을 포맷·압축·검증합니다. 2/4칸 공백 또는 탭 들여쓰기, 재귀적 키 정렬, 큰 숫자 원형 유지, .json 파일 열기와 저장 지원.
      • TSJSON → TypeScript 변환기JSON 샘플에서 TypeScript 인터페이스나 타입 별칭을 생성합니다. 중첩 타입, 배열 항목 병합, 선택적 필드, export 키워드 지원. 브라우저에서 실행.
      • J{}대용량 JSON / JSONL 탐색기대용량 JSON과 JSONL을 로컬에서 열고 색인, 검색, 내보내기하세요. 가상 표, 지연 트리, 정확한 숫자를 제공합니다.
      • CSV대용량 CSV/TSV 탐색기증분 파싱과 가상화 테이블을 사용해 매우 큰 CSV 또는 TSV 파일을 로컬에서 열고 필터링하고 살펴보고 내보냅니다.
