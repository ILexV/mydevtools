OpenSSH 키

Ed25519, ECDSA, RSA SSH 키 쌍을 만들고(암호문 선택), OpenSSH·PKCS#8·SPKI PEM 형식 간에 변환합니다. 모두 브라우저에서 처리.

OpenSSH 키 도구는 SSH 키 쌍(Ed25519, ECDSA P-256/P-384, RSA 3072/4096)을 생성하고 OpenSSH, PKCS#8, SPKI PEM 형식 사이에서 키를 변환합니다. 키 생성과 변환은 브라우저에서 이뤄지며 개인 키는 어디로도 전송되지 않습니다.

상세 기능

생성하면 OpenSSH 개인 키(-----BEGIN OPENSSH PRIVATE KEY-----)와 authorized_keys에 바로 넣을 수 있는 공개 키 줄(ssh-ed25519 AAAA…)이 나옵니다. 암호문을 지정하면 개인 키는 ssh-keygen과 같은 방식(bcrypt-pbkdf 16라운드 + aes256-ctr)으로 암호화됩니다. 암호문은 공백까지 입력한 그대로 사용됩니다. 키 생성은 Web Worker에서 실행되어 Ed25519와 ECDSA는 몇 밀리초, RSA 4096은 몇 초에서 1분 정도 걸리며, 그동안 페이지는 계속 사용할 수 있고 경과 시간과 취소 버튼이 표시됩니다.

가져오기는 붙여넣은 키나 키 파일(드래그 앤 드롭 가능)을 받습니다. OpenSSH 공개 키 줄(ssh-ed25519, ecdsa-sha2-nistp256/384, ssh-rsa), OpenSSH 개인 키, SPKI PUBLIC KEY PEM, PKCS#8 PRIVATE KEY / ENCRYPTED PRIVATE KEY PEM을 지원합니다. 개인 키에서는 공개 키 줄을 만들고, 공개 키는 알고리즘과 주석을 보여 줍니다. 변환은 OpenSSH 개인 키를 PKCS#8로, OpenSSH 공개 키 줄을 SPKI PEM으로(반대도 가능), PKCS#8을 OpenSSH로 바꿉니다.

결과는 복사하거나 id_key / id_key.pub(생성) 또는 imported.key / imported.pub(가져오기)로 내려받을 수 있습니다. 3072비트 미만 RSA처럼 약한 선택에는 경고가 표시됩니다. 암호문의 공백을 잘라내던 이전 버전에서 만든 키도 열립니다. 입력한 암호문이 거부되면 앞뒤 공백을 뺀 값을 시도하고 안내를 표시합니다.

실용적인 예제

서버용 새 키: Ed25519를 고르고 키 생성을 누른 뒤, 공개 키 줄(ssh-ed25519 AAAAC3NzaC1lZDI1NTE5로 시작)을 서버의 ~/.ssh/authorized_keys에 추가하고 개인 키는 권한 600으로 ~/.ssh/id_ed25519에 저장합니다.

오래된 시스템용 RSA: 장비가 Ed25519를 받지 않으면 RSA 4096을 고릅니다. 생성에 시간이 걸리며 경과 초가 표시되고 취소로 멈출 수 있습니다.

OpenSSH 공개 키를 PEM으로: ssh-ed25519 AAAA… user@host를 붙여넣고 변환을 누르면 -----BEGIN PUBLIC KEY-----와 MCowBQYDK2VwAyEA로 시작하는 SPKI PEM이 나옵니다. OpenSSL, Java 같은 라이브러리가 기대하는 형식입니다.

코드에서 SSH 키 사용: OPENSSH PRIVATE KEY(암호문은 필드에 입력)를 붙여넣고 변환을 누르면 OpenSSH 형식을 읽지 못하는 라이브러리를 위한 PKCS#8 -----BEGIN PRIVATE KEY----- 블록을 얻습니다.

이 도구 사용 방법

  1. 1

    키 종류 선택

    생성에서 알고리즘을 고릅니다: Ed25519 (Recommended), ECDSA P-256/P-384, RSA 3072/4096. 키 크기는 RSA일 때만 활성화됩니다.

  2. 2

    필요하면 암호문 설정

    암호문 (선택 사항)에 입력하면 개인 키가 암호화됩니다. 비워 두면 암호화되지 않은 키가 만들어집니다.

  3. 3

    생성

    키 생성을 클릭합니다. RSA에서는 경과 시간과 취소가 있는 진행률 표시줄이 나타납니다.

  4. 4

    키 저장

    공개 키와 개인 키의 복사 또는 다운로드를 사용합니다.

  5. 5

    기존 키 가져오기 또는 변환

    가져오기에 키를 붙여넣거나 키 파일을 놓은 뒤, 가져오기로 내용을 확인하거나 변환으로 형식을 바꿉니다.

팁 및 모범 사례

  • Ed25519 키는 짧고 빠르며 OpenSSH 6.5 이상과 주요 Git 호스팅에서 쓸 수 있습니다. RSA는 꼭 필요한 곳에서만 쓰세요.
  • "ssh-rsa uses SHA-1" 경고는 예전 서명 방식에 관한 것입니다. 최신 OpenSSH는 RSA 키로 rsa-sha2-256/512 서명을 사용합니다.
  • 암호문이 없는 개인 키는 저장된 디스크만큼만 안전합니다. 노트북에 둘 키에는 암호문을 거세요.
  • 앞이나 뒤에 공백이 있는 암호문은 다른 암호문입니다. 실수하지 않도록 필드에 안내가 표시됩니다.
  • 내려받은 개인 키는 chmod 600을 해야 ssh가 사용합니다.

관련 도구

  • MACHMAC 계산기비밀 키로 메시지의 HMAC-SHA256 또는 HMAC-SHA512를 입력하는 즉시 계산합니다. 16진수 출력, UTF-8 입력, 빈 메시지도 지원.
  • AESAEAD 파일 암호화/복호화AES-256-GCM 또는 (X)ChaCha20-Poly1305와 Argon2id로 파일을 비밀번호 암호화하고 다시 복호화합니다. 파일은 브라우저를 떠나지 않습니다.
  • 509X.509 인증서Ed25519 또는 ECDSA 키로 자체 서명 X.509 인증서와 CSR을 만들고, PEM/DER 인증서나 CSR을 브라우저에서 바로 해석합니다.
  • sha해시 계산기텍스트나 여러 파일을 39가지 알고리즘으로 순서대로 해시합니다. 예상 다이제스트 비교, 속도·남은 시간 표시, TXT·CSV·JSON 내보내기를 지원합니다.
