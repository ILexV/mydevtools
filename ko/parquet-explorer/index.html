Parquet 탐색기

로컬 Parquet 파일을 열고 스키마와 행 그룹을 확인하고, 행을 필터링하고 그룹별로 요약하며, 선택한 열을 가상 표에서 살펴봅니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

Parquet 파일을 여기에 놓으세요

.parquet 파일 하나. 이 기기에 남습니다.

푸터, 선택한 열, 내보내기는 Web Worker에서 읽습니다. 파일 내용과 스키마는 업로드되거나 저장되지 않습니다.

Parquet 읽는 중

탐색기

Parquet 파일을 선택하면 스키마, 행 그룹, 가상 열 미리보기가 나타납니다.

행 필터링

행은 모든 조건과 일치해야 합니다. 숫자는 값으로 정확히 비교하고(64비트 정수와 decimal은 모든 자릿수 유지), 타임스탬프는 시점으로 비교하며(2024-03-01 또는 2024-03-01T12:00:00Z 입력), 불리언은 true/false로, 텍스트와 중첩 값은 표시된 텍스트로 비교합니다. 빈 값은 ‘비어 있음’에만 일치합니다. 필터는 파일 전체에서 조건이 걸린 열을 한 번 검색하고, 이후 표, 그룹 요약, 내보내기는 일치하는 행을 사용합니다.

그룹화 및 요약

현재 필터의 행을 그룹별로 셉니다. 요약할 열을 지정하면 비어 있지 않은 값의 개수, 최솟값, 최댓값이 추가되고, 정수, decimal, 부동소수점 열에서는 정확한 합계와 평균도 계산됩니다. 타임스탬프는 ISO 텍스트로 그룹화하고 비교합니다. 최대 100,000개 그룹까지 가능합니다.

선택한 행

더 긴 셀 값을 보려면 표의 행을 선택하세요.

화면의 값은 잘려 있습니다. 내보내기는 셀 한도까지 값을 유지합니다.

내보내기

권장: 스프레드시트가 =, +, -, @ 수식으로 실행할 수 있는 셀 앞에 아포스트로피를 붙입니다.

수식 보호가 꺼져 있습니다. CSV는 원문 값을 유지하지만 스프레드시트에서 열면 위험할 수 있습니다.

일치하는 모든 행의 선택한 열을 행 그룹 단위로 읽어 백프레셔와 함께 선택한 파일로 스트리밍합니다. 일치하는 행이 없는 창은 건너뜁니다. 기본 저장 선택기가 없으면 512 MiB 대체 다운로드를 사용합니다.

offset index가 있는 행 그룹은 65,536행 단위 창으로 읽고, 없는 그룹은 선택한 열마다 통째로 풉니다. 중첩 값은 JSON이 됩니다. INT64는 십진 표기를 유지합니다. 비압축, Snappy, gzip, Brotli, Zstd, LZ4, LZ4_RAW를 지원합니다. LZO는 지원하지 않습니다. 정렬, SQL, Parquet 쓰기는 이 탐색기에 포함되지 않습니다.

Parquet 탐색기는 Apache Parquet 파일을 브라우저 안에서만 엽니다. 푸터에서 스키마와 행 그룹 통계를 읽고, 표시한 열만 디코딩하므로 넓거나 긴 파일이 HTML 표 하나로 바뀌지 않습니다.

상세 기능

파일은 이 기기에 남습니다. Web Worker가 PAR1 푸터를 조각으로 읽고 최상위 열, 물리·논리 타입, 반복, 각 열의 압축 코덱을 보여 줍니다. 행 그룹에는 행 수와 압축 크기가 나옵니다. 표는 가상화되어 있어, 스크롤하면 체크한 열의 작은 행 창만 요청합니다.

JavaScript 숫자에 들어가지 않는 INT64와 다른 정수는 십진 자릿수를 유지합니다. 타임스탬프는 UTC ISO-8601 문자열이 됩니다. 이진 셀은 소문자 16진수로 보입니다. 중첩 구조와 목록은 JSON입니다. 중복된 열 이름에는 번호를 붙여 JSONL 키를 고유하게 합니다.

선택한 열의 모든 행을 읽어 백프레셔와 함께 선택한 파일로 스트리밍합니다. 기본 저장 선택기가 없으면 512 MiB 대체 다운로드를 사용합니다.

선택한 열 청크는 통째로 풀립니다. 중첩 값은 JSON이 됩니다. INT64는 십진 표기를 유지합니다. 비압축, Snappy, gzip, Brotli, Zstd, LZ4, LZ4_RAW를 지원합니다. LZO는 지원하지 않습니다. SQL 필터, 정렬, Parquet 쓰기는 없습니다.

필터는 어떤 열에든 최대 8개의 조건(포함, 같음, 비교, 빈 값 검사)을 조합합니다. 숫자는 정확히, 타임스탬프는 시점으로 비교합니다. 결과는 행마다 1비트로 보관하므로 수억 행짜리 파일도 일치하는 행을 메모리에 담지 않고 필터링합니다. 그룹 요약은 값별로 행을 세고 정확한 합계, 평균, 최솟값, 최댓값을 더하며 CSV나 JSONL로 내보낼 수 있습니다.

실용적인 예제

평탄한 열: name(문자열)과 id(INT64)가 있는 파일은 두 열이 모두 체크된 채로 열립니다. 9007199254740993 같은 id는 표, CSV, JSONL에서 그 십진 표기 그대로입니다.

열 투영: 「모두 선택」을 해제하고 name만 남긴 뒤 스크롤하세요. 그 보기에서는 다른 열 청크를 디코딩하지 않습니다. 내보내기에도 체크한 열만 들어갑니다.

여러 행 그룹: 목록은 각 그룹의 행 수와 코덱을 보여 줍니다. 표는 그것들을 하나의 행 순서로 읽습니다.

수식처럼 보이는 문자열: 보호가 켜져 있으면 =1+1은 CSV에서 '=1+1이 됩니다. JSONL은 원래 문자열을 유지합니다.

이 도구 사용 방법

  1. 1

    로컬 파일 열기

    .parquet 파일을 놓거나 선택합니다. 푸터를 읽는 동안 바이트, 속도, 경과 시간이 보입니다. 취소한 뒤 파일을 다시 고르면 처음부터입니다.

  2. 2

    스키마 읽기

    열 타입, 반복, 압축을 확인한 다음 행 그룹 크기를 봅니다. 푸터에 메타데이터 쌍이 있으면 함께 나열합니다.

  3. 3

    열 살펴보기

    필요 없는 열의 체크를 해제합니다. 가상 표를 스크롤하고 행을 선택하면 더 긴 셀 값을 볼 수 있습니다.

  4. 4

    필터링 및 요약

    amount > 100, category 같음 books 같은 조건을 추가하고 적용하면 표, 선택한 행, 내보내기가 일치하는 행으로 바뀝니다. 한 열로 그룹화하고 다른 열을 요약하면 개수, 합계, 평균, 최솟값, 최댓값을 얻을 수 있습니다.

  5. 5

    내보내기

    선택한 열의 모든 행을 읽어 백프레셔와 함께 선택한 파일로 스트리밍합니다. 기본 저장 선택기가 없으면 512 MiB 대체 다운로드를 사용합니다.

팁 및 모범 사례

  • 현재 표와 다운로드는 체크한 열만 디코딩합니다. 키만 필요하면 큰 이진 열은 끄세요.
  • offset index를 기록한 파일은 65,536행 단위 창으로 읽을 수 있습니다. 없으면 선택한 열 청크가 해당 행 그룹 단위로 통째로 풀리므로, 아주 큰 행 그룹은 메모리를 더 씁니다.
  • JSONL은 안전한 JavaScript 숫자에 들어가지 않는 정수를 반올림된 수가 아니라 십진 문자열로 씁니다.
  • 최상위 열이 512개를 넘으면 거부합니다. 행 그룹은 처음 500개만 나열하고, 요약의 개수에는 나머지도 포함됩니다.
  • LZO 압축은 지원하지 않습니다. 비압축, Snappy, gzip, Brotli, Zstd, LZ4, LZ4_RAW는 지원합니다.
  • 이 페이지는 SQL을 실행하거나 정렬하지 않습니다. 조인, 정렬, Parquet 쓰기는 SQL 플레이그라운드와 변환기에서 할 수 있습니다.

  • TSJSON → TypeScript 변환기JSON 샘플에서 TypeScript 인터페이스나 타입 별칭을 생성합니다. 중첩 타입, 배열 항목 병합, 선택적 필드, export 키워드 지원. 브라우저에서 실행.
  • J{}대용량 JSON / JSONL 탐색기대용량 JSON과 JSONL을 로컬에서 열고 색인, 검색, 내보내기하세요. 가상 표, 지연 트리, 정확한 숫자를 제공합니다.
