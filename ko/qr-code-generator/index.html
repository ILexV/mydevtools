링크, 텍스트, Wi-Fi 문자열로 QR 코드를 만들고 색상, 스타일, 오류 정정 수준, 크기를 고른 뒤 로고를 넣어 PNG나 SVG로 다운로드하세요. 코드는 브라우저에서 생성됩니다.

상세 기능

내용은 UTF-8 바이트로 인코딩되므로 어떤 문자나 이모지도 쓸 수 있습니다. 오류 정정 L, M, Q, H는 각각 약 7, 15, 25, 30%의 손상을 복구할 수 있으며, 수준이 높을수록 코드가 촘촘해집니다. 용량은 L에서 최대 2953바이트, H에서 1273바이트이며, 더 긴 내용은 깨진 코드 대신 오류를 표시합니다.

PNG는 정확히 256, 512, 1024, 2048 px이며 최소 4모듈의 여백(quiet zone)이 들어갑니다. 사각형, 점, 둥근 모서리 스타일은 데이터 모듈 모양을 바꾸지만 세 개의 위치 찾기 패턴은 항상 사각형으로 남으므로 어떤 스타일이든 읽을 수 있습니다. 로고(PNG, JPEG, WebP)는 배경 패드와 함께 가운데에 배치되며, 크기가 오류 정정 수준에 따라 커집니다(H에서 코드 너비의 최대 30%). 로고를 넣을 때는 Q나 H를 쓰고 실제 휴대폰으로 테스트하세요. 어떤 로고 크기도 스캔을 보장하지 않습니다. SVG는 로고 없는 사각형 스타일에서만 제공됩니다.

색상은 색상 선택기나 16진수 값(#RRGGBB)으로 지정하며, 잘못된 값은 표시됩니다. 두 색상의 대비가 표시되고, 낮거나 반전된 경우 경고가 나타납니다. 생성은 브라우저에서 Rust/WebAssembly로 실행되며, 입력하거나 옵션을 바꾸면 미리보기가 자동으로 업데이트됩니다.

실용적인 예제

웹사이트 링크: https://example.com을 수준 M, 512 × 512로 만들면 정확히 512×512 px인 qrcode.png가 나옵니다. QR 코드 스캐너로 다시 읽으면 링크 열기 버튼이 나타납니다.

Wi-Fi 접속: WIFI:T:WPA;S:MyNet;P:secret123;;는 네트워크 접속 정보를 담고 있어 휴대폰 카메라가 연결을 제안합니다.

브랜드 코드: Branded code를 둥근 로고, 수준 H, 둥근 모서리 스타일, 1024 × 1024로 만들어도 원래 텍스트로 정확히 디코딩됩니다.

데이터가 너무 많을 때: 3000자는 최대 용량을 넘으므로 코드 대신 오류가 표시됩니다.

이 도구 사용 방법

  1. 1

    내용 입력

    내용에 URL이나 텍스트를 입력합니다.

  2. 2

    모양 선택

    QR 코드 색상과 배경색을 정한 다음 스타일, 오류 정정 수준, 이미지 크기를 고릅니다.

  3. 3

    로고 추가(선택)

    로고 (선택 사항)에 PNG, JPEG, WebP 이미지를 드롭하고 Q나 H로 바꿉니다.

  4. 4

    확인 및 다운로드

    미리보기는 입력하는 동안 업데이트됩니다. 최신 상태가 되면 PNG를, 로고 없는 사각형 스타일이라면 SVG를 다운로드합니다.

팁 및 모범 사례

  • 대비를 강하게 유지하세요. 밝은 배경에 어두운 모듈이 가장 안정적으로 스캔됩니다. 반전된 색상은 일부 스캐너가 지원하지 않습니다.
  • 내용이 짧을수록 코드가 덜 촘촘해져 멀리서도 스캔하기 쉽습니다. 가능하면 짧은 URL을 쓰세요.
  • 로고를 넣을 때는 수준 H를 쓰고 인쇄하기 전에 휴대폰으로 코드를 확인하세요.
  • 인쇄용으로는 SVG(로고 없는 사각형 스타일)나 2048 px PNG를 쓰세요.
  • 코드 주변의 흰 테두리는 남겨 두세요. 스캐너에는 여백(quiet zone)이 필요합니다.

관련 도구

  • QR→QR 코드 스캐너브라우저에서 카메라나 PNG, JPEG, WebP 이미지로 QR 코드를 읽어 텍스트를 복사하거나 http(s) 링크를 엽니다. 아무것도 업로드되지 않습니다.
  • −%이미지 압축기브라우저에서 JPEG, PNG, WebP 이미지를 압축합니다. 품질 1–100 설정, 형식 유지 또는 변경, 크기 비교 후 다운로드. 업로드 없음.
  • B64Base64 인코더 / 디코더텍스트나 파일을 Base64로 인코딩하고 다시 디코딩합니다. 표준·URL 안전 알파벳, 패딩, 76자 줄 바꿈, 이미지 미리보기 지원. 브라우저에서 처리.
  • uuidUUID/GUID 생성기무작위 UUID v4 또는 시간순 UUID v7을 최대 100개까지 한 번에 생성합니다. 하이픈, 하이픈 없음, 중괄호, URN 형식과 복사·TXT 다운로드를 지원합니다.
