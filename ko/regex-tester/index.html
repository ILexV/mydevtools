정규식 테스터

Rust regex 엔진(WebAssembly)으로 정규식을 실시간 테스트합니다. 일치 항목 강조, 캡처 그룹과 이름 있는 그룹, i/m/s 플래그, 패턴 저장을 지원합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

정규 표현식을 입력하면 테스트 텍스트의 모든 일치 항목이 입력과 동시에 강조되고, 아래에 위치와 캡처 그룹이 나열됩니다. 패턴은 WebAssembly로 컴파일된 Rust regex 크레이트에서 실행되므로 문법과 동작은 JavaScript가 아닌 Rust를 따릅니다.

상세 기능

문자 클래스와 \p{Cyrillic} 같은 유니코드 클래스, 탐욕적·게으른 수량자, 선택, 앵커, 단어 경계 \b, 번호 그룹, 이름 있는 그룹 (?<name>…) 또는 (?P<name>…), 비캡처 그룹, (?i) 같은 인라인 플래그를 지원합니다. 전방 탐색, 후방 탐색, \1 같은 역참조는 이 엔진에서 지원하지 않으며, 대신 엔진의 오류가 표시됩니다. 그 대가로 일치 시간은 입력에 비례해 선형으로 늘어나므로 (a+)+$ 같은 패턴도 페이지를 멈추게 하지 않습니다.

플래그: i 는 대소문자를 무시하고, m 은 ^ 와 $ 가 각 줄에서 일치하게 하며, s 는 . 가 줄바꿈과도 일치하게 합니다. 전역 을 끄면 첫 번째 일치 항목만 표시됩니다. Rust 엔진에서는 유니코드 모드가 항상 켜져 있으므로 \w, \d, . 가 ASCII가 아닌 글자, 숫자, 문자와도 일치합니다. 위치는 JavaScript 문자열 인덱스(UTF-16, 이모지는 2)입니다. 목록에는 처음 50개가 표시되고, 개수 세기는 10,000에서 멈춥니다.

모든 처리는 로컬에서 이루어집니다. 패턴 저장 을 눌렀을 때만 패턴이 이름, 플래그, 샘플 텍스트와 함께 이 브라우저의 localStorage에 저장됩니다. 기본 제공 예제 5개(이메일, IPv4 주소, 날짜, 16진수 색상, URL)는 클릭 한 번으로 불러올 수 있습니다.

실용적인 예제

이름 있는 그룹: (?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2}) 를 Released 2026-10-06, patched 2026-11-02 에 적용하면 2개가 일치합니다. 첫 번째는 [9-19] 위치의 2026-10-06 이고 year는 2026, month는 10, day는 06 입니다.

대소문자를 무시한 선택: error|warn 을 i 플래그와 함께 ERROR: disk full 과 Warn: low memory 두 줄에 적용하면 ERROR 와 Warn 이 일치합니다.

줄 앵커: ^\w+ 를 alpha one 과 beta two 두 줄에 적용하면 alpha 만 일치하고, m 플래그를 켜면 alpha 와 beta 가 일치합니다.

지원되지 않는 전방 탐색: foo(?=bar) 는 “look-around, including look-ahead and look-behind, is not supported” 오류로 거부됩니다. 대신 foo(bar) 로 일치시키고 그룹을 사용하세요.

이 도구 사용 방법

  1. 1

    패턴 입력

    패턴 에 식을 입력합니다. 앞뒤 슬래시는 필요 없습니다. 치트 시트 에 자주 쓰는 토큰이 정리되어 있습니다.

  2. 2

    플래그 설정

    플래그 에서 필요에 따라 대소문자 무시, 여러 줄, 점으로 모두 일치 를 선택합니다. 첫 번째 일치 항목만 보려면 전역 을 해제합니다.

  3. 3

    테스트 텍스트 추가

    테스트 문자열 에 텍스트를 붙여 넣으면 입력과 동시에 일치 항목이 강조됩니다.

  4. 4

    일치 항목 확인

    일치 항목 목록에 각 일치의 [start-end] 위치와 캡처 그룹이 표시됩니다.

  5. 5

    저장 및 재사용

    패턴 저장 으로 식을 보관하고, 저장된 패턴 에서 불러오기 하거나 예제 중 하나로 시작합니다.

팁 및 모범 사례

  • 탐색이나 \1 을 쓰는 JavaScript·PCRE 패턴은 다시 작성해야 합니다. 주변 텍스트를 그룹으로 캡처하거나 조건을 코드에서 확인하세요.
  • / 는 이스케이프할 필요가 없지만 리터럴 점은 필요합니다: “.” 은 \. 로 씁니다.
  • 인라인 플래그는 패턴 안에서도 동작합니다: (?i)error 는 i 플래그를 켠 error 와 같습니다.
  • 저장한 패턴은 이 브라우저에만 남으며, 사이트 데이터를 지우면 삭제됩니다.
  • 단어 앞뒤에 \b 를 붙이면(\bcolou?r\b) colours 가 colour 로 일치하지 않습니다.

관련 도구

  • wc단어/문자 수 세기입력하는 동안 단어, 문자, 줄, 단락, 문장 수를 세고 읽기·말하기 시간을 계산합니다. 이모지와 중국어·일본어 텍스트도 정확히 셉니다.
  • {}JSON 포맷터브라우저에서 JSON을 포맷·압축·검증합니다. 2/4칸 공백 또는 탭 들여쓰기, 재귀적 키 정렬, 큰 숫자 원형 유지, .json 파일 열기와 저장 지원.
  • B64Base64 인코더 / 디코더텍스트나 파일을 Base64로 인코딩하고 다시 디코딩합니다. 표준·URL 안전 알파벳, 패딩, 76자 줄 바꿈, 이미지 미리보기 지원. 브라우저에서 처리.
  • Aa텍스트 대소문자 변환기텍스트를 camelCase, snake_case, kebab-case, 제목 케이스, 문장 케이스, 대문자, 소문자로 변환합니다. XMLHttpRequest 같은 식별자도 올바르게 나눕니다.
