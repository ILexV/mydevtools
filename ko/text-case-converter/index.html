텍스트 대소문자 변환기

텍스트를 camelCase, snake_case, kebab-case, 제목 케이스, 문장 케이스, 대문자, 소문자로 변환합니다. XMLHttpRequest 같은 식별자도 올바르게 나눕니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

텍스트를 입력하거나 붙여넣은 뒤 아래에서 형식을 고르면 그 자리에서 변환됩니다.

변수명, 제목, 문단 전체를 클릭 한 번으로 아홉 가지 케이스로 변환합니다: camelCase, snake_case, kebab-case, 제목 케이스, 문장 케이스, 대문자, 소문자, 교차 대소문자, 반전 대소문자. JavaScript, Python, CSS, SQL의 명명 규칙 사이에서 식별자를 옮길 때 편리합니다.

상세 기능

식별자용 변환은 기존 단어 경계를 인식합니다. 공백, 하이픈, 밑줄뿐 아니라 소문자→대문자 전환, 문자↔숫자 전환, 약어도 단어를 나눕니다. 그래서 getHTTPResponse 는 get, HTTP, Response 로, XMLHttpRequest2 는 XML, Http, Request, 2 로 나뉩니다. 연속된 구분자는 하나로 합쳐지고, 앞뒤의 구분자는 제거되며, 그 밖의 문장 부호는 해당 단어에 붙은 채로 남습니다.

줄바꿈과 탭은 유지되므로 이름 목록은 줄 단위로 변환됩니다. 문장 케이스 는 모든 글자를 소문자로 바꾼 뒤 ., !, ? 다음의 첫 글자를 대문자로 만듭니다. 반전 대소문자 는 모든 글자의 대소문자를 바꾸고 나머지는 그대로 둡니다. 교차 대소문자 는 글자마다 소문자와 대문자를 번갈아 씁니다. 키릴 문자, 그리스 문자, 악센트가 있는 라틴 문자 등 대소문자가 있는 문자를 지원하며, 한국어·중국어·일본어·힌디어에는 대소문자가 없으므로 구분자만 바뀝니다.

변환은 페이지의 JavaScript에서 실행되며 텍스트는 어디에도 전송되지 않습니다. 결과가 같은 입력란의 텍스트를 대체하므로 여러 변환을 연달아 적용할 수 있습니다.

실용적인 예제

JavaScript에서 Python으로: getHTTPResponse code 에 스네이크 케이스 를 적용하면 get_http_response_code 가 됩니다.

CSS 속성에서 JavaScript로: background-color 에 카멜 케이스 를 적용하면 backgroundColor 가 됩니다.

약어와 숫자: XMLHttpRequest2 에 케밥 케이스 를 적용하면 xml-http-request-2 가 됩니다.

대소문자 바로잡기: hello world. how are you? 에 문장 케이스 를 적용하면 Hello world. How are you? 가 됩니다.

이 도구 사용 방법

  1. 1

    텍스트 입력

    텍스트 칸에 입력하거나 붙여 넣습니다.

  2. 2

    케이스 선택

    변환 아래에서 카멜 케이스 나 스네이크 케이스 같은 버튼을 누릅니다. 입력란의 내용이 결과로 바뀝니다.

  3. 3

    결과 복사

    복사 를 눌러 변환된 텍스트를 복사합니다. 지우기 는 입력란을 비웁니다.

팁 및 모범 사례

  • 대문자, 소문자, 제목 케이스 도 _ 와 - 를 단어 구분자로 보고 공백으로 바꿉니다: user_id 는 USER ID 가 됩니다. USER_ID 를 얻으려면 모두 소문자인 user_id 에 반전 대소문자 를 적용하세요.
  • 문장 케이스는 고유명사와 약어도 소문자로 바꿉니다(HTTP server 는 Http server 가 됨). 필요하면 직접 고치세요.
  • 제목 케이스는 짧은 단어를 포함해 모든 단어의 첫 글자를 대문자로 만듭니다: the lord of the rings 는 The Lord Of The Rings 가 되며, 스타일 가이드의 예외 규칙은 따르지 않습니다.
  • 단어 중간의 대문자는 새 단어의 시작이 됩니다: iPhone 에 스네이크 케이스를 적용하면 i_phone 이 됩니다.
  • 변환은 입력란을 덮어쓰므로 여러 결과를 비교하려면 원문을 다른 곳에 보관해 두세요.

관련 도구

  • wc단어/문자 수 세기입력하는 동안 단어, 문자, 줄, 단락, 문장 수를 세고 읽기·말하기 시간을 계산합니다. 이모지와 중국어·일본어 텍스트도 정확히 셉니다.
  • ±텍스트 차이 뷰어두 텍스트나 파일을 줄 단위로 비교해 추가·삭제·변경된 줄을 나란히 또는 unified diff로 보여 주고, 줄 안의 바뀐 단어를 강조합니다.
  • .*정규식 테스터Rust regex 엔진(WebAssembly)으로 정규식을 실시간 테스트합니다. 일치 항목 강조, 캡처 그룹과 이름 있는 그룹, i/m/s 플래그, 패턴 저장을 지원합니다.
  • {}JSON 포맷터브라우저에서 JSON을 포맷·압축·검증합니다. 2/4칸 공백 또는 탭 들여쓰기, 재귀적 키 정렬, 큰 숫자 원형 유지, .json 파일 열기와 저장 지원.
