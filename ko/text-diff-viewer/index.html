텍스트 차이 뷰어

두 텍스트나 파일을 줄 단위로 비교해 추가·삭제·변경된 줄을 나란히 또는 unified diff로 보여 주고, 줄 안의 바뀐 단어를 강조합니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

원본 텍스트를 붙여넣거나 파일을 여세요.

변경된 텍스트를 붙여넣거나 파일을 여세요.

출력

양쪽을 채우고 비교를 누르면 차이가 여기에 표시됩니다.

    설정 파일, 코드 조각, 문서의 두 버전을 붙여 넣으면 어떤 줄이 추가, 삭제, 변경되었는지 정확히 볼 수 있습니다. Git diff와 비슷한 나란히 보기와 줄 단위(unified) 보기를 제공합니다.

    상세 기능

    비교는 줄 단위입니다. jsdiff가 unified 패치를 만들고 diff2html이 줄 번호, 각 변경 주변 최대 4줄의 변경되지 않은 컨텍스트, 수정된 줄 안의 단어 단위 강조와 함께 렌더링합니다. 텍스트 전체가 아니라 변경된 영역(hunk)만 표시됩니다. 공백과 대소문자를 구분하므로 들여쓰기 변경이나 줄 끝 공백도 변경으로 처리됩니다.

    양쪽 모두 직접 입력하거나, 붙여 넣거나, 로컬 텍스트 파일(UTF-8로 읽음)에서 불러올 수 있습니다. 줄바꿈 문자는 통일되므로 같은 줄을 가진 Windows(CRLF) 파일과 Unix(LF) 파일은 동일하다고 판단됩니다. 양쪽을 모두 파일에서 불러오면 비교가 자동으로 시작되고, 입력이 같으면 차이가 없다고 알려 줍니다.

    diff는 브라우저에서 계산되고 파일도 로컬에서 읽으므로 아무것도 업로드되지 않습니다. 페이지가 멈추지 않도록 차이가 너무 큰 텍스트에는 상한이 있어, 1,000줄 넘게 다르면 diff 대신 안내 메시지를 표시합니다.

    실용적인 예제

    설정 변경: 원본 줄 host=localhost, port=8080, debug=true 와 host=0.0.0.0, port=8080, debug=false 를 비교하면 host와 debug 줄이 삭제·추가로 표시되고 바뀐 단어가 강조되며, port=8080 은 변경되지 않은 컨텍스트로 남습니다.

    긴 파일의 한 줄: 20줄 텍스트에서 11번째 줄만 바꾸면 diff에는 hunk @@ -7,9 +7,9 @@ 하나만 표시됩니다. 변경된 줄과 앞뒤 각 4줄의 컨텍스트입니다.

    두 파일 비교: 파일 버튼으로 이전 버전과 새 버전을 고르면 둘 다 불러오는 즉시 diff가 나타납니다.

    복사본 확인: 동일한 두 텍스트를 비교하면 차이가 없다고 알려 줍니다.

    이 도구 사용 방법

    1. 1

      원본 추가

      원본 텍스트 에 붙여 넣거나 원본 파일 선택 을 누릅니다.

    2. 2

      수정본 추가

      수정된 텍스트 에 붙여 넣거나 수정된 파일 선택 을 누릅니다.

    3. 3

      비교

      비교 를 누릅니다. 양쪽이 모두 파일이면 diff가 자동으로 나타납니다.

    4. 4

      보기 전환

      보기 모드 에서 나란히 또는 통합을 고릅니다. 지우기 는 두 입력란을 초기화합니다.

    팁 및 모범 사례

    • 넓은 화면에서는 나란히, 휴대폰에서는 통합이 읽기 편합니다.
    • 일반 텍스트만 비교할 수 있으며 이미지, PDF, Word 문서는 지원하지 않습니다.
    • 1,000줄 넘게 다르면 파일을 작은 부분으로 나눠 비교하세요.
    • JSON이나 압축된 코드는 먼저 정리하세요(한 줄에 한 항목). 긴 한 줄은 변경된 한 줄로만 표시됩니다.
    • 처음 방문한 뒤에는 네트워크 연결 없이도 페이지가 동작합니다.

    관련 도구

    • wc단어/문자 수 세기입력하는 동안 단어, 문자, 줄, 단락, 문장 수를 세고 읽기·말하기 시간을 계산합니다. 이모지와 중국어·일본어 텍스트도 정확히 셉니다.
    • Aa텍스트 대소문자 변환기텍스트를 camelCase, snake_case, kebab-case, 제목 케이스, 문장 케이스, 대문자, 소문자로 변환합니다. XMLHttpRequest 같은 식별자도 올바르게 나눕니다.
    • .*정규식 테스터Rust regex 엔진(WebAssembly)으로 정규식을 실시간 테스트합니다. 일치 항목 강조, 캡처 그룹과 이름 있는 그룹, i/m/s 플래그, 패턴 저장을 지원합니다.
    • {}JSON 포맷터브라우저에서 JSON을 포맷·압축·검증합니다. 2/4칸 공백 또는 탭 들여쓰기, 재귀적 키 정렬, 큰 숫자 원형 유지, .json 파일 열기와 저장 지원.
