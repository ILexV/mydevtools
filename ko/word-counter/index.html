단어/문자 수 세기

입력하는 동안 단어, 문자, 줄, 단락, 문장 수를 세고 읽기·말하기 시간을 계산합니다. 이모지와 중국어·일본어 텍스트도 정확히 셉니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

여기에 텍스트를 입력하거나 붙여넣어 단어 수, 문자 수 등을 계산하세요...

텍스트를 입력하거나 붙여 넣으면 키를 누를 때마다 단어, 문자, 줄, 단락, 문장 수가 갱신되고 예상 읽기 시간과 말하기 시간도 함께 표시됩니다. 에세이, meta 설명, 커밋 메시지, UI 문구의 길이 제한을 확인할 때 유용합니다.

상세 기능

문자는 사용자가 보는 기호 단위(그래핌 클러스터)로 셉니다. 👍 같은 이모지, 여러 코드 포인트로 이루어진 가족 이모지, 결합 악센트가 붙은 글자는 각각 한 문자입니다. 문자 수 (공백 제외) 는 탭과 줄바꿈을 포함한 모든 공백을 제외합니다. 단어는 공백으로 구분된 덩어리로 셉니다. 띄어쓰기 없이 쓰는 중국어와 일본어는 브라우저 내장 단어 분할(Intl.Segmenter)로 단어를 나눕니다.

줄은 줄바꿈으로 세고(Windows의 CRLF는 한 번), 단락은 텍스트 덩어리 사이의 빈 줄로, 문장은 종결 기호 ., !, ?, … 와 전각 마침표 。！？ 로 셉니다. 문장 부호 없이 끝나는 마지막 문장도 포함됩니다. 읽기 시간은 분당 200단어, 말하기 시간은 분당 130단어로 계산해 분 단위로 반올림하며, 비어 있지 않은 텍스트는 최소 1분입니다.

통계는 페이지의 JavaScript가 계산합니다. 텍스트는 업로드되지 않으며 도구에 저장되지도 않습니다. 붙여넣기 와 복사 는 시스템 클립보드를 사용하므로 브라우저가 권한을 요청할 수 있습니다.

실용적인 예제

두 단락: Hello world! How are you?, 빈 줄, Second paragraph. 를 입력하면 7단어, 3문장, 2단락, 3줄, 44문자(공백 제외 37문자)가 됩니다.

이모지와 악센트: 👍 café 는 2단어, 6문자입니다. 이모지와 악센트가 붙은 é 는 각각 한 문자로 셉니다.

띄어쓰기 없는 일본어: 東京は晴れです。 는 4단어(Chrome 기준이며 정확한 분할은 브라우저 사전에 따라 다름), 8문자, 1문장으로 셉니다.

발표 길이: 1,000단어 텍스트는 읽기 시간 5분, 말하기 시간 8분으로 표시됩니다.

이 도구 사용 방법

  1. 1

    텍스트 입력

    텍스트 칸에 입력하거나 붙여넣기 를 눌러 클립보드 내용을 넣습니다.

  2. 2

    통계 확인

    통계 패널은 편집할 때마다 갱신됩니다: 단어 수, 공백 포함·제외 문자 수, 줄 수, 단락 수, 문장 수.

  3. 3

    시간 예측 확인

    읽기 시간 과 말하기 시간 은 텍스트를 눈으로 읽거나 소리 내어 말하는 데 걸리는 시간을 보여 줍니다.

  4. 4

    복사 또는 지우기

    복사 를 눌러 텍스트를 클립보드에 다시 넣거나 지우기 로 처음부터 시작합니다.

팁 및 모범 사례

  • 숫자나 약어 안의 점도 문장의 끝으로 처리됩니다: Version 2.0 is out... 은 2문장, e.g. this one 은 3문장이므로 문장 수는 대략적인 값으로 보세요.
  • 문자 수로 제한되는 경우(meta 설명, SMS, SNS 게시물)에는 문자 수 (공백 포함) 를 사용하세요. 일부 서비스는 UTF-16 단위로 세기 때문에 이모지 하나가 2로 계산될 수 있습니다.
  • 태국어, 라오어, 크메르어처럼 띄어쓰기 없이 쓰는 문자는 분할되지 않아 이어진 텍스트 전체가 한 단어로 계산됩니다.
  • 한국어와 힌디어는 단어를 공백으로 구분하므로 영어와 같은 방식으로 셉니다.
  • 처음 방문한 뒤에는 네트워크 연결 없이도 페이지가 동작합니다.

관련 도구

  • Aa텍스트 대소문자 변환기텍스트를 camelCase, snake_case, kebab-case, 제목 케이스, 문장 케이스, 대문자, 소문자로 변환합니다. XMLHttpRequest 같은 식별자도 올바르게 나눕니다.
  • ±텍스트 차이 뷰어두 텍스트나 파일을 줄 단위로 비교해 추가·삭제·변경된 줄을 나란히 또는 unified diff로 보여 주고, 줄 안의 바뀐 단어를 강조합니다.
  • .*정규식 테스터Rust regex 엔진(WebAssembly)으로 정규식을 실시간 테스트합니다. 일치 항목 강조, 캡처 그룹과 이름 있는 그룹, i/m/s 플래그, 패턴 저장을 지원합니다.
  • {}JSON 포맷터브라우저에서 JSON을 포맷·압축·검증합니다. 2/4칸 공백 또는 탭 들여쓰기, 재귀적 키 정렬, 큰 숫자 원형 유지, .json 파일 열기와 저장 지원.
