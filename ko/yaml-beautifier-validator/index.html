YAML 포맷터/검증기

YAML을 검증하고 2칸 들여쓰기의 깔끔한 블록 스타일로 다시 포맷합니다. 오류는 행과 열로 표시되며 WebAssembly로 로컬에서 실행됩니다.

입력 내용과 파일은 브라우저 밖으로 전송되지 않습니다

YAML 입력

여기에 YAML을 붙여넣어 다시 서식을 지정하거나 구문 오류를 검사하세요.

편집기에서 Tab 키는 들여쓰기를 합니다. 편집기에서 나가려면 Esc를 누른 다음 Tab을 누르세요.

출력

서식이 지정된 YAML 또는 검사 결과가 여기에 표시됩니다.

YAML 파일의 문법 오류를 확인하고 일관된 블록 스타일로 다시 작성하세요. 파싱과 포맷은 WebAssembly로 컴파일된 작은 Rust 라이브러리가 브라우저에서 처리하며, 이 라이브러리는 포맷이나 검증을 처음 누를 때만 로드됩니다.

상세 기능

검증은 입력을 파싱만 하고 “YAML이 유효합니다”라고 답하거나 첫 번째 오류를 행과 열과 함께 보여 줍니다. 예: mapping values are not allowed in this context at line 2 column 7. 포맷은 모든 문서를 파싱한 뒤 다시 출력합니다. 매핑과 리스트는 2칸 들여쓰기의 블록 스타일로, [80, 443]이나 {host: localhost} 같은 인라인 컬렉션은 여러 줄로 펼쳐지며, 각 문서는 ---로 시작합니다. ---로 구분된 여러 문서가 담긴 파일도 지원합니다.

포맷은 텍스트가 아닌 데이터를 다시 쓰기 때문에 일부가 정규화됩니다. 주석은 제거되고, 빈 값은 ~가 되며, YAML 1.1 도구가 불리언으로 읽는 단어(yes, no, on, off)는 따옴표로 감쌉니다(예: flag: "yes"). 키 순서는 유지됩니다. 문법만 확인하고 파일을 그대로 두고 싶다면 검증을 사용하세요.

입력 에디터는 YAML을 강조하고 중첩 블록을 접을 수 있으며, 결과는 읽기 전용 출력 에디터에 나타납니다. 붙여넣기는 클립보드의 텍스트를 넣고 복사는 출력을 복사합니다. 입력한 내용은 저장되거나 업로드되지 않습니다.

실용적인 예제

인라인 리스트를 블록 스타일로: ports: [80, 443]은 ports: 다음에 - 80과 - 443 줄이 오는 형태로 포맷됩니다.

들여쓰기 오류 찾기: name: demo 다음에 들여쓴 port: 80이 오면 “YAML이 유효하지 않습니다: mapping values are not allowed in this context at line 2 column 7” 오류가 납니다.

여러 문서: a: 1, ---, b: 2는 두 문서로 유지되며 출력은 ---, a: 1, ---, b: 2입니다.

정규화되는 값: flag: yes와 빈 empty:는 flag: "yes"와 empty: ~가 됩니다.

이 도구 사용 방법

  1. 1

    YAML 입력

    YAML 입력 에디터에 붙여넣거나 붙여넣기를 눌러 클립보드 내용을 넣습니다.

  2. 2

    문법 확인

    검증을 누릅니다. 배지에 “YAML이 유효합니다”가 표시되거나, 에디터 위에 행과 열이 담긴 오류가 나타납니다.

  3. 3

    포맷

    포맷을 누르면(또는 입력 에디터에서 Ctrl+Enter / Cmd+Enter) 출력에 정규화된 YAML이 나옵니다.

  4. 4

    결과 복사

    복사를 눌러 포맷된 YAML을 클립보드에 넣습니다.

팁 및 모범 사례

  • 포맷은 주석을 지웁니다. 원본 파일을 보관하거나, 중요한 주석이 있는 파일에는 검증만 사용하세요.
  • YAML은 들여쓰기에 탭을 허용하지 않습니다. 오류 위치가 문제의 줄을 가리킵니다.
  • 행과 열 번호는 대부분의 에디터처럼 1부터 시작합니다.
  • Kubernetes, Compose, CI 파일을 커밋하기 전에 "yes"처럼 따옴표로 감싼 값이 사용하는 도구가 기대하는 값인지 확인하세요.
  • WebAssembly 모듈은 처음 포맷이나 검증을 할 때 다운로드되며, 그 뒤에는 오프라인에서도 페이지가 동작합니다.
  • 입력 에디터에서 Tab은 들여쓰기를 넣습니다. 포커스를 밖으로 옮기려면 Esc를 누른 뒤 Tab을 누르세요.

  • TSJSON → TypeScript 변환기JSON 샘플에서 TypeScript 인터페이스나 타입 별칭을 생성합니다. 중첩 타입, 배열 항목 병합, 선택적 필드, export 키워드 지원. 브라우저에서 실행.
