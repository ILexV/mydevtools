      Ambientes

      Use {{nome}} na URL, parâmetros, cabeçalhos, corpo e autorização. O ambiente ativo prevalece sobre as variáveis de pasta, e estas sobre as globais. Para um valor somente de escrita, defina a variável como {{secret:nome}}.

      Configurações do cliente

      Proxy

      O agente se conecta por um proxy HTTP: CONNECT para https e URLs absolutas para http. A senha do proxy é salva com o espaço de trabalho.

      Certificados de cliente (mTLS)

      O agente apresenta um certificado aos hosts https da lista quando o servidor pede. A chave privada fica criptografada no agente e nunca volta para a página. Use arquivos PEM com a chave sem criptografia; converta um .pfx antes: openssl pkcs12 -in cert.pfx -out cert.pem -nodes

                        Envie HTTP e HTTPS sem conta e sem passar credenciais de API por um servidor MyDevTools. Um pequeno agente do Windows faz a conexão e retorna status, tempo, cabeçalhos e corpo.
                        Funcionalidade detalhada
                        O navegador pareia explicitamente com o agente em 127.0.0.1 por um código de uso único. O token de conexão fica salvo neste navegador por até 8 horas ou até o agente reiniciar; o código não é armazenado. O token concede apenas http.request. As requisições vão direto ao destino. Redes privadas exigem ativar «Allow local network and this PC as targets» na janela do agente (ou --allow-private); redirecionamentos vêm desligados e cabeçalhos sensíveis são removidos quando a origem muda. Rascunhos, incluindo URLs, cabeçalhos e segredos, e corpos são salvos automaticamente neste navegador para reabrir depois; respostas não são salvas. O token de conexão é armazenado separadamente por até 8 horas ou até o agente reiniciar. Com um agente atual, os rascunhos ficam cifrados no computador, guardados pelo agente em vez do navegador.
                        Exemplos práticos
                        Use GET para JSON, POST com Content-Type: application/json para APIs ou HEAD para metadados. Adicione Authorization: Bearer … só quando o destino exigir; ele vai ao destino, não ao MyDevTools.
                        Como usar esta ferramenta
                        1. 1
                          instalar e iniciar o agente
                          Baixe o agente Windows x64 e inicie-o.
                        2. 2
                          parear
                          Peça um código na janela do agente, digite-o e clique em Conectar.
                        3. 3
                          montar a requisição
                          Escolha método, URL HTTP ou HTTPS, cabeçalhos e corpo UTF-8.
                        4. 4
                          enviar e inspecionar
                          Veja status, tempo, URL final, cabeçalhos e prévia segura. Baixe corpos binários byte a byte.
                        Dicas e melhores práticas
                          

                        • Deixe os redirecionamentos desligados para ver a primeira resposta.
                          • 

                        • Authorization vai ao serviço de destino; não compartilhe capturas com segredos.
                          • 

                        • Só ative rede privada para um serviço LAN confiável.
                          • 

                        • O pareamento nunca autoriza futuras varreduras de portas ou rede.
