A Calculadora de Sub-rede IP é uma ferramenta essencial para engenheiros de rede e desenvolvedores para analisar rapidamente sub-redes IPv4. Calcule endereços de rede, endereços de broadcast, intervalos de hosts utilizáveis e máscaras wildcard instantaneamente no seu navegador sem enviar dados para um servidor.

Funcionalidade detalhada

Esta ferramenta fornece um detalhamento completo de qualquer sub-rede IPv4. Ao inserir um endereço IP com um prefixo CIDR (por exemplo, /24) ou uma máscara de sub-rede, você pode ver instantaneamente a arquitetura da rede. Ela lida com sub-redes padrão, bem como casos especiais como /31 (Ponto a Ponto) e /32 (Host Único).

Os principais recursos incluem:

  • Suporte CIDR: Aceita notação CIDR padrão (ex: 10.0.0.1/24).
  • Suporte a Máscara de Rede: Aceita IP e Máscara separados por espaço (ex: 10.0.0.1 255.255.255.0).
  • Cálculos em Tempo Real: Toda a matemática é feita via WebAssembly para latência zero.
  • Visualização Binária: Visualiza o IP e a máscara em formato binário para fins educacionais.
  • Foco na Privacidade: Nenhum endereço IP é enviado para um servidor backend.

Exemplos práticos

Exemplo 1: Rede Doméstica Padrão

Entrada: `192.168.1.1/24`

Resultado: Rede `192.168.1.0`, Intervalo `192.168.1.1 - 192.168.1.254`, Broadcast `192.168.1.255`.

Exemplo 2: Link Ponto a Ponto

Entrada: `10.1.1.0/30`

Resultado: 2 hosts utilizáveis, ideal para interconexões de roteadores.

Exemplo 3: Sub-rede Corporativa

Entrada: `172.16.0.0 255.255.0.0`

Resultado: prefixo /16, 65.534 hosts utilizáveis.

Como usar esta ferramenta

1. Digite um endereço IP seguido por uma barra e o comprimento do prefixo (ex: `192.168.1.1/24`).

2. Alternativamente, digite um endereço IP seguido por um espaço e a máscara de sub-rede (ex: `192.168.1.1 255.255.255.0`).

3. Clique em Calcular ou pressione Enter.

4. Veja os parâmetros detalhados da rede na tabela de resultados.

Dicas e melhores práticas

  • Use a visualização Binária para entender como a máscara de rede separa as porções de rede e host do endereço.
  • Clique no ícone de cópia ao lado do endereço de Rede ou Broadcast para colá-lo rapidamente na configuração do seu roteador.
  • Prefixos válidos são de /0 a /32.
