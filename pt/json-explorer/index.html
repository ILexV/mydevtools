Explorador de JSON / JSONL grandes

Abra, indexe, pesquise e exporte JSON e JSONL grandes localmente, com tabela virtual, árvore sob demanda e números exatos.

Os dados inseridos e arquivos ficam no navegador

Arquivo local

Solte um arquivo JSON, JSONL ou NDJSON

O arquivo permanece neste navegador. JSONL é lido incrementalmente; JSON comum usa o limite de memória configurado.

JSON comum é carregado até o limite escolhido de 8–64 MiB. JSONL flui em blocos de 1 MiB, com 1–8 MiB por registro e profundidade máxima 256. São limites de segurança explícitos.

Arquivos, pesquisas e colunas derivadas não saem do dispositivo nem são salvos; somente formato e limites são lembrados.

Processando arquivo

Registros

Escolha um JSON ou JSONL local para examinar sua estrutura e registros.

Pesquisar, filtrar e projetar

Um JSON Pointer RFC 6901 por linha, até 100 campos. Lista vazia mantém colunas automáticas do nível superior. Escape ~ como ~0 e / como ~1. JSONL projetado usa objeto plano com os ponteiros exatos como chaves; campo ausente vira null.

Colunas automáticas amostram os primeiros 10.000 registros e exibem até 100 campos. Nomes cujo JSON Pointer codificado passa de 256 caracteres e metadados de nomes além de 16.384 caracteres não são adicionados automaticamente. Nenhum campo é removido: use um JSON Pointer exato. Prévias têm 512 caracteres; inspeção e exportação usam valores completos.

Registro selecionado

Selecione uma linha para carregar o registro original completo.

Explore matrizes JSON grandes e JSON delimitado por linhas sem enviar dados privados. A ferramenta cria um índice esparso local, renderiza só uma pequena janela virtual e carrega registro ou ramo quando solicitado.
Funcionalidade detalhada
JSONL / NDJSON é decodificado como UTF-8 em blocos de 1 MiB. BOM, CRLF e linha final sem quebra são aceitos; erros indicam linha física e coluna. Só pontos esparsos e metadados limitados ficam na memória; janelas distantes, filtros e exportações relêem o arquivo.



JSON comum aceita objetos, matrizes e raízes escalares com árvore sob demanda. Uma matriz raiz também aparece como registros. O documento possui limite explícito de 8–64 MiB e é analisado em worker; profundidade máxima 256 e registros JSONL de 1–8 MiB.



Lexemas numéricos são preservados: 9007199254740993, 1.0 e expoentes não passam por Number. O filtro varre tudo sem criar uma matriz completa de resultados.
Exemplos práticos
Logs de API: abra .ndjson, procure timeout e filtre /service por billing; selecione uma linha para o original completo.



Campos aninhados: projete /id e /user/name; /a~1b aponta para a/b. CSV usa ponteiros como colunas e JSONL como chaves.



IDs grandes: {"id":9007199254740993,"price":1.0} mantém as duas grafias.



Matriz grande: expanda só os ramos necessários e role sem uma linha DOM por item.
Como usar esta ferramenta
  1. 1
    Escolha formato e limites
    Selecione automático, JSON ou JSONL/NDJSON e configure limites de arquivo, registro e profundidade.
  2. 2
    Abra o arquivo local
    Solte ou escolha o arquivo. O worker mostra bytes, tempo, taxa e estimativa; cancelar descarta a sessão.
  3. 3
    Pesquise ou projete
    Pesquise chaves e valores, informe caminho RFC 6901 e trecho, ou liste ponteiros de projeção.
  4. 4
    Inspecione e exporte
    Role, abra o registro completo, expanda a árvore ou baixe todas as correspondências em JSONL ou CSV.
Dicas e melhores práticas
    

  • Use .jsonl ou .ndjson para detecção confiável; escolha explicitamente arquivos ambíguos.
    • 

  • Linhas JSONL vazias são ignoradas, mas erros usam números físicos.
    • 

  • JSONL vazio é um resultado válido de zero registros; JSON comum vazio é inválido.
    • 

  • JSON Pointer usa /, ~0 para til e ~1 para barra.
    • 

  • Proteção CSV para =, +, - e @ vem ativada.
    • 

  • A exportação percorre todas as correspondências e transmite blocos limitados ao arquivo escolhido. Sem seletor nativo, usa um download alternativo de 256 MiB. CSV segue RFC 4180, CRLF e BOM UTF-8.
