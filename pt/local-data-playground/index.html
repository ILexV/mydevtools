Playground de dados local

Importe CSV, JSON, JSONL ou Parquet locais e consulte-os com DuckDB SQL diretamente no navegador.

Os dados inseridos e arquivos ficam no navegador

Importar dados locais

Solte um arquivo de dados aqui

CSV, TSV, JSON, JSONL, NDJSON ou Parquet. Importe mais arquivos para unir tabelas.

Os exemplos colocam o nome entre aspas, aceitando espaços e caracteres não latinos.

Os arquivos ficam neste dispositivo. O DuckDB roda em um Web Worker com recursos locais; o SQL não lê URLs nem outros arquivos.

Limites: 1 GiB por entrada, 128 MiB na transcodificação, 512 MiB de memória DuckDB, 100.000 linhas de prévia, 500 linhas por página e 512 MiB para download alternativo ou Parquet. JSON/JSONL é decodificado por inteiro na memória como registros planos, não em blocos. Cancelar libera todas as tabelas.

Operação local

Tabelas importadas

Nenhuma tabela importada.

    Consulta SQL

    Pressione Ctrl ou Cmd + Enter. Só uma instrução local SELECT ou WITH somente leitura é permitida.

    O resultado é materializado no worker e lido em páginas limitadas.
    Resultado da consulta

    Importe uma tabela e execute uma consulta para ver o resultado.

    Exportar resultado completo

    CSV, JSON e JSONL são gravados em blocos no arquivo escolhido. Parquet usa um único buffer limitado. O download alternativo é limitado a 512 MiB.

    O playground local executa DuckDB-WASM no navegador para consultar CSV, JSON, JSONL e Parquet sem upload. Cada arquivo recebe um nome de tabela SQL e vários arquivos podem ser unidos.

    Funcionalidade detalhada

    DuckDB e o Web Worker são servidos pelo MyDevTools e carregam apenas no primeiro import. Não exigem SharedArrayBuffer, isolamento entre origens, servidor ou CDN externo. Acesso externo, extensões, leitores de URL e SQL que altera o banco ficam desativados.

    O editor aceita SELECT e WITH, filtros, grupos, agregações, ordenação e JOIN. A prévia tem limite explícito de 100.000 linhas e a tabela virtual solicita no máximo 500 linhas por vez. Inteiros e decimais não passam por Number do JavaScript.

    CSV, JSON e JSONL são exportados em blocos com contrapressão. Parquet é gerado em um único buffer. Downloads alternativos e Parquet têm limite de 512 MiB.

    Exemplos práticos

    SELECT: importe orders.csv como orders e execute SELECT * FROM "orders" LIMIT 100.

    WHERE: filtre localmente por estado.

    GROUP BY: agrupe por país e some valores.

    JOIN: importe customers.parquet e una as tabelas por uma chave comum.

    Como usar esta ferramenta

    1. 1

      importe arquivos

      Escolha formato, nome da tabela e opções CSV.

    2. 2

      escreva SQL local

      Use SELECT, WHERE, GROUP BY ou JOIN e pressione Ctrl/Cmd + Enter.

    3. 3

      explore resultados

      A tabela virtual transfere e renderiza apenas uma pequena página.

    4. 4

      exporte ou reinicie

      Exporte CSV, JSON, JSONL ou Parquet. Cancelar ou reiniciar encerra o worker e libera os dados.

    Dicas e melhores práticas

    • Coloque tabelas e colunas entre aspas duplas.
    • Use LIMIT e WHERE seletivo em arquivos grandes.
    • A inferência CSV pode transformar identificadores com zeros iniciais em números; use o Conversor de formatos para preservar texto.
    • BIGINT e DECIMAL não são arredondados por Number.
    • Cancelar encerra o worker e exige novo import.
    • CSV/JSON/JSONL podem ser transmitidos; Parquet usa buffer de até 512 MiB.
