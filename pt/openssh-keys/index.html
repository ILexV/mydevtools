Chaves OpenSSH gera pares de chaves SSH (Ed25519, ECDSA P-256/P-384, RSA 3072/4096) e converte chaves entre os formatos OpenSSH, PKCS#8 e SPKI PEM. As chaves são criadas e convertidas no navegador; a chave privada não é enviada a lugar nenhum.

Funcionalidade detalhada

A geração produz uma chave privada OpenSSH (-----BEGIN OPENSSH PRIVATE KEY-----) e a linha pública correspondente (ssh-ed25519 AAAA…), pronta para authorized_keys. Com senha, a chave privada é criptografada como no ssh-keygen: bcrypt-pbkdf com 16 rodadas e aes256-ctr. A senha é usada exatamente como digitada, com espaços. A geração roda em um Web Worker: Ed25519 e ECDSA levam milissegundos, RSA 4096 de alguns segundos a cerca de um minuto; enquanto isso a página continua utilizável, mostra o tempo decorrido e oferece Cancelar.

Importar aceita uma chave colada ou um arquivo de chave (também arrastando): uma linha pública OpenSSH (ssh-ed25519, ecdsa-sha2-nistp256/384, ssh-rsa), uma chave privada OpenSSH, um PEM SPKI PUBLIC KEY ou um PEM PKCS#8 PRIVATE KEY / ENCRYPTED PRIVATE KEY. De uma chave privada deriva a linha pública; de uma pública mostra algoritmo e comentário. Converter transforma chave privada OpenSSH em PKCS#8, linha pública OpenSSH em SPKI PEM e vice-versa, e PKCS#8 em OpenSSH.

Os resultados podem ser copiados ou baixados como id_key / id_key.pub (geradas) ou imported.key / imported.pub (importadas). Avisos apontam escolhas fracas, como RSA abaixo de 3072 bits. Chaves criadas por versões anteriores, que cortavam espaços da senha, continuam abrindo: se a senha digitada for recusada, tenta-se a variante sem espaços nas pontas e uma nota avisa.

Exemplos práticos

Chave nova para um servidor: escolha Ed25519, clique em Gerar chaves, acrescente a linha pública (começa com ssh-ed25519 AAAAC3NzaC1lZDI1NTE5) ao ~/.ssh/authorized_keys do servidor e salve a privada como ~/.ssh/id_ed25519 com permissão 600.

RSA para um sistema antigo: escolha RSA 4096 se um equipamento não aceitar Ed25519. A geração demora; os segundos decorridos aparecem e Cancelar interrompe.

Chave pública OpenSSH para PEM: cole ssh-ed25519 AAAA… user@host e clique em Converter para obter um SPKI PEM que começa com -----BEGIN PUBLIC KEY----- e MCowBQYDK2VwAyEA, o formato que OpenSSL, Java e outras bibliotecas esperam.

Usar uma chave SSH no código: cole uma OPENSSH PRIVATE KEY (com a senha no campo), clique em Converter e obtenha um bloco PKCS#8 -----BEGIN PRIVATE KEY----- para bibliotecas que não leem o formato OpenSSH.

Como usar esta ferramenta

  1. 1

    Escolha o tipo de chave

    Em Gerar selecione o Algoritmo: Ed25519 (Recommended), ECDSA P-256/P-384 ou RSA 3072/4096. Tamanho da chave só fica ativo para RSA.

  2. 2

    Defina uma senha, se quiser

    Digite uma senha em Senha (opcional) para criptografar a chave privada; deixe vazio para uma chave sem criptografia.

  3. 3

    Gere

    Clique em Gerar chaves. Para RSA aparece uma barra de progresso com o tempo decorrido e Cancelar.

  4. 4

    Guarde as chaves

    Use Copiar ou Baixar em Chave pública e Chave privada.

  5. 5

    Importe ou converta chaves existentes

    Cole uma chave em Importar ou solte um arquivo de chave e clique em Importar para examiná-la ou Converter para mudar o formato.

Dicas e melhores práticas

  • Chaves Ed25519 são curtas, rápidas e aceitas pelo OpenSSH 6.5+ e pelos grandes serviços Git; use RSA só onde for obrigatório.
  • O aviso "ssh-rsa uses SHA-1" se refere ao esquema de assinatura antigo; o OpenSSH atual assina com chaves RSA usando rsa-sha2-256/512.
  • Uma chave privada sem senha é tão segura quanto o disco onde está; proteja com senha as chaves de notebooks.
  • Uma senha que começa ou termina com espaço é outra senha; o campo mostra um aviso para que isso não aconteça por acaso.
  • Chaves privadas baixadas precisam de chmod 600 antes que o ssh aceite usá-las.
