Converta um nome de variável, um título ou um parágrafo inteiro entre nove formatos com um clique: camelCase, snake_case, kebab-case, Formato de Título, formato de frase, MAIÚSCULAS, minúsculas, alternado e inverso. Útil ao levar identificadores entre as convenções de JavaScript, Python, CSS e SQL.

Funcionalidade detalhada

As conversões no estilo de identificadores reconhecem os limites de palavra existentes: espaços, hífens e sublinhados separam palavras, assim como as transições de minúscula para maiúscula, de letra para dígito e os acrônimos. Por isso getHTTPResponse é dividido em get, HTTP, Response, e XMLHttpRequest2 em XML, Http, Request, 2. Separadores repetidos viram um só, os do início e do fim são removidos e as demais pontuações ficam presas à sua palavra.

Quebras de linha e tabulações são mantidas, então uma lista de nomes é convertida linha a linha. Formato de frase coloca tudo em minúsculas e capitaliza a primeira letra depois de ., ! ou ?. Formato Inverso troca a caixa de cada letra e não mexe no resto; Formato Alternado alterna minúscula e maiúscula letra a letra. Cirílico, grego, latim com acentos e outros alfabetos com caixa funcionam; chinês, japonês e hindi não têm maiúsculas, então só os separadores mudam.

A conversão roda no JavaScript da página — o texto não é enviado a lugar nenhum. O resultado substitui o texto no mesmo campo, permitindo aplicar várias conversões seguidas.

Exemplos práticos

De JavaScript para Python: getHTTPResponse code com Snake Case vira get_http_response_code.

De propriedade CSS para JavaScript: background-color com Camel Case vira backgroundColor.

Acrônimo e dígito: XMLHttpRequest2 com Kebab Case vira xml-http-request-2.

Corrigindo maiúsculas: hello world. how are you? com Formato de frase vira Hello world. How are you?.

Como usar esta ferramenta

  1. 1

    Insira o texto

    Digite ou cole no campo Texto.

  2. 2

    Escolha o formato

    Em Converter para, clique em um botão como Camel Case ou Snake Case. O conteúdo do campo é substituído pelo resultado.

  3. 3

    Copie o resultado

    Clique em Copiar para copiar o texto convertido; Limpar esvazia o campo.

Dicas e melhores práticas

  • MAIÚSCULAS, minúsculas e Formato de Título também tratam _ e - como separadores e os trocam por espaços: user_id vira USER ID. Para obter USER_ID, aplique Formato Inverso ao user_id todo em minúsculas.
  • O formato de frase também deixa em minúsculas nomes próprios e siglas (HTTP server vira Http server) — corrija-os à mão.
  • O Formato de Título capitaliza todas as palavras, inclusive as curtas: the lord of the rings vira The Lord Of The Rings; ele não segue exceções de guias de estilo.
  • Uma maiúscula no meio da palavra inicia uma nova palavra: iPhone com Snake Case vira i_phone.
  • A conversão sobrescreve o campo; guarde o original em outro lugar se quiser comparar variantes.
