HTTP-клиент

Отправляйте HTTP-запросы с компьютера Windows через локальный агент без учётной записи и прокси MyDevTools.

Запросы идут с вашего компьютера Windows прямо к целевому серверу

Сохранённые запросы

Хранит последние 100 отправленных запросов как они написаны — переменные и секреты не подставляются, ответы не сохраняются. Лежит там же, где рабочее пространство.

    i Перетащите элементы в папку или на пустое место, чтобы переместить их в корень. Щёлкните правой кнопкой мыши или нажмите Shift+F10, чтобы открыть действия.

    URL, заголовки (включая секреты) и тела запросов автоматически сохраняются только в этом браузере. Ответы не сохраняются.

    Секреты

    Значения хранятся в зашифрованном хранилище агента и не возвращаются на страницу. Вставьте {{secret:name}} в URL, заголовок или тело: агент подставит значение только для указанных хостов и скроет его в ответе.

      Окружения

      Пишите {{имя}} в URL, параметрах, заголовках, теле и авторизации. Активное окружение важнее переменных папок, а они важнее глобальных. Для значения только на запись задайте переменной {{secret:имя}}.

      Настройки клиента

      Прокси

      Агент подключается через HTTP-прокси: CONNECT для https, абсолютные URL для http. Пароль прокси сохраняется вместе с рабочей областью.

      Клиентские сертификаты (mTLS)

      Агент предъявляет сертификат https-хостам из его списка, когда сервер его запрашивает. Закрытый ключ хранится в агенте в зашифрованном виде и на страницу не возвращается. Нужны PEM-файлы с незашифрованным ключом; .pfx сначала преобразуйте: openssl pkcs12 -in cert.pfx -out cert.pem -nodes

      Подключите агент с хранилищем секретов, чтобы добавить клиентские сертификаты.

        Клиентских сертификатов пока нет.

        Добавить сертификат

        Оставьте оба файла пустыми, чтобы сохранить прежние сертификат и ключ.

        Cookies

        Cookies из ответов попадают сюда и уходят с подходящими запросами: агент выбирает их по домену, пути и Secure на каждом переходе, включая перенаправления. Без «Сохранять cookies» они живут до закрытия страницы.

          Авторизация

          Переменные

          Доступны как {{имя}} всем запросам этой папки и вложенных; ближняя папка важнее.

          Скрипты

          Выполняются для каждого запроса в этой папке и вложенных, перед скриптами самого запроса.

          Данные

          Запросы выполняются по очереди в порядке дерева вместе со скриптами; переменные, изменённые скриптами, сохраняются. С файлом данных на каждую строку — своя итерация, значения доступны как pm.iterationData и {{столбец}}. Закрытие окна останавливает прогон.

              Импорт cURL

              Вставьте команду curl, например из DevTools браузера «Copy as cURL» (bash или cmd). Будет создан новый запрос; команда, вставленная в поле URL, заменяет открытый запрос.

              Код запроса

              Собран из открытого запроса: переменные подставлены, {{secret:…}} остаётся плейсхолдером, файлы указаны по имени. Подпись AWS и токен OAuth действуют ограниченное время.

                        Отправляйте HTTP- и HTTPS-запросы без аккаунта и передачи учётных данных API через сервер MyDevTools. Небольшой агент на компьютере Windows выполняет сетевой запрос и возвращает странице статус, время, заголовки и тело ответа.
                        Подробное описание функциональности
                        Браузер явно сопрягается с агентом на 127.0.0.1 по короткому одноразовому коду. Токен подключения хранится в этом браузере до 8 часов или до перезапуска агента; код не сохраняется. Токен разрешает только http.request. Запрос идёт от агента прямо к цели. Публичные цели доступны по умолчанию, а приватные, loopback- и LAN-адреса требуют включения флажка «Разрешить локальную сеть и этот ПК как цель» в окне агента (или параметра --allow-private). Перенаправления по умолчанию выключены, а чувствительные заголовки удаляются при смене origin. Черновики запросов, включая URL, заголовки и секреты, а также тела автоматически сохраняются в этом браузере и открываются позже; ответы не сохраняются. Токен подключения хранится отдельно до 8 часов или до перезапуска агента. С актуальным агентом черновики хранит в зашифрованном виде агент на компьютере, а не браузер.
                        Практические примеры
                        Используйте GET для JSON endpoint, POST с Content-Type: application/json для проверки API или HEAD для метаданных без тела. Добавляйте Authorization: Bearer … только если он нужен целевому API: он отправляется цели, а не серверам MyDevTools.
                        Как использовать этот инструмент
                        1. 1
                          Установите и запустите агент
                          Скачайте агент Windows x64 и запустите его.
                        2. 2
                          Выполните сопряжение
                          Запросите код в окне агента, введите его здесь и нажмите Подключиться. Поле сразу очистится.
                        3. 3
                          Составьте запрос
                          Выберите метод, укажите HTTP- или HTTPS-URL, добавьте заголовки и исходное тело UTF-8.
                        4. 4
                          Отправьте и изучите
                          Просмотрите статус, время, итоговый URL, все заголовки и безопасный текстовый предпросмотр. Двоичное тело скачивается побайтно.
                        Советы и лучшие практики
                          

                        • Оставьте перенаправления выключенными, чтобы увидеть первый ответ.
                          • 

                        • Заголовок Authorization уходит целевому сервису; не публикуйте снимки с секретами.
                          • 

                        • Не включайте приватную сеть без явной необходимости тестировать доверенный LAN-сервис.
                          • 

                        • Сопряжение не разрешает будущие функции сканирования портов или сети.
