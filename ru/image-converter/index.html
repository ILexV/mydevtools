Конвертируйте изображение между PNG, JPEG, WebP, GIF, BMP, ICO, TIFF и TGA в браузере — для favicon, устаревших форматов или чтобы перевести скриншот в WebP. Файл обрабатывается локально и никуда не загружается.

Подробное описание функциональности

На вход подходит любой из восьми форматов; формат результата выбирается в поле Целевой формат. Ползунок качества появляется только для JPEG и WebP (по умолчанию 90), остальные форматы его игнорируют. Изображения ICO крупнее 256 px уменьшаются до 256×256 с сохранением пропорций, в JPEG прозрачные области исходника получают белый фон, а 16-битные исходники приводятся к 8 битам на канал.

WebP кодируется браузером с потерями при выбранном качестве; если браузер этого не умеет, создаётся WebP без потерь, и пояснение сообщает, что качество не применено. Ориентация из EXIF применяется к пикселям, метаданные не копируются. У анимированного GIF конвертируется только первый кадр.

Браузеры не умеют показывать TIFF и TGA, поэтому для таких результатов выводится только размер — файл всё равно скачивается. Конвертация выполняется в Web Worker на Rust/WebAssembly, её можно отменить.

Практические примеры

Логотип в favicon: логотип PNG 1024×1024 после конвертации в ICO становится иконкой 256×256 размером 10.24 KB и сохраняется как logo.ico.

Прозрачный PNG в JPEG: прозрачные области получаются белыми, а не чёрными.

JPEG в WebP: фото 1920×1280 размером 476.38 KB при качестве 90 даёт 433.54 KB; снизьте качество, чтобы сэкономить больше.

Игровая текстура: texture.tga 640×480 после конвертации в PNG открывается где угодно как texture.png.

Как использовать этот инструмент

  1. 1

    Выберите изображение

    Нажмите Выбрать файл или перетащите файл PNG, JPEG, WebP, GIF, BMP, ICO, TIFF или TGA в зону загрузки.

  2. 2

    Выберите целевой формат

    Укажите формат в поле Целевой формат. Для JPEG и WebP настройте Качество (JPEG, WebP).

  3. 3

    Конвертируйте

    Нажмите Конвертировать. Долгую задачу можно остановить кнопкой Отмена.

  4. 4

    Скачайте

    Проверьте Размер: и предпросмотр, затем нажмите Скачать, чтобы сохранить <name>.<ext>.

Советы и лучшие практики

  • PNG подходит для скриншотов и текста, JPEG или WebP — для фотографий.
  • Для favicon берите квадратное изображение не меньше 256×256 px; более крупные уменьшаются до 256 px.
  • Конвертация JPEG в PNG не вернёт потерянные детали — файл просто станет больше.
  • У результатов TIFF и TGA нет предпросмотра в браузере, но скачанный файл полноценный.
  • Анимированный GIF теряет анимацию: сохраняется только первый кадр.
