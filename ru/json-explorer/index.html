Обозреватель больших JSON / JSONL

Открывайте, индексируйте, ищите и экспортируйте большие JSON и JSONL локально: виртуальная таблица, ленивое дерево и точные числа.

Введённые данные и файлы остаются в браузере

Локальный файл

Перетащите файл JSON, JSONL или NDJSON

Файл остаётся в браузере. JSONL читается потоком, обычный JSON ограничен выбранным объёмом памяти.

Обычный JSON загружается только до выбранного лимита 8–64 МиБ. JSONL читается блоками по 1 МиБ с лимитом 1–8 МиБ на запись и максимальной глубиной 256. Это явные защитные ограничения, а не обещание неограниченной памяти.

Файлы, запросы и найденные столбцы не покидают устройство и не сохраняются локально; запоминаются только формат и защитные настройки.

Обработка файла

Записи

Выберите локальный JSON или JSONL, чтобы изучить структуру и записи.

Поиск, фильтр и проекция

Один указатель RFC 6901 JSON Pointer на строку, не более 100 полей. Пустой список оставляет автоматические столбцы верхнего уровня. Экранируйте ~ как ~0, а / как ~1. Проекция JSONL — плоский объект с точными указателями в ключах; отсутствующее поле становится null.

Автостолбцы изучают первые 10 000 записей и показывают не более 100 полей верхнего уровня. Имена, чей кодированный JSON Pointer длиннее 256 символов, и метаданные имён свыше 16 384 символов автоматически не добавляются. Поля не удаляются: используйте точный JSON Pointer. Предпросмотр ячейки ограничен 512 символами; инспектор и экспорт используют полные значения.

Выбранная запись

Выберите строку таблицы, чтобы загрузить полную исходную запись.

Экспорт текущего результата
Экспорт повторно сканирует все совпавшие записи, а не только видимые строки. Результат собирается ограниченными блоками до 256 МиБ в браузере. CSV соответствует RFC 4180, использует CRLF и UTF-8 BOM.

Исследуйте большие массивы JSON и построчный JSON без загрузки конфиденциальных данных на сервер. Инструмент строит локальный разреженный индекс, отображает небольшое окно виртуальной таблицы и загружает запись или ветвь дерева только по запросу.
Подробное описание функциональности
JSONL / NDJSON декодируется как UTF-8 блоками по 1 МиБ. Поддерживаются BOM, CRLF и последняя строка без перевода строки, а ошибка содержит физический номер строки и столбец. В памяти остаются лишь разреженные контрольные точки и ограниченные метаданные столбцов; для далёких окон, фильтра и экспорта записи читаются повторно.



Обычный JSON поддерживает объекты, массивы и скалярный корень с ленивым деревом. Корневой массив также доступен как таблица записей. Поскольку единый документ нельзя независимо индексировать как JSONL, действует явный лимит 8–64 МиБ и разбор в worker. Глубина ограничена 256, запись JSONL — выбранными 1–8 МиБ.



Исходная запись чисел сохраняется. 9007199254740993, 1.0 и экспоненциальные формы не проходят через JavaScript Number при экспорте. Фильтр сканирует все записи, не создавая полный массив совпадений; для виртуальной таблицы используются разреженные точки.
Практические примеры
Журналы API: откройте .ndjson, найдите timeout в значениях и отфильтруйте /service по billing. Щелчок по строке загружает полный исходный JSON.



Вложенные поля: укажите /id и /user/name; /a~1b обращается к ключу a/b. Таблица и CSV используют указатели как столбцы, а JSONL — как ключи с точными значениями.



Большие идентификаторы: экспорт {"id":9007199254740993,"price":1.0} сохраняет обе числовые формы.



Большой массив: раскрывайте только нужные ветви и прокручивайте виртуальную таблицу без DOM-строки для каждого элемента.
Как использовать этот инструмент
  1. 1
    Выберите формат и лимиты
    Укажите автоопределение, JSON или JSONL/NDJSON и настройте предел документа, записи и глубины.
  2. 2
    Откройте локальный файл
    Перетащите или выберите файл. Worker покажет байты, время, скорость и оценку остатка. Отмена безопасно удаляет сеанс.
  3. 3
    Найдите или спроецируйте
    Ищите в ключах и значениях, задайте RFC 6901 путь и подстроку либо перечислите пути проекции по одному в строке.
  4. 4
    Изучите и экспортируйте
    Прокручивайте таблицу, открывайте полную запись, лениво раскрывайте дерево или скачайте все совпадения как JSONL либо CSV.
Советы и лучшие практики
    

  • Для надёжного автоопределения используйте расширение .jsonl или .ndjson; неоднозначный файл задавайте явно.
    • 

  • Пустые строки JSONL пропускаются, но ошибки используют физические номера строк.
    • 

  • Пустой JSONL — допустимый результат из нуля записей, пустой обычный JSON недопустим.
    • 

  • В JSON Pointer / разделяет сегменты, ~0 означает тильду, ~1 — косую черту.
    • 

  • Защита CSV от формул для =, +, -, @ включена по умолчанию.
    • 

  • Экспорт включает все отфильтрованные строки и прекращается до явного предела 256 МиБ.
