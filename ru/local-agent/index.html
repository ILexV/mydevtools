Помощник для Windows

Подключите браузерные инструменты к своему ПК с Windows

Локальный агент предоставляет выбранным инструментам MyDevTools явно разрешённую возможность на вашем компьютере. Установщик кладёт его в профиль пользователя, аккаунт не нужен, управление — из трея Windows.

Скачайте, запустите и подключите

Файл загрузки — установщик для текущего пользователя. Он помещает агент в профиль пользователя. Повторный запуск более новой сборки заменяет эту копию.

  1. 1

    Скачайте

    Скачайте установщик. Повторный запуск более новой сборки заменяет установленный агент.

  2. 2

    Запустите

    Откройте установщик. Он останавливает уже запущенный агент и записывает новую копию. Windows может попросить подтвердить запуск скачанного приложения; права администратора не нужны.

  3. 3

    Подключите

    Введите свежий код из окна агента в инструмент MyDevTools. Подключение даёт только возможность, запрошенную этим инструментом.

Минимальные разрешения

Агент — не аккаунт, не удалённый сервис и не универсальный запуск команд.

  • Без регистрации, входа и облачного прокси MyDevTools.
  • Без прав администратора и без службы Windows. Установщик работает только для текущего пользователя.
  • Одноразовый сменяемый код создаёт ограниченный по времени сеанс браузера. Браузер хранит токен подключения до 8 часов или до перезапуска агента, но никогда не сохраняет код сопряжения.
  • Агент слушает только этот ПК. Запросы и пробы идут от агента напрямую к цели, а через прокси — только если вы его задали. Адреса частной сети как цель заблокированы, пока вы не разрешите их в окне агента. Маршрутизаторы на пути показываются, даже если у них частный адрес.

Контроль остаётся у вас

Закрытие небольшого окна скрывает его; значок в трее открывает окно снова.

  • Просматривайте версию и текущий код подключения.
  • Автозапуск включается по желанию и по умолчанию выключен. Он использует настройки пользователя Windows и сохраняется, когда новый установщик заменяет агент.
  • «Разрешить локальную сеть и этот ПК как цель» по умолчанию выключено. Включение открывает инструментам частные и петлевые адреса и сканирование своей сети; выбор запоминается, а выключение останавливает идущее сканирование частной цели.
  • Команда «Выход» полностью останавливает локальный сервер и отзывает активные сеансы.

Зашифрованное хранилище на этом ПК

Инструменты, которые запросили хранилище, держат свои данные в агенте, а не в браузере.

  • Каждый файл зашифрован AES-256-GCM; ключ защищён Windows для вашей учётной записи.
  • Секреты и ключи клиентских сертификатов доступны только на запись: страница может подставить их в запрос, но не прочитать.
  • У каждого сайта своё хранилище, и один сайт не читает данные другого.
  • Чтобы перенести его на другой компьютер, нажмите «Экспорт хранилища…» и «Импорт хранилища…» в окне агента: один файл для всех сайтов, зашифрованный вашим паролем (Argon2id и AES-256-GCM). Страница запустить экспорт не может.

Доступная возможность

Этот выпуск умеет подключать HTTP-запросы, WebSocket-соединения, Server-Sent Events, хранилище для рабочих пространств и секретов, ICMP-трассировку, DNS-запрос, TCP-проверку, просмотр TLS, WHOIS и поиск ASN, сканер портов и сканер сети. Каждый инструмент запрашивает собственную именованную возможность; подключение не разрешает будущие возможности автоматически, поэтому после обновления инструмент может попросить подключиться заново.

Проверьте скачанный файл

Установщик не подписан цифровой подписью: Windows SmartScreen может показать предупреждение или заблокировать запуск. Не отключайте защиту Windows. Для проверки целостности сравните SHA-256 скачанного файла со значением выше; совпадение хеша не заменяет подпись издателя.
