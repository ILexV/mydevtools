Обозреватель Parquet

Откройте локальный файл Parquet, посмотрите схему и группы строк, отфильтруйте строки, сгруппируйте с итогами и листайте выбранные колонки в виртуальной таблице.

Перетащите файл Parquet сюда

Один файл .parquet. Он остаётся на этом устройстве.

Нижний колонтитул, выбранные колонки и экспорт читаются в Web Worker. Содержимое файла и схема никуда не отправляются и не сохраняются.

Чтение Parquet

Обозреватель

Выберите файл Parquet, чтобы увидеть схему, группы строк и виртуальный просмотр колонок.

Фильтр строк

Строка должна подходить под все условия. Числа сравниваются точно по значению (64-битные целые и decimal без потери цифр), время — по моменту (введите 2024-03-01 или 2024-03-01T12:00:00Z), логические значения — как true/false, текст и вложенные значения — по показанному тексту. Пустое значение подходит только под «пусто». Фильтр один раз проходит колонки из условий по всему файлу; дальше таблица, итоги и экспорт работают с подходящими строками.

Группировка и итоги

Считает строки текущего фильтра по группам. Для колонки итогов добавляет число непустых значений, минимум и максимум, а для целых, decimal и чисел с плавающей точкой — точную сумму и среднее. Время группируется и сравнивается как текст ISO. До 100 000 групп.

Видимые и экспортируемые колонки

Выбранная строка

Выберите строку таблицы, чтобы увидеть более длинные значения.

На экране значение укорочено. В экспорте значение сохраняется до предела ячейки.

Экспорт

Рекомендуется: к ячейкам, которые таблица может выполнить как формулу =, +, - или @, добавляется апостроф.

Защита формул выключена. CSV сохранит исходные значения, но открывать его в таблице может быть небезопасно.

Экспорт читает выбранные колонки всех подходящих строк по группам строк и записывает их в файл потоком с обратным давлением; окна без подходящих строк пропускаются. Без системного диалога сохранения используется резервная загрузка до 512 МиБ.

Группы строк с offset index читаются окнами по 65 536 строк; группа без него распаковывается целиком для каждой выбранной колонки. Вложенные значения становятся JSON. INT64 сохраняет десятичную запись. Поддерживаются несжатые данные, Snappy, gzip, Brotli, Zstd, LZ4 и LZ4_RAW. LZO не поддерживается. Сортировки, SQL и записи Parquet здесь нет.

Обозреватель Parquet открывает файл Apache Parquet целиком в браузере. Он читает нижний колонтитул со схемой и статистикой групп строк, а затем декодирует только те колонки, которые вы отметили, поэтому широкий или длинный файл не превращается в одну HTML-таблицу.

Подробное описание функциональности

Файл остаётся на этом устройстве. Web Worker читает колонтитул PAR1 кусками файла и показывает колонки верхнего уровня, физический и логический тип, повторяемость и кодек сжатия. У групп строк видны число строк и сжатый размер. Таблица виртуализирована: прокрутка запрашивает небольшое окно строк только для отмеченных колонок.

INT64 и другие целые, которые не помещаются в число JavaScript, сохраняют десятичные цифры. Метки времени становятся текстом UTC ISO-8601. Двоичные ячейки показаны как шестнадцатеричные строчные цифры. Вложенные структуры и списки — это JSON. Повторяющимся именам колонок добавляется номер, чтобы ключи JSONL оставались уникальными.

Экспорт читает все строки выбранных колонок и записывает их в файл потоком с обратным давлением. Без системного диалога сохранения используется резервная загрузка до 512 МиБ.

Выбранный кусок колонки распаковывается целиком. Вложенные значения становятся JSON. INT64 сохраняет десятичную запись. Поддерживаются несжатые данные, Snappy, gzip, Brotli, Zstd, LZ4 и LZ4_RAW. LZO не поддерживается. Здесь нет SQL-фильтра, сортировки и записи Parquet.

Фильтр объединяет до восьми условий по любым колонкам: содержит, равно, сравнения и проверки на пустоту; числа сравниваются точно, время — по моменту. Результат хранится как один бит на строку, поэтому даже файл в сотни миллионов строк фильтруется без хранения подходящих строк в памяти. Итоги группировки считают строки по значениям, добавляют точные суммы, средние, минимумы и максимумы и выгружаются в CSV или JSONL.

Практические примеры

Плоские колонки: файл с name (строка) и id (INT64) открывается с обеими колонками. Идентификатор 9007199254740993 остаётся этой же десятичной записью в таблице, в CSV и в JSONL.

Проекция колонок: снимите «Выбрать все», оставьте name и прокрутите таблицу. Остальные куски колонок для этого просмотра не декодируются. В экспорте только отмеченные колонки.

Несколько групп строк: список показывает число строк и кодек каждой группы. Таблица читает их как одну последовательность.

Текст, похожий на формулу: значение =1+1 уходит в CSV как '=1+1, пока защита формул включена. JSONL сохраняет исходную строку.

Как использовать этот инструмент

  1. 1

    Шаг 1. Откройте локальный файл

    Перетащите или выберите один файл .parquet. При чтении колонтитула видны байты, скорость и время. Отмена и повторный выбор начинают заново.

  2. 2

    Шаг 2. Прочитайте схему

    Посмотрите типы, повторяемость и сжатие колонок, затем размеры групп строк. Пары метаданных из колонтитула показываются, если они есть в файле.

  3. 3

    Шаг 3. Листайте колонки

    Снимите отметку с ненужных колонок. Прокрутите виртуальную таблицу и выберите строку, чтобы увидеть более длинные значения.

  4. 4

    Шаг 4. Отфильтруйте и посчитайте итоги

    Добавьте условия, например amount > 100 и category равно books, примените их — таблица, просмотр строки и экспорт переключатся на подходящие строки. Сгруппируйте по колонке и посчитайте по другой количество, сумму, среднее, минимум и максимум.

  5. 5

    Шаг 5. Экспортируйте

    Экспорт читает все строки выбранных колонок и записывает их в файл потоком с обратным давлением. Без системного диалога сохранения используется резервная загрузка до 512 МиБ.

Советы и лучшие практики

  • Для текущей таблицы и для скачивания декодируются только отмеченные колонки. Крупные двоичные колонки лучше выключить, если нужны только ключи.
  • Если файл записан с offset index, обозреватель читает окна по 65 536 строк; без него выбранный кусок колонки распаковывается целиком для своей группы строк, поэтому очень крупным группам нужно больше памяти.
  • В JSONL целые, которые не помещаются в безопасное число JavaScript, записываются десятичной строкой, а не округлённым числом.
  • Больше 512 колонок верхнего уровня отклоняется. В списке первые 500 групп строк; в сводке их полное число.
  • Сжатие LZO не поддерживается. Без сжатия, Snappy, gzip, Brotli, Zstd, LZ4 и LZ4_RAW поддерживаются.
  • Эта страница не выполняет SQL и не сортирует. Объединения, сортировка и запись Parquet — в SQL-песочнице и конвертере.
