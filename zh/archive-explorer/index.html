ZIP

压缩包浏览器

在浏览器中打开 ZIP、TAR、TAR.GZ 以及 Zstandard 或 Brotli 压缩包，列出其内容，安全解压所选文件，并创建新的 ZIP 或 TAR 压缩包。

输入内容和文件始终留在浏览器中

压缩包

压缩包文件

ZIP、TAR、TAR.GZ、TGZ、TAR.ZST、TAR.BR、GZ、ZST 或 BR。文件始终保留在此设备上。

压缩包在 Web Worker 中以 1 MiB 块读取，并在 WASM 中解包。不会上传任何内容，也不会保存文件名、内容和选择。

正在处理压缩包

内容

选择一个压缩包以列出其中的文件和文件夹。

    点击某一行或按空格键将其选中。选择文件夹会选中其中的所有内容。

    解压

    写入任何内容之前都会检查路径：绝对路径、“..”、驱动器盘符和控制字符会被跳过，链接绝不会被创建；文件夹中已存在的文件会被保留，新文件则以“ (2)”名称保存。每个条目都必须与其声明的大小和 CRC-32 一致。

    最多 1,000,000 个条目和 256 MiB 的中央目录。当数据在超过 64 MiB 后膨胀超过 1000 倍，或输出超过 64 GiB 时，解压将停止。ZIP 方法：Stored、Deflate 和 Zstandard；加密条目不会被打开。在没有保存对话框的浏览器中（Firefox、Safari），下载限制为 512 MiB。

    要打包的文件

    拖放的文件会添加到列表中。“添加文件夹”会保留文件夹结构。

    尚未添加文件。

    ZIP 使用 Deflate 和 UTF-8 文件名，对于 4 GiB 及以上的文件会切换为 ZIP64。TAR 使用 ustar 头，长名称或非 ASCII 名称使用 pax；TAR.GZ 和 TAR.ZST 会压缩整个数据流。

    压缩包浏览器可直接在浏览器中打开 ZIP、TAR 以及压缩的 TAR 压缩包（gzip、Zstandard、Brotli）。它会列出每个条目的大小、压缩后大小、日期和方法，将所选文件解压到文件夹或新的 ZIP 中，还能把你自己的文件打包为 ZIP、TAR、TAR.GZ 或 TAR.ZST。不会上传任何内容。

    详细功能

    ZIP 通过其中央目录读取，支持 ZIP64 压缩包、自解压存根和 Info-ZIP Unicode 文件名，因此即使包含一百万个条目的压缩包也无需解包即可打开。TAR 压缩包逐个读取文件头，支持 GNU 长文件名和 pax 记录；压缩的 TAR 在 Web Worker 中通过一次流式处理解包。Deflate、gzip、Zstandard 和 Brotli 在 WASM 中运行，输出窗口有上限，因此压缩炸弹每次最多只会膨胀 1 MiB。

    解压过程可防御路径穿越（Zip Slip）：绝对路径、驱动器盘符、“..”片段和控制字符绝不会被写入，符号链接和硬链接绝不会被创建，Windows 拒绝的字符或设备名会被替换。每个条目都必须与其声明的大小和 CRC-32 一致；重叠条目、超过 64 MiB 后压缩比高于 1000:1 以及输出超过 64 GiB 都会使解压停止。在基于 Chromium 的浏览器中，文件会直接写入你选择的文件夹，并保留已有文件；在其他浏览器中，所选内容会作为一个 ZIP 下载。

    创建压缩包时，每个文件都会以流式方式经过压缩器写入你保存的文件，使用 UTF-8 文件名，4 GiB 及以上的文件使用 ZIP64，长 TAR 名称使用 pax 头。

    实用示例

    查看下载内容： 打开一个 2 GB 的 release.zip，一秒内即可看到其中的 40,000 个文件及其大小，无需解包。

    从备份中取出一个日志： 按“2026-10”筛选 logs.tar.gz，选择匹配的文件，只将它们解压到文件夹。

    检查可疑压缩包： 条目中包含“../../etc/passwd”的 ZIP 会被列出，这些条目被标记为不安全，并且绝不会被写入。

    打包项目文件夹： 添加一个文件夹，选择 TAR.ZST 级别 3，保存一个保留文件夹结构的压缩包。

    如何使用此工具

    1. 1

      打开压缩包

      拖放或选择 ZIP、TAR、TAR.GZ、TAR.ZST、TAR.BR、GZ、ZST 或 BR 文件。读取完成后会显示条目列表。

    2. 2

      查找并选择文件

      在“筛选”中输入名称的一部分，然后点击行或使用“选择匹配项”。选择文件夹会选中其中的所有内容。

    3. 3

      解压

      在基于 Chromium 的浏览器中选择“解压到文件夹…”，在任何浏览器中都可选择“下载为 ZIP”，选中单个文件时可选择“保存文件”。

    4. 4

      创建压缩包

      在“创建压缩包”下添加文件或文件夹，选择格式和级别，然后保存新的压缩包。

    提示和最佳实践

    • 不含 TAR 的单个 .gz、.zst 或 .br 文件显示为一个条目；其大小只有解压后才能得知。
    • 加密的 ZIP 条目以及 BZIP2、LZMA 或 Deflate64 等方法会被列出，但不会被解压。
    • “取消”会立即停止处理进程；写入了一部分的文件会被丢弃。
    • 想比较 gzip、Brotli 和 Zstandard 处理你的数据的效果，请试试“压缩基准测试”。

    编码

    • B64Base64 编码 / 解码将文本或文件编码为 Base64 并解码还原：标准或 URL 安全字母表、填充控制、每 76 字符换行、图片预览。全部在浏览器中完成。
    • B32Base32 编码器 / 解码器使用 RFC 4648、Crockford 或 z-base-32 字母表编码和解码 Base32，支持填充与大小写选项，适用于文本和文件，全部在浏览器中完成。
    • B58Base58 编码器 / 解码器使用 Bitcoin、Flickr 或 Ripple 字母表编码和解码 Base58，支持文本和不超过 1 MiB 的文件。在浏览器本地运行，不上传任何数据。
    • 0xHex 编码 / 解码将文本或文件转换为十六进制并还原。可选字符集和大小写；解码时支持空格、冒号、连字符或 0x 前缀分隔的 hex。在浏览器中运行。
