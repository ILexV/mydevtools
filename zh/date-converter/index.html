日期转换器

将秒或毫秒级 Unix 时间戳转换为 ISO 8601、RFC 5322、UTC、本地时间或自定义格式，也可反向转换，输入即出结果。

输入内容和文件始终留在浏览器中

输入 Unix 时间戳（秒或毫秒）或 ISO 8601 日期。

转换后的日期将显示在这里。

把 Unix 时间戳转换为可读日期，或把日期字符串转换回时间戳。自动识别秒、毫秒和 ISO 8601，可输出 ISO、RFC 5322、UTC、本地时间、欧洲格式或自定义格式。

详细功能

自动检测模式下，整数部分不超过 11 位的数字按 Unix 秒处理，更长的按毫秒处理；支持负数（1970 年以前的日期）和小数。其他输入按日期字符串解析：ISO 8601（2024-02-29T12:00:00Z）、RFC 5322（Tue, 14 Nov 2023 22:13:20 GMT）以及浏览器日期解析器能识别的其他格式。也可以把输入类型固定为秒、毫秒或 ISO 8601——此时 0x10、1e3 等十六进制或科学计数写法会被拒绝，而不是被猜测。

共有八种输出格式：带毫秒的 UTC ISO 8601、欧洲格式 dd.MM.yyyy HH:mm:ss、UTC 字符串、按页面语言和你的时区显示的本地时间、带数字时区 +0000 的 RFC 2822/5322、Unix 秒、Unix 毫秒，以及由 yyyy、MM、dd、HH、mm、ss、SSS 组成的自定义格式。结果随输入实时更新，“当前时间”按钮会填入此刻。

所有处理都由 JavaScript 借助浏览器自带的 Date 和 Intl API 完成，粘贴的值不会发送到任何地方。支持范围与 JavaScript 日期相同，大约为 1970 年前后各 27.3 万年；超出范围会提示无效。

实用示例

日志中的时间戳：1700000000（秒）→ ISO 8601 2023-11-14T22:13:20.000Z。同一时刻的毫秒值 1700000000000 也会被自动识别。

日期转 Unix 时间：2024-02-29T12:00:00Z 选择 Unix 秒输出，得到 1709208000。

纪元之前：-86400 → 1969-12-31T00:00:00.000Z，正好是 1970 年 1 月 1 日的前一天。

邮件头日期：1700000000 选择 RFC 2822 / 5322 输出，得到 Tue, 14 Nov 2023 22:13:20 +0000。

如何使用此工具

  1. 1

    粘贴数值

    在“日期 / 时间戳”中输入 Unix 时间戳或日期字符串，或点击“当前时间（现在）”填入当前时间。

  2. 2

    确认输入类型

    “输入类型”保持“自动检测”，若数值有歧义，可明确选择秒、毫秒或 ISO 8601。

  3. 3

    选择输出格式

    在“输出格式”中选择格式；选择“自定义格式”时，输入如 yyyy-MM-dd HH:mm 的模式。

  4. 4

    复制结果

    结果会自动更新（“转换”可手动重新计算），点击“复制”即可复制。

提示和最佳实践

  • 1973 年 3 月之前的毫秒值不超过 11 位，在自动模式下会被当作秒——请为它们选择毫秒输入类型。
  • 不带时区的 ISO 字符串（2024-02-29T12:00）按你的本地时区解释；加上 Z 或 +08:00 等偏移可避免依赖本机设置。
  • ISO 8601、UTC 和 RFC 输出始终为 UTC；欧洲格式和自定义格式使用浏览器的本地时区。
  • 自定义模式中 MM 表示月份，mm 表示分钟；其他字符原样保留。
  • 本地时间按页面语言显示，因此同一时刻在中文页和英文页上的写法不同。
