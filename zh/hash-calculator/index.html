哈希计算器

用 39 种算法依次计算文本或多个文件的哈希。可比较预期摘要、查看速度和剩余时间，并导出 TXT、CSV 或 JSON。

输入内容和文件始终留在浏览器中

输入或粘贴文本，添加一个或多个文件，或加载示例。

文件优先于文本。每次新选择或拖放的文件都会加入列表，并可单独移除。

    算法

    哈希值

    点击“计算”后，所选算法的哈希值将显示在这里。

    用于与所选算法比较的十六进制摘要。忽略大小写和首尾空格。

      哈希计算器可为文本或多个文件计算多达 39 种哈希与校验和算法：MD5、SHA-1、SHA-2 与 SHA-3 系列、BLAKE2/BLAKE3、RIPEMD、Streebog、CRC32、xxHash 等。文件在浏览器的 Web Worker 中依次处理，绝不会上传；每个文件都有独立的结果或错误。

      详细功能

      可任意组合 39 种算法（列表支持按名称筛选；重置为默认值 恢复 MD5、SHA-1 和 SHA-256）。localStorage 只保存算法选择。文本按输入原样的 UTF-8 字节计算，包括空格和换行；结果以小写十六进制显示。

      可通过选择或拖放添加文件：每次添加都会追加到列表，单个文件可以移除；只要列表中有文件，就优先处理文件而非文本。Rust/WebAssembly 模块在 Web Worker 中一次处理一个文件，以 1 MiB 分块读取，并在同一遍读取中向所有已选算法提供数据。进度会显示已处理字节数、速度、已用时间和剩余时间。某个文件出错不会阻止后续文件。取消 会立即终止当前 Worker，保留已完成结果，并将当前及尚未处理的文件标记为已取消；再次点击 计算 会开始全新的一轮。

      可选的预期十六进制摘要无需重新计算，就能与每个已完成的文本或文件结果比较；只有对应算法的匹配行会被标记。修改文本、文件或算法后，结果会变为过期状态，直到重新计算。可下载的 TXT、CSV 和 JSON 报告包含来源类型、文件名和大小、状态、耗时、算法 ID 与摘要以及最终错误，但绝不包含原始内容。已完成、失败和已取消的条目都会保留在导出中。

      密码学哈希（SHA-2、SHA-3、BLAKE2/BLAKE3、Streebog）适合做完整性校验；MD5 和 SHA-1 只用于比对旧的校验值。CRC32、Adler-32、xxHash、FNV-1a、FxHash、SeaHash 和 MetroHash 是快速的非密码学校验和，SipHash/HighwayHash 使用全零密钥计算。本工具不计算带密钥的 MAC，也不做密码哈希。

      实用示例

      短字符串的哈希：hello 的 MD5 为 5d41402abc4b2a76b9719d911017c592，SHA-1 为 aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d，SHA-256 为 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824。

      末尾换行会改变哈希：hello 后按回车得到 SHA-256 5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03，与 echo hello | sha256sum 相同；printf hello | sha256sum 则与上一个值一致。

      校验下载文件：选择下载的文件，保留 SHA-256，并与下载链接旁公布的校验值比较。空输入的结果始终是 e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855。

      非 ASCII 文本：привет 按 UTF-8 计算，SHA-256 为 e58f1e8c55fa105bdd3f40e5037eb0b039b5998d52c05e6cd98878dd2da5cab2，与对含该词的 UTF-8 文件运行 sha256sum 的结果相同。

      用 SHA256SUMS 校验发布文件：选择已下载的文件，点击 校验和文件 并选择随发布提供的 SHA256SUMS（或 *.sha256、md5sum 输出、BSD 格式 SHA256 (file) = … 列表），然后点击 计算。按文件名匹配，每个文件会标记为一致或不一致，摘要列出不一致的文件、未选择的条目以及列表中没有的已选文件。校验和文件指定的算法会自动选中。校验和一致只能证明文件完整；列表本身是否可信需要它的签名（SHA256SUMS.asc、.sig）。

      如何使用此工具

      1. 1

        输入文本或添加文件

        在 输入文本 中输入或粘贴内容，或在 文件（可选） 中选择或拖放一个或多个文件。之后选择的文件会继续追加，单个文件可移除；列表中有文件时以文件为准。

      2. 2

        选择算法和预期摘要

        在 算法 中勾选需要的算法。还可以粘贴十六进制摘要，与每个已完成结果进行比较。

      3. 3

        计算或取消

        点击 计算。文件依次处理，进度显示字节数、速度、已用时间和剩余时间。点击 取消 会停止当前文件、保留已完成结果，并将未处理文件标记为已取消。

      4. 4

        查看并导出

        查看每个文件的哈希、匹配标记、状态或错误。可复制单个摘要，或将当前结果下载为 TXT、CSV 或 JSON。

      提示和最佳实践

      • 想得到与 sha256sum 文件 相同的结果，请直接对文件计算，而不是粘贴其内容：复制时换行符可能改变，末尾换行也可能丢失。
      • 整数型校验和（CRC32、Adler-32、xxHash、FNV-1a）以十六进制数值显示，与 zlib、crc32 和 xxhsum 的输出一致：hello 的 CRC32 为 3610a686。
      • MD5 和 SHA-1 已可实际构造碰撞，只应用于比对已有校验值；新的校验请用 SHA-256、SHA-3 或 BLAKE3。
      • 文件逐个处理，所有已选算法共用对每个文件的一次读取；浏览器自身的内存限制仍然适用。
      • 单个文件失败不会停止后续文件。取消时会保留已完成结果，失败和已取消的行也可包含在 TXT、CSV 和 JSON 导出中。
      • 签名 API 请求或校验 Webhook 需要带密钥的哈希，请使用 HMAC 计算器。
