                        无需创建账户，也无需让 API 凭据经过 MyDevTools 服务器，即可发送 HTTP 和 HTTPS 请求。Windows 上的小型助手负责网络连接，并把状态、耗时、标头和正文返回本页面。
                        详细功能
                        浏览器使用一次性代码与 127.0.0.1 上的助手明确配对。连接令牌会存储在此浏览器中，最长 8 小时或直到助手重启；配对码不会存储。令牌仅授予 http.request。请求从助手直达目标。私有网络需要在代理窗口中勾选“Allow local network and this PC as targets”（或使用 --allow-private）；重定向默认关闭，跨来源时会删除敏感标头。 请求草稿（包括 URL、标头和密钥）及正文会自动保存在此浏览器中，以便稍后重新打开；响应不会保存。连接令牌单独保存，最长 8 小时或直到助手重启。使用新版代理时，草稿由代理加密保存在电脑上，而不是浏览器中。
                        实用示例
                        用 GET 查看 JSON，用带 Content-Type: application/json 的 POST 测试 API，或用 HEAD 查看元数据。仅在目标需要时添加 Authorization: Bearer …；它会发送给目标，而不是 MyDevTools。
                        如何使用此工具
                        1. 1
                          安装并启动助手
                          下载 Windows x64 助手并启动。
                        2. 2
                          配对
                          在助手窗口申请代码，输入后点击连接。
                        3. 3
                          编写请求
                          选择方法，输入 HTTP 或 HTTPS URL、标头和 UTF-8 正文。
                        4. 4
                          发送并检查
                          查看状态、耗时、最终 URL、标头和安全文本预览；二进制正文可逐字节下载。
