将图片缩放到精确的像素尺寸，可选择锁定宽高比，并以 JPEG、PNG 或 WebP 下载。图片在浏览器中处理，不会上传。

详细功能

选择文件后，工具会读取原始尺寸并填入 宽度 (像素) 和 高度 (像素)。开启 保持宽高比 时，修改一边会按原始比例重新计算另一边；关闭后可输入任意尺寸，图片会被拉伸以适应。重采样使用 Lanczos3 滤镜，缩小后的图片依然清晰。

输出 格式 根据文件扩展名预设（JPG 保持 JPEG，PNG 和 WebP 保持不变，其他一律为 PNG），也可以手动修改。JPEG 和 WebP 以质量 90 保存（WebP 在可用时使用浏览器的有损编码器），PNG 为无损。输入可以是 PNG、JPEG、WebP、GIF、BMP、ICO、TIFF 或 TGA；浏览器无法显示的格式由 WebAssembly 解码用于预览。

尺寸必须是正整数，每边最多 16384 px，总计不超过 6400 万像素；无效值会在处理开始前标出。缩放在 Web Worker 中运行，可以取消。文件命名为 <name>_<width>x<height>.<ext>。

实用示例

缩小一半：一张 1920×1280 的照片，宽度设为 960 并开启锁定，变为 960×640；保存为 WebP 时大小为 46.94 KB，下载文件名为 photo_960x640.webp。

精确正方形：关闭 保持宽高比，输入 512 × 512——图片会被拉伸，而不是裁剪。

尺寸过大：宽度 20000 会被拒绝，并提示“尺寸过大：每边最多 16384 像素，总计不超过 6400 万像素。”

TGA 输入：一张 640×480 的 .tga 纹理缩放到宽度 320，得到 320×240 的 PNG。

如何使用此工具

  1. 1

    选择图片

    点击 选择文件，或将图片拖放到区域中。原始尺寸显示在 原始图像 下。

  2. 2

    设置新尺寸

    输入 宽度 (像素) 或 高度 (像素)。保持 保持宽高比 开启即可维持比例。

  3. 3

    选择格式并缩放

    在 格式 中选择 JPEG、PNG 或 WebP，然后点击 缩放。耗时较长的任务可用 取消 停止。

  4. 4

    下载

    在 结果信息 下查看新尺寸，然后点击 下载。

提示和最佳实践

  • 缩小能保持画质；放大无法增加细节，只会让图片变得更模糊。
  • 除非确实想拉伸图片，否则请保持宽高比锁定。
  • 网页缩略图用 WebP 或 JPEG 可让文件更小；截图和带透明度的图形请用 PNG。
  • 目标尺寸很大时需要大量内存：6400 万像素的 RGBA 在浏览器中约占 256 MB。
  • EXIF、GPS 等元数据不会复制到缩放后的文件中。
