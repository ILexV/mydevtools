为何选择 MyDevTools？

MyDevTools 是一套免费的浏览器端开发者工具：JSON、XML 和 YAML 的格式化与校验，Base64、Hex 和 URL 编码器，哈希和 HMAC 计算器，JWT 和 X.509 工具，正则表达式测试器，图片和 PDF 工具，以及 UUID、密码和二维码生成器。无需安装，也无需注册账号。针对本地大文件，还有可处理数 GB 的 CSV、JSON、日志、Parquet 和 SQLite 浏览器、大文件对比和压缩包浏览器；可选的 Windows 代理程序还提供 HTTP 客户端和网络工具：DNS、WHOIS、TLS、路由追踪和端口扫描。

隐私来自架构本身：网站由静态页面组成，每个工具都在浏览器内处理你的输入。哈希、加密以及图片、PDF、二维码处理等计算密集型工具使用由 Rust 编译的 WebAssembly 模块；JSON 格式化、文本对比等较轻量的工具则是普通 JavaScript。你处理的密码、密钥和文件都不会被上传。

  • 隐私至上

    你的输入和文件只在浏览器中处理，绝不会发送。启用分析时，只会发送匿名操作计数、成功处理的粗略耗时区间、错误类别以及你提交的固定选项投票，绝不包含输入内容。

  • WebAssembly 用在关键处

    哈希、加密、图片和 PDF 处理在 Rust 编译的 WebAssembly 中运行；简单的工具使用轻量的 JavaScript。

  • 离线可用

    打开过一次的页面在断网时也能继续使用。安装 PWA 可快速访问。

  • 多语言

    界面和工具说明提供 10 种语言版本。

  • 完全免费

    所有工具均免费。无隐藏费用或订阅。

  • 打造你的工具集

    为常用工具加星标。收藏和最近使用的工具保存在你的浏览器中。
