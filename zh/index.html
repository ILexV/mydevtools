编码

6
B64Base64 编码 / 解码将文本或文件编码为 Base64 并解码还原：标准或 URL 安全字母表、填充控制、每 76 字符换行、图片预览。全部在浏览器中完成。
B32Base32 编码器 / 解码器使用 RFC 4648、Crockford 或 z-base-32 字母表编码和解码 Base32，支持填充与大小写选项，适用于文本和文件，全部在浏览器中完成。
B58Base58 编码器 / 解码器使用 Bitcoin、Flickr 或 Ripple 字母表编码和解码 Base58，支持文本和不超过 1 MiB 的文件。在浏览器本地运行，不上传任何数据。
0xHex 编码 / 解码将文本或文件转换为十六进制并还原。可选字符集和大小写；解码时支持空格、冒号、连字符或 0x 前缀分隔的 hex。在浏览器中运行。
%20URL 编码 / 解码以组件、URI 或表单模式对 URL 和查询字符串进行百分号编码与解码，支持 UTF-8、UTF-16 和 Latin-1 字符集，在浏览器本地运行。
&;HTML 实体编码器 / 解码器把 HTML 特殊字符转义为命名、十进制或十六进制实体，并将实体解码回文本。可正确处理表情符号，完全在浏览器中运行。

8
{}JSON 格式化在浏览器中格式化、压缩和校验 JSON：支持 2/4 空格或制表符缩进、递归排序键、大数字原样保留，可打开和保存 .json 文件。
TSJSON 转 TypeScript 转换器根据 JSON 示例生成 TypeScript interface 或类型别名：嵌套类型、合并数组元素、可选字段、export 关键字。在浏览器中运行。
J{}大型 JSON / JSONL 浏览器在本地打开、索引、搜索和导出大型 JSON 与 JSONL 文件，提供虚拟表格、惰性树和精确数字。
CSV大型 CSV/TSV 浏览器在本地打开、筛选、检查和导出超大型 CSV 或 TSV 文件，并通过增量解析和虚拟化表格保持流畅操作。
</>XML 格式化在浏览器中美化或压缩 XML，支持 2/4 空格或制表符缩进；保留注释、CDATA 和处理指令，并报告带行号和列号的解析错误。
Y:YAML 格式化/验证器校验 YAML 并将其重新格式化为 2 空格缩进的整洁块样式；错误会显示行号和列号。通过 WebAssembly 在本地运行。
*/5Cron 表达式生成器按分钟、小时、日期、月份、星期逐字段构建 cron 表达式，实时校验取值，并给出通俗说明和按本地时区计算的接下来 5 次运行时间。
cronCron 表达式解析器用通俗语言解释 cron 表达式，逐字段严格校验，并按本地时区列出接下来 5 次运行时间。内置常用快速预设，支持 @daily 等 @ 宏。

Aa文本大小写转换器一键将文本转换为 camelCase、snake_case、kebab-case、标题大小写、句子大小写、全大写或全小写，能正确拆分 XMLHttpRequest 这类标识符。

加密

4
MACHMAC 计算器用密钥实时计算消息的 HMAC-SHA256 或 HMAC-SHA512，边输入边更新。十六进制输出、UTF-8 输入，支持空消息。
AESAEAD 文件加密/解密用密码通过 AES-256-GCM 或 (X)ChaCha20-Poly1305 与 Argon2id 加密文件，并可再解密。文件不会离开浏览器。
sshOpenSSH 密钥在浏览器中生成 Ed25519、ECDSA 或 RSA SSH 密钥对（可加密码短语），并在 OpenSSH、PKCS#8 与 SPKI PEM 之间转换。
509X.509 证书使用 Ed25519 或 ECDSA 密钥创建自签名 X.509 证书和 CSR，并解析 PEM/DER 格式的证书或 CSR，全部在浏览器本地完成。

2

LoLorem Ipsum 生成器按段落、句子或单词（1–1000）生成 Lorem Ipsum 占位文本，可输出纯文本、带 <p> 标签的 HTML 或 Markdown，并统计词数和字符数。

UTC日期转换器将秒或毫秒级 Unix 时间戳转换为 ISO 8601、RFC 5322、UTC、本地时间或自定义格式，也可反向转换，输入即出结果。

图像

3
−%图像压缩器在浏览器中压缩 JPEG、PNG 或 WebP 图片：质量可设 1–100，可保留或更换格式，对比压缩前后大小后下载。文件不会上传。
png图像转换器在浏览器中将图片在 PNG、JPEG、WebP、GIF、BMP、ICO、TIFF 和 TGA 之间互相转换，JPEG 和 WebP 可调质量。文件不会上传。

3

QR→二维码扫描器在浏览器中用摄像头或从 PNG、JPEG、WebP 图片识别二维码，可复制解码文本或打开 http(s) 链接，全程本地处理，不上传任何内容。

为何选择 MyDevTools？

MyDevTools 是一套免费的浏览器端开发者工具：JSON、XML 和 YAML 的格式化与校验，Base64、Hex 和 URL 编码器，哈希和 HMAC 计算器，JWT 和 X.509 工具，正则表达式测试器，图片和 PDF 工具，以及 UUID、密码和二维码生成器。无需安装，也无需注册账号。

隐私来自架构本身：网站由静态页面组成，每个工具都在浏览器内处理你的输入。哈希、加密以及图片、PDF、二维码处理等计算密集型工具使用由 Rust 编译的 WebAssembly 模块；JSON 格式化、文本对比等较轻量的工具则是普通 JavaScript。你处理的密码、密钥和文件都不会被上传。

  • 隐私至上

    你的输入在浏览器中处理，从不发送到服务器。

  • WebAssembly 用在关键处

    哈希、加密、图片和 PDF 处理在 Rust 编译的 WebAssembly 中运行；简单的工具使用轻量的 JavaScript。

  • 离线可用

    打开过一次的页面在断网时也能继续使用。安装 PWA 可快速访问。

  • 多语言

    界面和工具说明提供 10 种语言版本。

  • 完全免费

    所有工具均免费。无隐藏费用或订阅。

  • 打造你的工具集

    为常用工具加星标。收藏和最近使用的工具保存在你的浏览器中。
