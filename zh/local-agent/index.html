Windows 配套程序

将浏览器工具连接到您的 Windows 电脑

本地代理让指定的 MyDevTools 工具在您的电脑上获得明确授权的能力。安装程序把它放到当前用户的配置文件夹，无需账户，并可通过 Windows 托盘控制。

下载、运行并配对

下载的是当前用户的安装程序。它把代理放到用户配置文件夹。再次运行更新的安装程序会替换这一份。

  1. 1

    下载

    下载安装程序。用更新的版本再次运行它会替换已安装的代理。

  2. 2

    运行

    打开安装程序。它会先停止已经在运行的代理，再写入新副本。Windows 可能要求确认运行下载的应用。不需要管理员权限。

  3. 3

    配对

    在 MyDevTools 工具中输入代理显示的最新代码。配对只授予该工具请求的能力。

严格限定的权限模型

代理不是账户、远程服务或通用命令执行器。

  • 无需注册、登录或 MyDevTools 云代理。
  • 无需管理员权限，也不安装 Windows 服务。安装程序只作用于当前用户。
  • 轮换的一次性代码会建立有时限的浏览器会话。浏览器会存储连接令牌，最长 8 小时或直到助手重启，但绝不会存储配对码。
  • 它只在本机监听。请求和探测由代理直接发往目标；只有在您设置代理时才经由代理。私有网络目标会被阻止，直到您在代理窗口中允许。路径上的路由器即使使用私有地址也会显示。

控制权始终在您手中

关闭小窗口只会将其隐藏；单击托盘图标可再次打开。

  • 查看版本和当前配对代码。
  • 自动启动需主动选择，默认关闭。它使用您的 Windows 用户设置；更新的安装程序替换代理后，自动启动仍指向已安装的副本。
  • “Allow local network and this PC as targets”默认关闭。开启后，工具可以访问私有地址和环回地址，并扫描您自己的网络；该选择会被记住，关闭它会停止正在进行的私有目标扫描。
  • 退出会停止本地服务器并完全撤销活动会话。

本机上的加密保管库

请求保管库的工具会把数据保存在代理中，而不是浏览器里。

  • 每个文件都使用 AES-256-GCM 加密；密钥由 Windows 为您的用户帐户保护。
  • 机密和客户端证书私钥只能写入：页面可以在请求中使用它们，但永远无法读回。
  • 每个网站都有自己的保管库，一个网站无法读取另一个网站的数据。
  • 要迁移到另一台电脑，请在代理窗口中使用“Export vault…”和“Import vault…”：所有网站一个文件，用你的密码加密（Argon2id 和 AES-256-GCM）。网页无法发起导出。

可用能力

此版本可以配对 HTTP 请求、WebSocket 连接、Server-Sent Events、用于工作区和机密的保管库、ICMP 路径跟踪、DNS 查询、TCP 检查、TLS 检查、WHOIS 和 ASN 查询、端口扫描器和网络扫描器。每个工具都会请求自己的命名能力；配对不会自动授予未来的能力，因此更新后工具可能会要求重新配对。

验证下载文件

此安装程序未经过数字签名，Windows SmartScreen 可能会警告或阻止运行。请勿关闭 Windows 防护。将下载文件的 SHA-256 与上面的值比较以验证完整性；哈希值一致并不等同于发布者签名。
