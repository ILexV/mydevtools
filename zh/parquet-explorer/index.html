Parquet 浏览器完全在浏览器中打开 Apache Parquet 文件。它先读文件尾以获取 schema 和行组统计，然后只解码你勾选的列，因此很宽或很长的文件不必变成一整张 HTML 表。

详细功能

文件留在这台设备上。Web Worker 按切片读取 PAR1 文件尾，并列出顶层列、物理类型与逻辑类型、重复性以及每列的压缩编码。行组会显示行数和压缩后大小。表格是虚拟的：滚动时只为已勾选的列请求一小段行。

放不进 JavaScript 数字的 INT64 和其他整数会保留十进制数字。时间戳变成 UTC ISO-8601 文本。二进制单元格显示为小写十六进制。嵌套结构和列表是 JSON。重复列名会加上数字后缀，使 JSONL 键保持唯一。

导出会读取所选列的每一行，并通过背压流式写入所选文件。没有原生保存选择器时，将使用上限为 512 MiB 的备用下载。

选中的列块会整块解压。嵌套值会变成 JSON。INT64 保留十进制写法。支持未压缩、Snappy、gzip、Brotli、Zstd、LZ4 和 LZ4_RAW。不支持 LZO。这里没有 SQL 筛选、排序或 Parquet 写入。

实用示例

扁平列： 含 name（字符串）和 id（INT64）的文件会同时勾选两列。像 9007199254740993 这样的 id 在表格、CSV 和 JSONL 中都保持这串十进制数字。

列投影： 取消「全选」，只勾选 name 再滚动。该视图不会解码其他列块。导出也只包含已勾选的列。

多个行组： 列表显示每组的行数和编码。表格仍把它们当成连续的行来读。

形如公式的文本： 在公式保护开启时，字符串 =1+1 会导出为 CSV 中的 '=1+1。JSONL 保留原始字符串。

如何使用此工具

  1. 1

    打开本地文件

    拖入或选择一个 .parquet 文件。读取文件尾时会显示字节、速度和用时。取消后重新选择文件即可重来。

  2. 2

    阅读 schema

    查看列类型、重复性和压缩，然后查看行组大小。文件若带有文件尾元数据对，也会列出来。

  3. 3

    浏览列

    取消不需要的列。滚动虚拟表格并选中一行，以查看更长的单元格。

  4. 4

    导出

    导出会读取所选列的每一行，并通过背压流式写入所选文件。没有原生保存选择器时，将使用上限为 512 MiB 的备用下载。

提示和最佳实践

  • 当前表格和下载只解码已勾选的列。如果只需要键，请不要勾选很大的二进制列。
  • 列块仍会整块解压，因此即使文件其余部分按切片读取，一个巨大的值也可能占用大量内存。
  • JSONL 会把放不进安全 JavaScript 数字的整数写成十进制字符串，而不是四舍五入后的数字。
  • 超过 512 个顶层列会被拒绝。列表只显示前 500 个行组；摘要中的数量包含其余行组。
  • 不支持 LZO。支持未压缩、Snappy、gzip、Brotli、Zstd、LZ4 和 LZ4_RAW。
  • 此页不运行 SQL。排序、分组和写入 Parquet 是另外的任务。

结构化数据

  • {}JSON 格式化在浏览器中格式化、压缩和校验 JSON：支持 2/4 空格或制表符缩进、递归排序键、大数字原样保留，可打开和保存 .json 文件。
  • TSJSON 转 TypeScript 转换器根据 JSON 示例生成 TypeScript interface 或类型别名：嵌套类型、合并数组元素、可选字段、export 关键字。在浏览器中运行。
  • J{}大型 JSON / JSONL 浏览器在本地打开、索引、搜索和导出大型 JSON 与 JSONL 文件，提供虚拟表格、惰性树和精确数字。
  • CSV大型 CSV/TSV 浏览器在本地打开、筛选、检查和导出超大型 CSV 或 TSV 文件，并通过增量解析和虚拟化表格保持流畅操作。
