关于代理和下载
  1. 启动 MyDevTools Agent。在 Linux 上，ICMP 需要 ping 组范围或 CAP_NET_RAW。
  2. 从代理窗口复制配对码。
  3. 把代码粘贴到下方。如果浏览器请求本地网络权限，请为此连接允许。

默认阻止私有、回环和局域网目标。仅在明确需要时在代理窗口中勾选“Allow local network and this PC as targets”。路径上的路由器即使使用私有地址也会显示。配对会添加 icmp.trace，并保留此浏览器中已经授予的能力；绝不会授予扫描器权限。

浏览器只把目标和探测设置发给 127.0.0.1 上的代理。ICMP 探测从代理进入网络，因此目标和路径上的路由器可以看到这台电脑。MyDevTools 服务器不会收到目标或跳表。此浏览器记住最近的目标和这些设置。它不保存跳结果或配对码。

目标
一个主机名或 IP 地址。只探测第一个解析到的地址。路径上的路由器即使地址是私有的也会显示。
间隔（毫秒）
两次探测之间的毫秒数，200 到 60000。下一次探测会等完间隔的剩余时间。默认 1000。
载荷（字节）
ICMP 载荷大小，0 到 1472 字节。不分片标志始终开启。默认 64。
最大跳数
要探测的跳数，1 到 64。探测在目标处停止。默认 30。
超时（毫秒）
每次探测等待多久，100 到 30000 毫秒。默认 5000。
源地址
自动表示由计算机选择。列表只包含这台计算机自己的地址，不是网络上的邻居。
空闲

路径跟踪从你电脑上的 MyDevTools 本地代理持续发送 ICMP 回显探测，并显示每一跳的丢包和延迟。浏览器本身不发送 ICMP。icmp.trace 与 http.request 分开授予。

详细功能

跟踪进行时表格会更新。每一跳记录已发送、已接收、丢包，以及最近、最佳、平均和最差往返时间、样本标准差和平均抖动。沉默的一跳显示“无响应”，地址留空。路由器的应答会保留，包括家庭网关和 100.64.0.0/10 中的 CGNAT 地址。这些地址是路径上的观察，不是新目标。你输入的主机单独检查：私有和回环目标需要在代理窗口中勾选“Allow local network and this PC as targets”，元数据、链路本地和多播目标始终拒绝。探测在目的地停止，或在路径末尾同一路由器重复时停止。可以把当前表格复制或下载为文本和 HTML。代理不会把报告写到磁盘。最近的目标和间隔、载荷、跳数上限、超时以及名字解析设置留在此浏览器。跳结果不保存。

实用示例

  • 1.1.1.1 以 64 字节载荷、30 跳和 5 秒探测超时跟踪公共解析器。
  • example.com 由电脑的 DNS 解析，然后只探测第一个地址。
  • 127.0.0.1 需要在代理窗口中勾选“Allow local network and this PC as targets”。

如何使用此工具

  1. 1

    启动本地代理

    下载并启动代理，复制配对码。在 Linux 上，ICMP 需要 ping 组范围或 CAP_NET_RAW。

  2. 2

    配对路径跟踪

    粘贴代码并连接。页面请求 icmp.trace，并保留此浏览器已经拥有的能力，例如 http.request。

  3. 3

    跟踪主机

    输入一个主机名或 IP，按需要调整间隔、载荷、跳数上限和超时，然后按开始。停止会结束探测。最后的快照留在页面上。

  4. 4

    复制报告

    选择一跳以查看 ICMP 状态。将表格复制或下载为文本或 HTML。

提示和最佳实践

  • 丢包是整数。尚未发送探测时为 0。之后是 100 减去 100 乘以已接收再除以已发送。
  • 缺失的往返时间显示为破折号，不是零。
  • 标准差和平均抖动在两次应答之后出现，精确到十分之一毫秒。超时不算样本。抖动是相邻应答绝对差值的滑动平均。
  • 关闭名字解析后，主机列保留数字地址。
  • 代理最多同时运行两条跟踪。每个桌面窗口开始自己的跟踪。
  • 已发布的 Windows 下载可能比此页面旧。路径跟踪需要宣告 icmp.trace 的代理。
  • 查找路径 MTU 会发送 DF 探测，并保留获得应答的最大尺寸。丢失的探测不是大小限制。搜索在 1500 字节停止。
  • 源地址列出这台计算机自己的地址。自动把选择留给系统。这不是扫描，也不是 ARP 表。
