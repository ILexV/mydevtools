PDF 转文本

在浏览器中将 PDF 的文本层提取为 UTF-8 编码的 .txt 文件，支持字体 Unicode 映射和批量处理。无需上传，不使用 OCR。

    在浏览器中将 PDF 文件的文本层提取为纯 UTF-8 .txt 文件——用于搜索、比对或交给脚本处理。不会上传任何内容，也不涉及 OCR。

    详细功能

    提取器读取每一页的文本显示命令，并通过字体的 ToUnicode 映射表、嵌入的 TrueType cmap 或 WinAnsi 编码解码字符，因此只要 PDF 提供了映射，西里尔文等非拉丁文字都能正确输出。PDF 每换到下一行就开始新的一行，页面之间以空行分隔。

    扫描版 PDF 只包含图片，由于没有 OCR，提取结果为空。多栏排版和表格会按文本在文件中的存储顺序展开，单词间的空格取决于 PDF 的生成方式。受密码保护的 PDF 会被拒绝，并给出明确提示。

    可以一次添加多个 PDF：它们在 Web Worker 中依次处理并显示进度条，取消 会立即停止，每个完成的行都会出现 下载 TXT，用于保存 <name>.txt。

    实用示例

    两页文档：页面内容分别为“Second doc page A”和“Second doc page B”的 PDF，提取结果为 Second doc page A、一个空行和 Second doc page B。

    大文件：一个 2,500 页、5.44 MB 的 PDF 生成 36 KB 的 big.txt，期间页面保持流畅。

    扫描合同：由页面图片组成的 PDF 会得到空的 .txt——请先用其他工具进行 OCR。

    受密码保护的文件：显示“locked.pdf：该 PDF 受密码保护，无法处理。”，同一批次中的其他文件照常提取。

    如何使用此工具

    1. 1

      添加 PDF 文件

      点击 选择文件，或将一个或多个 PDF 拖放到 上传 PDF。文件会显示在 待处理文件 下。

    2. 2

      提取

      点击 提取文本。进度条显示当前文件；取消 可停止整批处理。

    3. 3

      下载文本

      点击某一行的 下载 TXT，保存 <name>.txt（UTF-8）。

    提示和最佳实践

    • 如果结果为空，PDF 很可能是扫描件：没有可提取的文本层。
    • 出现乱码说明 PDF 的字体没有可用的 Unicode 映射；从 PDF 阅读器中复制通常也会同样失败。
    • 表格和多栏内容按存储顺序输出，用脚本解析文本前请先检查行的顺序。
    • 再次点击 提取文本 时会跳过已提取的文件，因此可以继续向同一列表添加文件。
