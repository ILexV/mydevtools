为链接、文本或 Wi-Fi 字符串生成二维码，选择颜色、样式、纠错等级和尺寸，添加徽标，然后下载 PNG 或 SVG。二维码在您的浏览器中生成。

详细功能

内容以 UTF-8 字节编码，因此任何文字和 emoji 都可使用。纠错等级 L、M、Q 和 H 分别可恢复约 7%、15%、25% 和 30% 的损坏；等级越高，码越密集。容量最高为 L 级 2953 字节、H 级 1273 字节——内容超长时会显示错误，而不是生成无法识别的码。

PNG 的尺寸恰好为 256、512、1024 或 2048 px，四周留有至少四个模块宽的静区。方形、点状 和 圆角 样式改变的是数据模块，三个定位方块始终保持方形，因此每种样式都可读取。徽标（PNG、JPEG 或 WebP）放在中心的底板上，其大小随纠错等级增大（H 级最多占码宽的 30%）——使用徽标时请选 Q 或 H，并用真实手机测试；任何徽标大小都不能保证一定可扫。SVG 仅适用于不带徽标的方形样式。

颜色可通过取色器或十六进制值（#RRGGBB）设置，无效值会被标出；两种颜色的对比度会显示出来，过低或反色时给出警告。生成在浏览器中通过 Rust/WebAssembly 完成，输入内容或更改选项时预览会自动更新。

实用示例

网站链接：https://example.com，M 级，512 × 512，得到恰好 512×512 px 的 qrcode.png；二维码扫描器能读回内容并显示 打开链接 按钮。

Wi-Fi 连接：WIFI:T:WPA;S:MyNet;P:secret123;; 编码了网络凭据，手机相机识别后会提示加入该网络。

品牌二维码：Branded code 加圆形徽标、H 级、圆角 样式、1024 × 1024，仍能解码出原文。

数据过多：3000 个字符超出最大容量，工具会显示错误而不是生成二维码。

如何使用此工具

  1. 1

    输入内容

    在 内容 中输入网址或文本。

  2. 2

    选择外观

    设置 二维码颜色 和 背景颜色，然后选择 样式、纠错等级 和 图像大小。

  3. 3

    添加徽标（可选）

    将 PNG、JPEG 或 WebP 图片拖放到 徽标（可选） 下，并切换到 Q 或 H 级。

  4. 4

    检查并下载

    预览会随输入实时更新。更新完成后，下载 PNG；不带徽标的方形样式还可下载 SVG。

提示和最佳实践

  • 保持强对比度：浅色背景上的深色模块识别最可靠；部分扫码器不支持反色。
  • 内容越短，码越稀疏，远距离也更容易扫描——尽量使用短网址。
  • 使用徽标时选择 H 级，并在打印前用手机测试。
  • 打印时请使用 SVG（不带徽标的方形样式）或 2048 px 的 PNG。
  • 保留二维码周围的白边：扫码器需要静区。
