关于代理与下载
  1. 启动 MyDevTools Agent。私有地址或环回地址需要在代理窗口中勾选“Allow local network and this PC as targets”。
  2. 从代理窗口复制配对码。
  3. 把配对码粘贴到下面。如果浏览器询问本地网络访问，请为这次连接允许。

浏览器只把主机、端口和超时发给 127.0.0.1 上的代理。代理打开一次 TCP 连接后就关闭。它不发送数据，也不尝试一段端口。检查不会发到 MyDevTools 服务器。这个浏览器只记住超时，不保存主机、端口或结果。

主机
一个主机名或一个 IP 地址。私有地址和环回地址需要在代理窗口中勾选“Allow local network and this PC as targets”。不接受端口范围。
端口
一个端口，范围是 1 到 65535。
超时
这一次连接最多等待多久，从 200 到 10000 毫秒。

TCP 连接让本地代理打开一次到你输入的主机和端口的连接，然后关闭。页面显示它是打开、被拒绝、超时还是没有路由，以及花了多少毫秒。能力 tcp.connect 与 http.request、icmp.trace 和 dns.lookup 分开授予。

详细功能

代理采用名字的第一个地址，并使用与 HTTP 客户端相同的目标规则。私有地址和环回地址只有在代理窗口中勾选“Allow local network and this PC as targets”（或代理以 --allow-private 启动）时才可用。metadata、链路本地和多播地址仍然被阻止，代理自己的监听端口也被阻止。检查只是一次握手：不发送字节，也不读取横幅。像 80-443 这样的数字范围会被拒绝。同时最多两次检查。超时留在这个浏览器里。主机、端口和结果不留。

实用示例

  • example.com 端口 443 显示一次打开的握手和耗时。
  • 没有服务在听的 127.0.0.1 端口显示拒绝。
  • 主机栏里的 80-443 会被拒绝。这不是扫描。

如何使用此工具

  1. 1

    启动本地代理

    下载代理，启动它，并复制配对码。

  2. 2

    配对 TCP 连接

    粘贴配对码并连接。页面请求 tcp.connect，并保留这个浏览器已经持有的能力。

  3. 3

    检查一个端口

    输入一个主机和一个端口，设置超时，然后按开始检查。

  4. 4

    阅读结果

    页面显示状态、地址和耗时。可以复制成文本。重新加载页面会清掉它。

提示和最佳实践

  • 拒绝和超时是结果。检查本身并没有失败。
  • 一次请求是一个主机和一个端口。范围不属于这个工具。
  • 同时最多两次检查。
  • 已发布的 Windows 下载可能比这一页旧。TCP 连接需要宣告 tcp.connect 的代理。
