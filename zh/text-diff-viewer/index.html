逐行比较两段文本或两个文件：以并排或统一 diff 视图显示新增、删除和修改的行，并高亮行内变化的单词。

    粘贴配置文件、代码片段或文档的两个版本，即可准确看到哪些行被新增、删除或修改——提供类似 Git diff 的并排视图和逐行（统一）视图。

    详细功能

    比较以行为单位：jsdiff 生成统一补丁，diff2html 负责渲染，显示行号、每处变化周围最多 4 行未改动的上下文，并在修改过的行内高亮变化的单词。只显示发生变化的区域（hunk），而不是整段文本。空白和大小写都会被区分，因此缩进变化或行尾空格也算作改动。

    每一侧都可以输入、粘贴，或从本地文本文件加载（按 UTF-8 读取）。换行符会被统一，因此行内容相同的 Windows（CRLF）文件和 Unix（LF）文件会被判定为相同。两侧都从文件加载时会自动开始比较；输入完全相同时会提示没有差异。

    diff 在浏览器中计算，文件也在本地读取——不会上传任何内容。为了保持页面流畅，差异过大的文本有上限：如果超过 1,000 行不同，工具会显示提示信息而不是 diff。

    实用示例

    配置变更：原始行 host=localhost、port=8080、debug=true 与 host=0.0.0.0、port=8080、debug=false 比较——host 和 debug 行被标记为删除和新增，并高亮变化的单词，port=8080 作为未改动的上下文保留。

    长文件中的一行：在一段 20 行的文本中只修改第 11 行，diff 只显示一个 hunk @@ -7,9 +7,9 @@——改动本身加上前后各 4 行上下文。

    比较两个文件：用文件按钮选择旧版本和新版本，两者加载完毕后立即显示 diff。

    检查副本：比较两段完全相同的文本时，会提示没有发现差异。

    如何使用此工具

    1. 1

      添加原始文本

      将文本粘贴到 原始文本，或点击 选择原始文件。

    2. 2

      添加修改后的版本

      将文本粘贴到 修改后的文本，或点击 选择修改后的文件。

    3. 3

      比较

      点击 比较。两侧都来自文件时，diff 会自动显示。

    4. 4

      切换视图

      在 视图模式 中选择 并排视图 或 统一视图；清除 会清空两个输入框。

    提示和最佳实践

    • 并排视图 适合宽屏阅读，统一视图 更适合手机。
    • 只能比较纯文本；不支持图片、PDF 或 Word 文档。
    • 如果超过 1,000 行不同，请把文件分成较小的部分再比较。
    • 先格式化 JSON 或压缩过的代码（每行一项）——单独一长行只会显示为一行改动。
    • 首次访问后，页面在没有网络时也能使用。
