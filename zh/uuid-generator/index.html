UUID/GUID 生成器

批量生成随机 UUID v4 或按时间排序的 UUID v7（最多 100 个），支持带连字符、无连字符、花括号和 URN 格式，可复制或下载 TXT。

    在浏览器中生成符合 RFC 9562 的 UUID：随机的版本 4 或按时间排序的版本 7，可单个生成，也可每批最多 100 个。可选带连字符、无连字符、花括号或 URN 格式及大小写，然后复制单个、复制全部或下载为文本文件。

    详细功能

    版本 4 用浏览器的密码学安全随机数生成器（Web Crypto getRandomValues）填充 122 位随机数据，其余 6 位标记版本和变体。版本 7 以 48 位毫秒级 Unix 时间戳开头，随后是 12 位计数器和 62 位随机数据。计数器遵循 RFC 9562 §6.2：同一毫秒内生成的 ID，甚至系统时钟回拨之后生成的 ID，仍然严格递增，因此一批 v7 UUID 会按生成顺序排列。这让 v7 很适合作为 B-tree 索引的主键，而 v4 不会泄露生成时间。

    提供四种格式：标准的带连字符 8-4-4-4-12、无连字符的 32 位十六进制、Windows 和 .NET 中 GUID 常用的花括号 {…}，以及 URN urn:uuid:…。“大写”只改变十六进制字符，URN 前缀保持小写。

    生成完全由页面上的 JavaScript 完成——不使用 WebAssembly，也不请求服务器——ID 不会离开你的设备。下载的是普通 .txt 文件，每行一个 UUID。

    实用示例

    数据库主键：带连字符的版本 4 形如 xxxxxxxx-xxxx-4xxx-Yxxx-xxxxxxxxxxxx，第 13 位十六进制字符总是 4，Y 为 8、9、a 或 b。

    可排序 ID：在 2023-11-14T22:13:20Z（Unix 1700000000000 毫秒）生成的 v7 UUID 以 018bcfe5-6800-7 开头——前 12 位就是时间戳，所以一批 ID 按时间排序。

    .NET 和注册表风格：花括号格式加“大写”生成 {9F2C…} 样式的 GUID，可直接用于 C# 特性或 .reg 文件。

    测试数据：把数量设为 100，生成一批后点击下载为 TXT，即得到 100 行的文件。

    如何使用此工具

    1. 1

      选择版本

      在“UUID 版本”中选择“版本 4 (随机)”或“版本 7 (基于时间)”。

    2. 2

      设置格式、大小写和数量

      选择“格式”和“大小写”，拖动“UUID 数量”滑块（1–100）。

    3. 3

      生成

      点击“生成”，每次点击都会用新的一批替换列表。

    4. 4

      复制或下载

      用行内按钮复制单个 UUID，用“复制全部”复制整个列表，或用“下载为 TXT”保存为文件。

    提示和最佳实践

    • 数据库主键和日志关联 ID 建议用 v7：按时间排序可让索引插入更集中。
    • v7 UUID 会暴露精确到毫秒的生成时间；若需保密，请使用 v4。
    • UUID 是唯一标识符而不是秘密，不要拿它当密码或会话令牌。
    • 大多数解析器两种大小写都接受，但 RFC 9562 建议输出小写；大写适用于 Windows 注册表等系统。
    • 32 位无连字符形式适合 CHAR(32) 列；如果数据库有原生 16 字节 UUID 类型，优先使用它。
